# Mods

Information on modding for PlanarAlly will be managed here.

<Warning title="Experimental">
    Mod support is still experimental. The mod API and UI may change between releases. Only install mods from sources
    you trust.
</Warning>

This section of the docs will be mostly focussed on mod development.

If you're looking for information on how to add mods to your campaign check the [DM settings](/docs/dm/mods/) for more information.

If you're looking for information on how this impacts your server infrastructure check the [server settings](/server/management/mods/).
