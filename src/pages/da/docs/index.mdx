# Introduktion

PlanarAlly er et open source virtuelt spillebord, som du selv kan hoste og køre uden internetforbindelse.
Denne dokumentation dækker brugen af PlanarAlly som spiller eller DM samt hostning af din egen server.

## Kernefunktioner

**Belysning og syn** — Krigståge, dynamiske lys og synslinjer, så spillerne kun ser det, deres karakterer kan se.
[Dokumentation →](/da/docs/dm/lighting-vision/)

**Lag, etager og lokationer** — Stabel kortelementer i lag, opdel bygninger i etager og organisér scener på tværs af lokationer.
[Oversigt →](/da/docs/game/gameboard/)

**Aktiver og skabeloner** — Upload kort og tokens, organisér dem i mapper, og gem formpræsæt til genbrug.
[Dokumentation →](/da/docs/dm/assets/)

**Værktøjer** — Ruler, draw, spellområder, initiativsporing med mere — tilgængelige i Build- og Play-tilstand.
[Oversigt →](/da/docs/tools-overview/)

**Noter** — Kampagnenoter med søgning, tags og valgfri tilknytning til former.
[Dokumentation →](/da/docs/game/notes/)

**Selvhostning** — Kør din egen server med fuld kontrol over dine data. Fungerer offline, når den først er sat op.
[Opsætningsvejledning →](/da/server/setup/)
