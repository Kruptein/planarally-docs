# Værktøj Ping

Ping-værktøjet kan tilgås i værktøjslinjen nederst til højre på spillebordet, men kun i [Play-tilstand](/da/docs/tools-overview/#toolbar-and-modes).
Det fungerer som et minimalistisk "beacon"-værktøj.
Mens musen er trykket ned og holdt, viser det to cirkler til alle spillere der, hvor din mus i øjeblikket er.

Ping-cirklerne bruger samme farve som din ruler-farve fra dine [klientindstillinger](/da/docs/game/settings/).
