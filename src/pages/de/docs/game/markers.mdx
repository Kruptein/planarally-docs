# Marker

Auf Marker kannst du über das Seitenmenü zugreifen (klicke auf das <Cog />-Symbol oben links im Browserfenster, um das Menü zu öffnen).

Dies ist ein Ort, an dem Formen, die du markiert hast, als Schnellreferenz erscheinen. Wenn du auf einen deiner Marker klickst, zentriert sich der Bildschirm auf die zugehörige Form.

Um eine Form zu markieren, klicke einfach mit der rechten Maustaste darauf und wähle die Option „Set marker“. Nach dem Markieren kannst du die Markierung entweder über das Marker-Menü entfernen oder per Rechtsklick auf die Form und Auswahl von „Remove marker“.
