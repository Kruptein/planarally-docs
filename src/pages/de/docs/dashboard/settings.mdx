# Einstellungen

<Image src={DashboardSettings} alt="Dashboard-Einstellungen" />

Derzeit sind nur die Kontoeinstellungen verfügbar.
Dieser Bereich ermöglicht es dir, falls gewünscht, eine E-Mail-Adresse festzulegen und, was noch wichtiger ist, dein Passwort zu ändern oder dein Konto zu löschen.
