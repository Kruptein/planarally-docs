# Werkzeug Zoom

Obwohl es kein auswählbares Werkzeug in der Symbolleiste ist, gibt es oben rechts auf dem Bildschirm ein eigenes Zoom-Werkzeug.

Zusätzlich kannst du auch mit dem Mausrad zoomen.
Dieses Verhalten kann in den [Client-Einstellungen](/de/docs/game/settings/#behaviour) deaktiviert werden.

Ein entscheidender Unterschied zwischen dem Mausrad und dem Scroll-Werkzeug besteht darin, dass ersteres relativ zu deinem Mauszeiger zoomt, während letzteres relativ zur Bildschirmmitte scrollt.
