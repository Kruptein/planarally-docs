# Werkzeug Ping

Das Ping-Werkzeug kann über die Symbolleiste unten rechts am Spieltisch aufgerufen werden, allerdings nur im [Play-Modus](/de/docs/tools-overview/#toolbar-and-modes).
Es dient als einfaches „Leuchtfeuer"-Werkzeug.
Solange die Maustaste gedrückt gehalten wird, werden allen Spielern zwei Kreise an der Stelle angezeigt, an der sich deine Maus gerade befindet.

Die Ping-Kreise verwenden dieselbe Farbe wie dein Lineal in deinen [Client-Einstellungen](/de/docs/game/settings/).
