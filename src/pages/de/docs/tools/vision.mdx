# Werkzeug Vision

Das Vision-Werkzeug kann in beiden [Modi](/de/docs/tools-overview/#toolbar-and-modes) über die Symbolleiste unten rechts am Spieltisch aufgerufen werden.
Es hilft dabei, die Sicht mehrerer Token zu verfolgen.
Sein Verhalten ist für Spieler und DMs unterschiedlich.

## Spieler

Wenn du darauf klickst, öffnet das Vision-Werkzeug eine Liste aller Objekte, für die dem Spieler [Zugriff auf die Sicht](/de/docs/game/shapes/#access) konfiguriert ist.
Standardmäßig werden sie in der Liste als aktiv angezeigt, was durch einen farbigen Hintergrund gekennzeichnet ist.
Alle Modi und Werkzeuge zeigen nur die Sicht derjenigen Token, die einen _aktiven_ Eintrag im Vision-Werkzeug haben.

Mit einem Klick wird ein Eintrag deaktiviert und zeigt nun einen grauen Hintergrund.
Gleichzeitig wird die Sicht dieses Tokens nicht mehr auf dem Spieltisch angezeigt.

## DM

Standardmäßig sehen DMs immer alles.
Die alleinige Verwendung des Vision-Werkzeugs ändert daran nichts.
Sie können jedoch den [Fake-Player](/de/docs/dm/settings/#fake-player) verwenden, um einen ähnlichen Effekt wie den oben beschriebenen zu erzielen.
In diesem Fall verwenden sie das Vision-Werkzeug, um festzulegen, welche Sicht eines Spielers sie sehen möchten.
