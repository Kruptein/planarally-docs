# Undo

Dieses "Werkzeug" hat weder einen Platz in der Symbolleiste noch ein anderes UI-Element, sondern wird über 2 Tastenkürzel gesteuert.

Mit ctrl+z kannst du eine Operation rückgängig machen, mit ctrl+shift+z kannst du eine Operation wiederholen.

Die Liste der derzeit unterstützten Aktionen:

- Bewegen von Formen
- Rotieren von Formen
- Größenänderung von Formen
- Etagenwechsel
- Ebenenwechsel
- Erstellen/Entfernen von Formen
