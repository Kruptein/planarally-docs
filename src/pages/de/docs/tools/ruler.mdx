# Werkzeug Ruler

Das Ruler-Werkzeug kann unabhängig vom [Modus](/de/docs/tools-overview/#toolbar-and-modes) über die Symbolleiste unten rechts am Spieltisch aufgerufen werden.
Es ist ein einfaches Werkzeug, mit dem du Entfernungen messen kannst.

Ab dem Ort, an dem du geklickt hast, wird eine Linie mit einer Zahl gezeichnet, die die Entfernung zu deinem Mauszeiger anzeigt, bis du die Maustaste loslässt.
Wenn du unterwegs `space` drückst, werden Wegpunkte gesetzt, sodass du Entfernungen rund um Objekte leicht messen kannst.
Es zeigt die erste Nachkommastelle an, um das metrische System bei Spielen zu unterstützen, die für das imperiale System konzipiert wurden (z. B. entspricht das übliche 5-Fuß-Raster in D&D 1,5 m).

Wenn du die Option `Share with others` aktivierst, die oberhalb der `Ruler`-Schaltfläche in der Symbolleiste geöffnet wird, ist das Lineal für alle Spieler in der Sitzung **öffentlich** sichtbar.
Wenn du diese Option deaktivierst, siehst nur du das Lineal.
Diese Einstellung wird auch vom Lineal verwendet, das im [Select-Werkzeug](/de/docs/tools/select/) integriert ist.

Die Farbe, in der dies gezeichnet wird, kann von jedem Spieler in seinen [Client-Einstellungen](/de/docs/game/settings/) gewählt werden.
Das Lineal hat außerdem ein [Einrastverhalten](/de/docs/game/snapping/), das versucht, an logischen Stellen auf dem Raster einzurasten.
