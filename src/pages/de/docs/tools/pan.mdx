# Werkzeug Pan

Das Pan-Werkzeug kann unabhängig vom [Modus](/de/docs/tools-overview/#toolbar-and-modes) über die Symbolleiste unten rechts auf dem Bildschirm aufgerufen werden.
Wenn dieses Werkzeug ausgewählt ist, kannst du den Bildschirm verschieben, indem du die Maustaste gedrückt hältst, während du sie bewegst.

## Schnelles Verschieben

Da das Verschieben eine so häufig verwendete Aktion ist, kann das Umschalten von anderen Werkzeugen lästig sein.

PA löst das Verschieben außerdem auch beim Ziehen mit der mittleren Maustaste sowie beim Ziehen mit der rechten Maustaste aus.
