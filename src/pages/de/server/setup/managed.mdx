# Gehostet

Bei weitem die einfachste Option bezüglich der Einrichtung ist die Nutzung eines Online-Dienstes, der PlanarAlly für dich und deine Spieler bereitstellt.

Im Moment habe ich nicht die Ressourcen, um einen PlanarAlly-Server öffentlich zu hosten, aber das ist möglicherweise etwas, das ich in Zukunft gerne hinzufügen würde.

<Warning>
    Diese Dienste werden **nicht** von mir betrieben, daher kann ich nicht garantieren, dass die Software nicht
    böswillig verändert wurde.
</Warning>

## Bekannte Anbieter

_Wenn du PA öffentlich hostest oder jemanden kennst, der das tut, lass es mich gerne wissen!_

[Dice.Quest](https://planarally.dice.quest/) (früher dndbox.com) v2024.3 wird in der Schweiz/Europa gehostet und hostet eine Reihe von [Open-Source-Projekten](https://dice.quest), darunter PlanarAlly. Support wird auf [Reddit](https://reddit.com/r/dndbox/) angeboten.

[10leej.com](https://planarally.10leej.com/) v2025.1.1 wird in Atlanta, Georgia/USA gehostet; Support wird von 10leej angeboten. Für den Support nutze die Kontaktinformationen auf der [Website-Startseite](https://10leej.com/).
