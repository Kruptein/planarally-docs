# Undo

Esta "herramienta" no tiene un lugar en la barra de herramientas ni ningún otro elemento de UI, sino que se controla mediante 2 atajos de teclado.

Con ctrl+z puedes deshacer una operación, con ctrl+shift+z puedes rehacer una operación.

La lista de acciones actualmente soportadas es:

- movimiento de forma
- rotación de forma
- redimensionado de forma
- cambio de planta
- cambio de capa
- creación/eliminación de forma
