# 简介

恭喜你，你的团队正在考虑为你的下一场游戏使用 PlanarAlly！
但你究竟该怎么使用它？

在这个入门指南中，我们将了解如何创建账户、加入游戏，并通过查看打开游戏时可见的主要 UI 元素来热身！

## 创建账户

<Info title="PA 服务器">
    并不是只有一个 PlanarAlly
    服务器，任何人都可以自由托管自己的版本，并选择对其他人开放或关闭。通常你组里的某个人会安排你们在哪个 PA
    服务器上玩，如果没有，就得有人去阅读[服务器文档](/zh/server/setup/)，确定一个共同的服务器。
</Info>

当你访问选定的服务器主机时，你会立即看到一个登录页面。
PlanarAlly 在你注册新账户时不需要任何特别的东西，
只需要一个用户名和密码，邮箱可选。

目前邮箱在 PA 本身中不会被用到，
但服务器管理员可能会用它来通知用户即将到来的维护或类似事情。

## 加入游戏

登录后，你会看到主仪表盘，它会显示你加入的游戏，如果以后你决定自己主持游戏，它们也会显示在这里。

![登录后的主仪表盘](./assets/dashboard.png)

不过，要让游戏显示在这里，你首先需要被邀请。

你的主持会给你发一个 URL，访问它会自动将你的账户连接起来，并把你放进游戏。
将来该游戏会按上面解释的那样显示在你的主仪表盘中！

## UI 快速介绍

一旦你打开一个游戏，你立即会看到各种 UI 元素。

![一个游戏内会话示例](./assets/in-game.png)

占据屏幕大部分空间的是任何 VTT 的核心：带有棋子、视野和照明的地图。
你的 DM 之前已经准备好了这些。

<Warning title="怎么全是黑的？！">
    有可能你唯一能看到的就是纯粹的黑色虚空。但别担心，你的 DM 可能还需要给你一个形状的权限！

    如果他们做了这些而你仍然看不到任何东西，试试按 <kbd>space</kbd> 把屏幕重新居中到你拥有视野权限的棋子上。

</Warning>

在下一章中，我们将看到如何正确地与地图交互，平移和缩放它，以及移动我们的角色。

让我们先介绍一下屏幕的四个角，PA 把大多数其他重要的 UI 元素放在那里。

左上角有一个 <Cog />，会打开一个侧边栏，
这主要用于配置一些不常用的设置，也是离开当前游戏并返回主仪表盘的方式。

右上角有一个缩放滑块，用于控制地图的缩放级别，你还会看到一个显示当前选中角色信息的 UI 元素。

继续顺时针看，我们在右下角看到一堆图标和一个 Build/Play 切换。
这些都与 PA 提供的各种工具有关。从 Draw 工具，到 Ruler 和骰子。
下一章会有更多内容！

最后是左下角，在上面的截图中它是空的。
这个区域主要保留给 DM 特定的东西，但如果你的 DM 使用了名为 "floors" 的特殊 PA 功能，它也可以在玩家那边显示出来。
如果你的 DM 启用了文本聊天功能，聊天也会显示在这里！

这个快速介绍只让我们热身了一下，让我们完全潜入，看看这些工具是什么，以及我们如何与我们的角色交互，[在下一章](/zh/learn/player/interaction/)！
