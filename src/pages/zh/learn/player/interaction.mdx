# 与游戏交互

是时候真正使用 PA 了！

## 移动地图

让我们从最简单的事情开始，移动地图。

使用任何 VTT 的一个基本部分就是知道如何移动镜头。

### 缩放

放大/缩小非常简单，只需滚动鼠标滚轮。
如上一章所述，右上角也有一个专用的缩放滑块可以使用。

主要区别是滑块总是相对于屏幕中心缩放，
而鼠标缩放则相对于当前鼠标位置缩放。

### 平移

要移动地图，你可以按住鼠标中键或右键并移动鼠标。

<Tip>你可以在客户端设置中禁用你不打算使用的按钮，以防止意外平移</Tip>

你也可以用键盘移动，按任意方向键屏幕就会朝对应方向平移。
每按一次屏幕移动 1 个网格单元格。

<Tip>如果想发现更多方式，请看[快捷键](/zh/docs/reference/#keybindings)！</Tip>

## 查看工具

让我们仔细看看右下角的工具栏。
根据**模式**的不同，它可以有两种形式，但作为玩家，你几乎只会使用 play 模式：

![Play 工具](./assets/tools-play.png)

<Tip>
    1: 如果你不喜欢抽象的图标，你可以在客户端设置中把 UI 改为显示文本标签。
    <br />
    2: 你可以通过按 <kbd>tab</kbd> 在模式之间快速切换
</Tip>

PA 中的大多数交互都取决于当前激活的是哪个工具，在上面的例子中是 Select 工具。

我们很快会把所有工具过一遍，但只限于你经常使用的基本内容。
更深入的信息请查看[工具文档](/zh/docs/tools/select/)。

### Select

这是你最常用的工具。它的主要用途是……选择东西！

左键点击一个形状会选中它，并在形状周围添加红色边框。
如果你现在在移动鼠标时按住左键，你将能移动这个形状。

如果你选择多个形状，你就能一次移动它们！

震惊吧，我知道。

不过 Select 工具还有更多功能，当你有活动选区时，
右上角会出现一个特殊 UI，显示选中形状的快速信息，
右下角也有 Select 工具的额外配置选项。

<Info title="调整大小 / 旋转">
    Select 工具也有调整形状大小或旋转的能力。
    <br />
    因为这通常不是你经常做的事情，这个功能只在 Build 模式下可见。
    这可以防止当你只是想拖动形状却碰巧点击得离角落太近时的意外调整大小。
</Info>

### Pan

下一个可能是最少使用的工具，因为它允许你用左键点击移动/平移屏幕。

因为你总是可以用中键或右键从任何工具进行平移，
你只会在没有鼠标的设备上主动使用这个工具。

### Spell

如果你需要临时在地图上添加一些法术效果，这个工具可以帮你。

它允许你选择一些常见的法术形状，配置尺寸并把它们放在地图上。

如果你选中了一个形状，会在这个形状和法术效果之间自动跟踪一条 Ruler 线，
以确保你了解你施法的距离。

### Ruler

如果你需要测量距离，它就是你的朋友。

一个非常直接的工具，你点击并拖动一条线来测量距离，以网格单元格数量或世界内距离（例如英尺或米）为单位。

<Tip>如果在拖动鼠标时按下空格键，会生成一个新的锚点，让你可以测量绕过角落的距离！</Tip>

### Ping

另一个小而好用的工具是 Ping 工具，它只是让你在地图的特定区域引起注意。

### Vision

这是一个专用工具，只有在你控制多个角色时才会显示。

它会把你的视野限制在这个工具中选中的角色上。

### Dice

骰子工具是一个要么经常用要么根本不用的工具。

它允许你以纯文本形式或通过实际模拟虚拟 3D 骰子来结算骰子投掷。

### Draw

这个工具只在 Build 模式下可见！

使用这个工具，你可以在地图上绘制各种形状。

## 修改你的角色

还没有涵盖的是你如何修改你的角色，这当然也是游玩的重要组成部分。

当你选中了你的角色时，有多种方式打开编辑 UI。

- 按下快速信息中的 <PenSquare /> 图标（右上角）
- 右键点击你的角色并点击 "show properties"
- 按 <kbd>Enter</kbd>

无论你最终选择哪种方式，都会出现一个更大的 UI 元素，允许你编辑角色的多个方面。
可以配置很多东西，但别担心，作为玩家最重要的标签页是 Properties 和 Trackers。

### Properties

在这里你可以编辑一些基本信息，比如角色的名字和素材。

### Trackers

在这里你可以配置追踪器和光环。

追踪器是你可能想在游戏过程中保存和修改的数值数据（例如 HP）。
它们也可以选择性地显示在你的角色上方的地图上，可以是私密的，也可以对所有其他玩家可见。

另一方面，光环总是可视化的，它们代表诸如区域效果和灯光之类的东西。
如果光环是为了给你视野（例如火把或黑暗视觉），请确保切换 "Light source"。

光环的范围输入有 2 个值，第一个值是应该有明亮光照多少英尺，
第二个是昏暗光照多少英尺。所以一个 5e 火把应该是 20 / 20（而不是 20 / 40！）。

## 延伸阅读

这是让你与 PlanarAlly 交互的工具的一个非常简短的概述。

一些没有提到的你可能想了解的东西：

- Notes：跟踪你收集的关于特定 npc 或故事节奏的信息
- Chat：一个简单的基于文本的临时聊天
- Initiative：一个基础的先攻跟踪器

如果你对实际主持游戏感兴趣，可以看看[DM 指南](/zh/learn/dm/intro/)，了解那都是怎么回事。
