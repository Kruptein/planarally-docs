# RTS 风格照明

指南由 [@veritanuda](https://keybase.io/veritanuda) 贡献

本教程将专注于更复杂的照明设置。
请确保你熟悉 PlanarAlly 的[照明与视野系统](/zh/docs/dm/lighting-vision/)，以及它的[图层](/zh/docs/dm/layers)和棋子的[光环](/zh/docs/game/shapes/#trackers--auras)与[权限](/zh/docs/game/shapes/#access)。

在本教程中，我们想要模拟 RTS 风格（*实*时*战*略）的照明设置。
该设置**将**：

- 给玩家一张可以探索的地图，并且
- 向他们展示他们已经探索过的区域。

该设置**不会**：

- 考虑玩家实际的视线，而是使用简化方案，
- 添加只隐藏棋子但不隐藏地图的'薄战争迷雾'（PlanarAlly 无法做到这一点），或者
- 自动化这个过程。

## 概念

即时战略游戏经常让玩家面对未探索的地图。
然而，一旦侦察兵到达某个区域，地图就被揭示，任何战争迷雾只会隐藏其他玩家的单位，而不会隐藏地图。
这是一个经常被要求的功能。
尽管如此，由于各种原因，它还没有被实现到 PlanarAlly 中（还没有？）。

但很容易模拟出类似的效果。
它会有上面提到的缺点，但会给玩家提供比他们自己的视线更多的（更好的）地图方向感。

本质上，我们将

- 把地图划分成多个区域，
- 给这些区域各提供一个光源，
- 在玩家探索过该区域的时刻点亮这些区域，这样他们离开后也能看到它。

## 准备

首先，用照明和视野系统布置你的常规地图：用战争迷雾填充画布，按你喜欢的方式添加一些墙壁和灯光。

![rts-image-00](./assets/rts-image-00.png)

### 区域

然后查看你的地图，找出可以独立探索的部分。
对于常规地牢，这应该很容易，因为它已经被划分成几个房间。

现在，放置一个或多个光源（取决于区域的布局）。
这些灯应该能够照亮整个区域。
你可能只想要锋利的光环，边缘没有昏暗的光。

![rts-image-01](./assets/rts-image-01.png)

把灯光藏在*DM*图层上并/或停用光环以备后用。

## 实施

当区域应该对玩家可见时（无论是当他们进入时，还是当他们完全探索过时），打开灯。
通过激活光环（如果你停用了它）并把光源移到 `fow` 图层来实现，以点亮该区域。
还要把光源设置为*公开*，这样玩家才能真正看到它。

![rts-image-02](./assets/rts-image-02.png)

由于光源在 _fow_ 图层上，它的光环会画在 token 图层上，而形状本身保持不可见。
`fow` 图层也会剥离光环的*任何*颜色。

![rts-image-03](./assets/rts-image-03.png)

![rts-image-04](./assets/rts-image-04.png)

如果你想区分实际视线和 RTS 风格的视线，要么给玩家的视线加上一点色调，要么把光源移到*map*图层。
你可以让棋子不可见，或者用 `move to back` 功能把它藏在你添加的任何地图图片下面。
使用 `lock` 功能防止意外拖动灯光与你的小组或其他地图元素。

如果你启用了*只显示视线内的光*选项，你需要反而给所有玩家添加*视野*权限，用于你想使用的灯。
否则，一旦他们和相应区域之间有了一堵墙，他们就会失去对已探索区域的了解。
在这种情况下，你可能想事先在光源属性中为所有玩家添加访问*条目*，同时停用所有访问级别。

这样，你只需要勾选几个 <Lightbulb/> 图标就可以点亮一个区域。

![rts-image-05](./assets/rts-image-05.png)

![rts-image-06](./assets/rts-image-06.png)

注意这将不仅点亮*map*图层，还会点亮*tokens*图层。

如果你想为你的玩家隐藏敌人的移动，把他们的棋子移到*DM*图层。
