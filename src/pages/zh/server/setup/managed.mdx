# 托管

就安装设置而言，最轻松的选择无疑是使用一个为你和你的玩家提供 PlanarAlly 的在线服务。

目前我还没有资源公开托管一个 PlanarAlly 服务器，但这可能是我未来希望加入的功能。

<Warning>这些服务**并非**由我运营，因此我无法保证这些软件没有被恶意篡改。</Warning>

## 已知的服务商

_如果你托管 PA 或认识公开托管 PA 的人，欢迎告诉我！_

[Dice.Quest](https://planarally.dice.quest/)（原 dndbox.com）v2024.3 托管在瑞士/欧洲，运行着包括 PlanarAlly 在内的多个[开源项目](https://dice.quest)。支持可在 [reddit](https://reddit.com/r/dndbox/) 上获取。

[10leej.com](https://planarally.10leej.com/) v2025.1.1 托管在美国乔治亚州亚特兰大，由 10leej 提供支持，可访问[网站首页](https://10leej.com/)上的联系信息获取支持。
