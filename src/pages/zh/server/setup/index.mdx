# 安装

> 安装相关文章**只**需要 DM 阅读[^1]。

PlanarAlly 不需要每个玩家都进行安装，所以如果你是玩家，可以直接前往[这里](/zh/docs/)开始使用 PlanarAlly 或阅读完整文档。

作为 DM，你需要选择是自己托管 PlanarAlly，还是使用现有的在线服务。这两种方式各有利弊。

如果你已经知道自己想用哪种方式，可以直接前往[外部服务](/zh/server/setup/managed/)或[自托管](/zh/server/setup/self-hosting)；否则请继续阅读，了解关于这两种方式的更多信息！

## 托管方式对比

了解自行托管 PA 与使用在线服务的利弊非常重要。
为了让你有更深入的了解，我们将讨论这两种方式之间的一些差异点。

### 复杂度

与在线服务相比，自托管要复杂得多。在线服务完全无需安装，而自托管需要一些手动操作。你可能需要学习端口转发之类的知识，才能让玩家访问你的服务器。如果这些听起来让你望而却步，欢迎联系我，或者干脆选择在线服务，这样你就不用担心这些问题了。

### 灵活性

自托管虽然更复杂，但也为你提供了更大的灵活性。你可以按照自己的喜好配置服务器设置，并按需调整软件。也许你想更改某些颜色，或者在某个位置放置标志。这些在使用预配置的在线服务时都是不可能的。

话虽如此，我预计大多数人不会真正做太多修改。

### 离线支持

由于在线服务需要访问互联网，自托管是唯一支持离线使用的方式。你可以在地下室之类的任何地方启动服务器，只要玩家在同一个网络中，就能连接上来。

[^1]: 从技术上讲，任何人都可以是托管服务器的人，不一定非得是 DM
