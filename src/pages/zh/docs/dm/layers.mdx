# 图层

<Image src={LayersPicture} width={800} aspectRatio={861 / 404} alt="图层信息" />

PlanarAlly 将游戏桌面按多个图层进行组织。
这些图层相互叠加绘制。
这些图层共同构成了你在游戏时看到的结果。

这些图层各有其专门的用途。
DM 理解每一层的用途非常重要。
如需快速了解每个图层，请查看[快速参考](/zh/docs/reference/)文档。
如需更详细的内容，请继续阅读！

除了 DM 图层之外，所有图层也都会绘制在玩家的游戏桌面上。
但是，玩家只能与棋子图层上的元素进行交互。

_目前这些图层是硬编码的，但我确实预见到未来有可能根据你自己的偏好进行调整。_

## 地图

绘制堆栈的最底部是地图图层。
该图层用于放置地图、建筑布局等内容。

该图层绘制在网格图层下方。
这样你就可以将网格线与你的各种地牢对齐。
除此之外，该图层的行为与棋子图层相同。

## 网格

该图层无法手动选择，但可以通过[DM 选项菜单](/zh/docs/dm/settings/)进行配置。
该图层在屏幕上绘制网格线。

这些网格线要么是方形（默认），要么是六边形。
可以绘制平顶和尖顶两种六边形网格，但目前仅提供实验性支持。

<Warning title="实验性">
    六边形网格是实验性的，因此可能会经常出现奇怪的行为。一个例子是网格吸附仍然适用于方形网格，尽管显示的是 六边形网格。
</Warning>

## 棋子

核心游戏玩法将在此图层上进行。
这是玩家和非玩家角色移动的地方。
你通常会保持该图层处于激活状态。

## DM

该图层仅供 DM 访问。
玩家在此图层上看不到任何内容。
可用于提前规划遭遇战。
也可以用于放置文本标签，以便记住关键信息。

你还可以更改形状所在的图层。
通过在 DM 图层上隐藏玩家还不应该看到的素材，你可以确保玩家不会提前看到信息。

## FOW

该图层具有一些有助于视野的特殊行为。

在绘制墙壁时，你希望它们是静态的。
你不希望它们发生变化，因为你的玩家可能会看到他们本不应该看到的地图部分。
通过在视野图层上绘制墙壁，你可以确保在与棋子图层交互时，不会意外移动墙壁。
因此，该图层会自动为你施展两个魔法戏法。

你在该图层上绘制的大多数形状将用于墙壁或门，因此在该图层上绘制的形状会自动应用"阻挡移动"和"阻挡视野"设置。
"阻挡移动"可防止玩家穿过这些形状。
"阻挡视野"可防止玩家看穿这些形状。
如果不需要，你可以取消选择这些选项，但要知道它们会默认应用在该图层上。

在该图层上绘制的**所有内容**在其他图层上都是不可见的。
这是因为通常你的地图已经预先绘制好了墙壁。
当你绘制一个难看的黑色矩形来向照明系统标示墙壁时，你不会想在棋子图层上看到那个难看的色块。

该图层纯粹是为了方便。
如果你不喜欢自动设置或不可见特性，你可以使用棋子图层，在那里以你想要的任何设置绘制墙壁。
