# 楼层

一组完整堆叠的[图层](/zh/docs/dm/layers/)称为*楼层*。

楼层相互叠加绘制。
因此，在新创建的楼层上，其下方的楼层将完全可见。
对于游戏桌面上未被其他任何东西覆盖的每一部分，无论是*地图*图层上的素材，还是*棋子*图层上的形状，这一点都成立。

<Image src={FloorsPicture} width={300} aspectRatio={314 / 277} alt="楼层按钮及打开的楼层菜单" />

可以通过屏幕左下角的楼层按钮访问楼层。
楼层带有编号（显示在打开的菜单左侧），并且有名称（显示在右侧）。
楼层按钮始终显示你当前活动楼层的编号。

**贴心提示**：请务必查看[移动快捷键](/zh/docs/reference/#movement)，让楼层导航变得轻松自如！

在任何[地点](/zh/docs/dm/locations)中，始终至少存在一个楼层，因此在创建地点的同时，第一个楼层会自动创建。
它将被命名为 `ground`，并编号为 `0`，`0` 始终是堆栈最底部楼层的编号。

楼层按展示顺序列出，最高的楼层排在第一位。

楼层是增强沉浸感与感知力的实用工具，建议在适用时经常使用。请注意，每个楼层都会增加渲染时间。虽然有一些优化措施可以减轻这种负担（例如更高的楼层不会被渲染/计算），但还是请记住这一点。

## 创建新楼层

你可以通过点击`添加新楼层`来创建新楼层。
系统会弹出一个窗口，要求你输入楼层的名称。

<Info title="不允许重复">请注意，一个地点上不能有两个同名的楼层。</Info>

## 重新排列楼层

你可以通过将楼层拖到其他位置来重新排列楼层。楼层上的所有对象都将保持与该楼层相关联。

## 楼层操作

### 重命名

点击铅笔 <PencilAlt/> 会出现一个弹出窗口，你可以在其中输入楼层的新名称。

### 切换玩家访问权限

通过点击眼睛 <Eye/>，你可以切换玩家是否可以手动访问此楼层。

**请注意**，这并不会隐藏楼层！可能存在一个窗口，透过它可以看到该楼层。

### 删除

删除楼层就像点击打开菜单中的 <TrashAlt /> 按钮一样简单。
你需要确认删除楼层，_因为此操作无法撤销_！

删除后，该楼层将从堆栈中移出并丢弃。该楼层上的所有对象也将被移除。
