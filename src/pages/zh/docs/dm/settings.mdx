# 战役设置

作为 DM，你将拥有一个特殊的选项窗口。
这些选项让你可以配置当前战役的设置。

可以从侧边菜单访问 DM 设置（点击浏览器窗口左上角的 <Cog /> 图标以打开菜单）。

## Admin

<Image src={SettingsPicture} width={600} aspectRatio={659 / 543} alt="DM 设置" />

Admin 部分提供管理选项。

### 玩家

在玩家部分，你可以看到当前玩家的列表。
在每个玩家名字旁边，你可以设置他们在战役中的角色。

<Warning title="警告！">将任何玩家设置为 DM 会授予他们对**整个**战役的**无限制**访问权限！</Warning>

启用 <Eye /> 图标后，你将在 DM 图层上看到玩家的视口。
这样你既可以跟踪玩家正在看哪里，也可以改变他们观看的位置。

点击"踢出"可将特定玩家从你的战役中移除。

### 邀请链接

邀请链接允许你邀请玩家加入你的战役。
链接右侧有一个按钮，可将该链接复制到你的剪贴板。
按下"刷新邀请码"即可刷新链接。

### 锁定会话

"锁定此会话"按钮用于锁定或解锁战役。
锁定后，只有 DM 可以访问战役。
如果你想编辑地图，并确保在你工作期间没有任何玩家开始四处窥探，此功能会非常有用。

### 移除会话

"移除会话"将**永久性**地从 PlanarAlly 服务器上删除该战役。所有数据都将无法恢复。**请谨慎使用！**

## 网格

<Image src={GridPicture} width={600} aspectRatio={690 / 256} alt="网格设置" />

网格设置让你可以调整网格设置，甚至完全禁用网格。
这些设置是战役默认设置，可以在[单独的地点设置](/zh/docs/dm/locations/#grid)中被覆盖。

### 使用网格

启用或禁用网格。这也适用于所有玩家。

### 网格类型

PA 对方形网格提供全面支持，对六边形网格提供最低限度的支持。

六边形网格提供两种变体（尖顶和平顶），但不像方形网格那样拥有完整的功能集。
最重要的是，[吸附行为](/zh/docs/game/snapping)尚未更新以支持六边形。

### 尺寸单位

尺寸单位允许你将默认的单位表示方式从英尺（D&D 的标准）改为其他单位。
可以用来把所有内容改为米（包括分数，例如 D&D 标准的 1.5&nbsp;米等于 5&nbsp;英尺），也可以用来让某个地点拥有以公里或英里为比例的世界地图。

### 单位尺寸

单位尺寸是一个网格单元格在你游戏系统中所代表的距离。当你使用 Ruler 工具测量距离时，将使用此信息进行换算。

## 视野

<Image src={VisionPicture} width={600} aspectRatio={675 / 402} alt="视野设置" />

视野是对 DM 最重要的设置之一。
这些设置让你可以改变玩家看到的内容以及他们看到的方式。
在有关[照明与视野](/zh/docs/dm/lighting-vision/)的 DM 章节中也会引用它们。

此对话框中定义的设置是战役默认设置，可以在[单独的地点设置](/zh/docs/dm/locations/#vision)中被覆盖。

### 假玩家

启用此选项后，屏幕将不带你的 DM 权限进行渲染。
相反，它将使用你在[Vision 工具](/zh/docs/tools/vision/)中选择的所有玩家的视野进行渲染。
这可以帮助你在准备期间甚至游戏中验证你的视野设置是否正确。

你可以使用 [Quick Toggles](/zh/docs/tools/quick-toggles/#fake-player) 快速打开/关闭此选项。

### 用 FoW 填满整个画布

_FoW 代表战争迷雾（Fog of War）_

启用此选项后，屏幕上的所有内容默认对玩家隐藏。
需要添加灯光才能为区域提供视野。

禁用此选项后，屏幕上的所有内容默认对玩家可见。
需要添加战争迷雾才能移除区域的视野。

### 仅 LoS

_LoS 代表视线（Line of Sight）_

此选项可切换一种高级照明模式。

禁用时，屏幕上每个有光源的地点都是可见的。
无论该地点是否有玩家，都是如此。

启用时，只有玩家棋子视线内的东西才会显示在屏幕上。
玩家需要能看到光，光才会显示在屏幕上。

有关此主题的更多信息，请参阅[照明文档](/zh/docs/dm/lighting-vision/)。

### FoW 不透明度

此设置允许 DM 选择隐藏区域对于 DM 而言的不透明度。
玩家自己始终会将该设置视为 1.0，并且无法编辑。

在假玩家模式下，你也会被固定在 1.0。

### 视野模式

<Warning>这是一个技术性设置，只有在你知道自己在做什么时才应该碰它。</Warning>

实验性视野模式与默认版本相比，计算照明/视野的方式不同。

在实验性版本中，照明/视野的更改是增量进行的，而不是每次更改都进行完全重新计算。好处非常明显，但后果是它受到的测试较少，而且在出错的情况下可能会完全卡住。

如果你的地图上有很多与照明/视野相关的对象，并且在移动东西时屏幕更新缓慢，你可以考虑使用此选项。

### 最小/最大视野

这些设置是[视野系统](/zh/docs/dm/lighting-vision/)的调节因素。
它们决定了所有棋子的视野限制。

假设有一大片开阔的场地，绵延 5000 英尺，并且完全被照亮。
你可能会认为站在场地中央的棋子能看到整个区域。
然而，人类和非人眼都存在局限性，因此引入了这些设置。

在最小视野范围内的一切都可以照常看到。
超过最大范围的一切都不可见，属于战争迷雾。  
介于两者之间的内容，随着你向视野边缘靠近，会以逐渐增加的不透明度显示。
