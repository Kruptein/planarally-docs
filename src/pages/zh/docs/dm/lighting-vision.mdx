# 照明与视野

在本节中，我们将介绍作为 DM 的你如何为地牢带来更多生机，并为玩家提供动态的体验！

_如果你想看一个实操示例，请查看[首次游戏教程](/zh/learn/dm/first-map/#setting-up-a-light)！_

正如标题所示，PlanarAlly 中有两个核心概念决定了你的玩家如何看待游戏桌面的状态。

通过在地图的某些位置添加灯光（或黑暗），你可以立即为场所增添更多个性；此外，你还可以在某个角色的身上放置火把，从而获得更强烈的深入地下城的体验。然而，在整个地图上布置灯光，会让玩家还在入口处时就提前看到一些很酷的地点。为了防止这种情况，需要考虑某个角色的视野，而一旦做到这一点，我们就能获得非常沉浸式的体验。

我们首先会介绍一些照明设置，最后再讨论视野如何运作。

## 照明

在 PlanarAlly 中，我们可以实现不同程度的复杂度，根据你想要如何运行游戏，你会选择不同的方法。

还有一个与照明相关的 DM 设置，名为"用 FOW 填满整个画布"，你可以在"视野"选项卡中找到它。该设置决定整个屏幕默认是否被迷雾覆盖。

<Warning>强烈建议，如果你想使用视野系统，请用迷雾填满整个屏幕。目前没有迷雾的视野系统行为 不太正常。</Warning>

### 魔法光与魔法黑暗

第一种照明就是我所说的"魔法"照明，因为它非常强大：魔法光无法被隐藏，魔法黑暗也无法被普通光照亮。

虽然听起来很令人兴奋，但我实际上很少使用这类光，因为它非常静态。我确实会用它来处理一些边界情况。

#### 使用方法

作为 DM，如果你选择 Draw 工具，你会看到顶部有一个模式切换。当设置为"显示"时，你将绘制魔法光；当设置为"隐藏"时，你将绘制魔法黑暗。

所有在"显示"或"隐藏"模式下绘制的形状都会自动绘制在视野（fow）图层上！因此，如果你犯了错误或想移除某些内容，请前往视野图层进行修正！

#### 使用时机

有时你可能想快速向玩家展示屏幕的某个部分，而不必让他们四处移动。也许你想在默认被迷雾覆盖的整个屏幕上始终显示指南针。或者，也许你有一个没有迷雾的白天场景，但希望确保建筑物内的内容直到最终决战时才被揭示。

另一个典型用例是，作为 DM，你想在玩家前进时授予他们视野，让他们走过的所有地方保持可见。通过结合"用迷雾覆盖一切"选项，然后在"显示"模式下用画笔绘制，你可以轻松地为玩家绘制出一条路径。

### 普通灯光

更常见的照明用途是在地图上放置灯光。你可以将光源附加到任何素材上，它会从素材的中心向外辐射。这些灯光能够穿透普通迷雾，但无法穿透上述魔法迷雾。

#### 使用方法

通过右键单击素材并选择"编辑属性"来打开素材属性。找到标题为"光环"的部分，然后开始填写新的一行。

更多信息请参阅[光环](/zh/docs/game/shapes/#auras)文档。

不过，请务必把你的光环标记为光源！

<Tip title="隐藏光源">
    光源始终附加在形状上。如果你想对玩家隐藏该形状，但仍显示其灯光效果，请将其移动到 `fow` 图层
    ——或者，如果你需要显示光环的颜色，则可以将其设置为不可见。
</Tip>

#### 使用时机

在大多数情况下，这是为场景添加灯光的推荐方式。将光源附加到棋子上，当棋子移动时就会立即产生动态照明，之后再与视野结合，就构成了强大的组合。

## 视野

到目前为止，我们已经为场景添加了一些灯光和/或迷雾，但没有任何东西阻挡这些灯光，因此它们会穿过地图上的墙壁，除非你精心微调每一盏灯——这可不是什么有趣的事。

因此，PlanarAlly 让你可以指出地图上墙壁、门和其他障碍物的位置，以便 PA 能够正确评估灯光应如何表现。

### 阻挡光线的物体

向 PA 提供墙壁等信息的关键在于，像平常一样绘制形状，然后在形状的属性对话框中选择"阻挡光线"选项。由于在准备阶段经常需要绘制这些形状，PA 提供了一个专门的视野图层（FOW），会自动在该图层上绘制的每个形状上应用"阻挡光线"（和"阻挡移动"）选项。有关该图层的更多信息，请参阅[图层文档](/zh/docs/dm/layers/)。

你可以使用任何可用的形状来绘制建筑轮廓，但有些形状比其他形状更有用。虽然矩形对于具有 90 度墙壁的简单结构很有用，但我发现这些天我几乎只用多边形工具。有关这些形状行为方式的更多详细信息，请参阅[Draw 工具文档](/zh/docs/tools/draw/)。

<Info>这只会阻挡普通灯光。"魔法"光可以穿透任何非魔法迷雾。</Info>

### 视线

要完成照明与视野的设置，我们还需要讨论的最后一个设置，就是 DM 设置中的视线设置。

在不启用此设置的情况下，灯光会照亮房间，并正确地在墙壁边缘停止。但我们无法判断角色能看到什么。所有有光源的房间都将是可见的，无论房间里是否有玩家。

当你在 DM 设置中启用视线设置时，PlanarAlly 会考虑玩家角色的位置，只向玩家显示棋子实际可见的灯光。

<Warning>
    此设置只会考虑至少一位玩家具有**视野访问权限**的素材。如果某位玩家没有任何具有视野访问权限的棋子，
    则该玩家将**没有视野**。
</Warning>

## 最小/最大视野

这些可以在[战役设置](/zh/docs/dm/settings/)中进行设置。
这些设置的行为很像光环，但只是*限制*所有棋子的视野，而不是在地图上发出光芒。

<Warning>这只会影响被战争迷雾覆盖的画布。</Warning>

一个棋子将能像平常一样看到*最小视野*范围内的所有东西。
然而，它将*无法*看到*最大视野*范围之外的光源。
位于最小视野与最大视野之间的每个光源，都会被调暗，就像昏暗的光环一样。

<Info>这只会阻挡普通灯光。`魔法光可以穿透任何非魔法迷雾。</Info>
