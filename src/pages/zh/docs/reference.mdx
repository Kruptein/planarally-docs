# 快速参考

## 默认图层

有关图层的更多信息，请查看[图层文档](/zh/docs/dm/layers/)。

| 名称   | 玩家可见 | 玩家可编辑 | 简要说明                                  |
| ------ | -------- | ---------- | ----------------------------------------- |
| Map    | 是       | 否         | 网格下方的图层，通常用于地图素材          |
| Grid   | 是       | 否         | DM 也无法选中，但可以在会话设置中进行配置 |
| Tokens | 是       | 是         | 主游戏桌面                                |
| DM     | 否       | 否         | 供 DM 放置对玩家隐藏物体的地方            |
| Vision | 是       | 否         | 此图层上的所有形状在其他图层上都不可见    |

## 快捷键

在 Mac 上，请使用 `Command` 代替 `Ctrl`。

### 移动

相当大一部分快捷键用于移动形状或屏幕。

| 键/修饰键                  | 上下文 | 操作                                           |
| -------------------------- | ------ | ---------------------------------------------- |
| 方向键、小键盘 1-4、6-9    | 空选择 | 将游戏桌面朝按下的方向移动 1 个网格格          |
|                            | 选择   | 将选中的形状朝按下的方向移动 1 个网格格        |
| 空格、小键盘 0             |        | 将屏幕居中到下一个棋子（循环切换你拥有的棋子） |
| Shift                      | 选择   | 让形状穿过阻挡移动的地形（仅限 DM）            |
| Ctrl + 0、小键盘 5         |        | 聚焦网格原点 (0,0)                             |
| 小键盘 5                   | 选择   | 聚焦选择的中心                                 |
| 鼠标中键（按住）           |        | 平移屏幕                                       |
| 鼠标中键滚动               |        | 相对于当前鼠标指针缩放                         |
| Page up/down               |        | 将相机楼层向上/下移动                          |
| Page up/down + alt         | 选择   | 将选择向上/下移动楼层                          |
| Page up/down + shift + alt | 选择   | 将选择与相机同时向上/下移动楼层                |

### 行为

| 键/修饰键        | 上下文 | 操作                                    |
| ---------------- | ------ | --------------------------------------- |
| Tab              |        | 切换模式（Build/Play）                  |
| Alt（按住）      |        | 禁用[吸附行为](/zh/docs/game/snapping)  |
| Ctrl + u         |        | 切换 UI                                 |
| Ctrl + z         |        | 撤销                                    |
| Ctrl + shift + z |        | 重做                                    |
| n                |        | 打开[笔记管理器](/zh/docs/game/notes)   |
| 空格             | ruler  | 设置[ruler](/zh/docs/tools/ruler)路径点 |

### 选择 / 形状交互

| 键/修饰键      | 上下文 | 操作                                    |
| -------------- | ------ | --------------------------------------- |
| Enter          | 选择   | 打开形状的编辑对话框                    |
| Ctrl           | 选择   | 通过 Ctrl-选择形状来扩展当前选择        |
|                | 缩放   | 保持宽高比                              |
| 空格           | 选择   | 设置[ruler](/zh/docs/tools/ruler)路径点 |
| Del、Backspace | 选择   | 删除当前选择中的所有形状                |
| d              | 选择   | 取消选择当前所有已选中的形状            |
| x              | 选择   | 将形状标记为被击败                      |
| Ctrl + l       | 选择   | （取消）锁定选中的形状                  |
| Ctrl + c       | 选择   | 将选择复制到剪贴板                      |
| Ctrl + v       |        | 将剪贴板粘贴到游戏桌面                  |
