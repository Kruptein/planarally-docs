# 素材

<Image src={DashboardAssets} alt="仪表盘素材" />

**素材**部分允许你管理或创建可在战役中使用的素材。
_请参阅 [DM 素材](/zh/docs/dm/assets/) 章节了解如何使用它们_。

<Info>目前素材只对 DM 有用。将来这里也应该成为玩家可以上传素材的地方。</Info>

右上角有一个小型操作栏，允许你创建文件夹、上传新素材或移除当前选中项。

## 浏览文件夹

主界面是一个文件夹浏览器，你可以双击进入某个文件夹。
你当前所在的文件夹路径会以面包屑导航的形式显示在“管理素材”（MANAGE ASSETS）标题正下方。

要返回上一个文件夹，你可以双击“..”文件夹[^1]。
你也可以点击面包屑导航中的任意一段，一次返回多个文件夹。

## 上传素材

素材可以通过点击操作栏中的添加文件图标上传，也可以直接将素材拖拽到素材管理器中。

## 移动素材

你可以通过将素材拖拽到目标文件夹来移动它们。
因此，如果你想把素材向上移动一层，只需将其拖到“..”文件夹上即可。

你可以一次移动多个素材，既可以拖拽包含多个素材的文件夹，也可以先选中多个素材。

## 选择素材

单击某个素材会将其选中，并取消选中所有其他素材。

如果你想扩展选区，可以使用 ctrl+点击或 shift+点击。
前者只会将点击的文件加入选区，
而后者会将上次选中的文件到新选中的文件之间的所有文件全部加入选区。

<Info>
    目前的行为是旧版素材管理器遗留的，模仿了常见文件浏览器的操作习惯。

    不过，当前选区的显示方式使它有些不符合直觉。
    因此这在将来可能会有所改变。

</Info>

[^1]: 这是源自 unix 世界的概念。
