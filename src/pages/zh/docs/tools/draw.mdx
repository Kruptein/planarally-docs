# 工具 Draw

Draw 工具可以在屏幕右下角的工具栏中访问，所有玩家都可以使用，但只能在 [Build 模式](/zh/docs/tools-overview/#toolbar-and-modes) 下使用。

它可以让你在游戏桌面上绘制形状，并分为三个部分：形状、视野和逻辑。

## 形状设置

在形状设置中可以选择所需的形状，以及该形状的一些常见基本属性。

大多数形状都提供填充色和/或边框颜色的设置。

### 矩形

_矩形_ 是最简单的形状之一。按住鼠标时，会显示一个预览，告诉你释放鼠标后矩形会是什么样子。

### 圆形

与矩形一样，_圆形_ 也非常简单。绘制出的圆形将以你按下鼠标的位置为中心，半径由你释放鼠标的位置决定。

### 多边形 / 线条

_多边形 / 线条_ 可能是最复杂的形状，但它提供了最大的灵活性。

与所有其他形状不同，绘制时你无需一直按住鼠标按钮。相反，每次你点击游戏桌面上的某个位置，就会出现一个新点，并有一条线将其与上一个点连接起来。你可以自由地交叉或重复使用已存在的点。

要表示形状已完成，目前需要使用鼠标右键。要取消绘制，可以按 Escape。

如果你勾选了"闭合多边形"复选框，在完成形状时，最后一个点和第一个点会自动连接，多边形将用填充色填充。

### 画笔

另一种绘制模式是 _画笔_，这是一个自由绘制的选项，让你可以绘制任何你想要的内容。

<Warning title="性能">
    请注意，使用 _画笔_ 绘制时需要大量点来表示一个形状。通常只建议用于小物件，因为它在性能方面的表现相当差。
</Warning>

### 文本

最后一种可用的绘制模式是 _文本_。
在绘制之前请先设置好字号，因为之后你将无法再更改大小本身。
不过，你之后可以自由缩放文本对象。

与其他绘制模式不同，绘制文本不需要拖动，而是只需单击一次。
这将会打开一个弹出窗口，询问要显示的文本。

输入的文本将以用于简单棋子的衬线字体渲染，_以第一步中点击的点为中心_。
它可以像任何其他形状一样被拖动、调整大小等。

<Tip title="编辑">你可以在形状属性对话框中事后编辑文本！</Tip>

## 视野设置

视野设置允许你预先配置所绘制形状的照明和视野设置。

当切换到战争迷雾图层或从中切出时，阻挡设置会自动切换，
但你可以根据自己的需要自由修改它们。

当至少启用一个阻挡设置时，该工具的 <Eye /> 图标会显示橙色背景作为视觉提醒。

### 仅限 DM 的模式

DM 还可以在此部分选择额外的视野绘制模式。

_普通_ 模式如预期那样是默认行为。

_揭示_ 和 _隐藏_ 将分别绘制"魔法光芒"或"黑暗"。
更多信息，请参阅[关于魔法光芒与黑暗的文档](/zh/docs/dm/lighting-vision/#magical-lights-and-darkness)。

_擦除_ 将创建一个作为（可移动的）"洞"来使用的形状，穿透绘制堆栈中位于其 _下方_ 的所有对象，包括[楼层](/zh/docs/dm/floors/)！
一个被 _擦除_ 的形状会自动放到[地图图层](/zh/docs/game/gameboard/#map)上，但也可以移动到任何图层。

有关擦除模式的更多信息，请参阅 [0.26 版本说明](/zh/blog/release-0.26#erase-floor-mode-dm)。

## 逻辑设置

这允许你为形状预配置门逻辑。

当你在绘制墙壁和门时，这可以节省大量时间！

更多信息，请参阅[形状逻辑](/zh/docs/game/shapes/#logic)。
