# 工具 Map

Map 工具可以在游戏桌面右下角的工具栏中访问，但只能在 [Build 模式](/zh/docs/tools-overview/#toolbar-and-modes) 下使用，且只有 GM 可以使用。
它提供了一种简单易用的方法，让自定义形状贴合网格。
它可以用来调整任意形状的大小，但它的核心用途是针对地图的。

要使用 Map 工具，首先需要选中一个形状。
如果没有选中形状，Map 工具会提示你，并且你可以在 Map 工具内部直接选择形状，而无需切换到 Select 工具。

如果选中了形状，你就可以在此形状中选择一个区域作为参考，或者缩放整个图像。
请注意，无论哪种方式，整个图像都会被缩放。
"缩放整个图像"只是把整张图像作为参考，而不需要单独选择一部分作为参考。

## 选择区域

选择区域的方式是在其周围拖出一个方框。
例如，你可以选择一个应在网格上占据 3 乘 3 区域的区域。
在初次选择之后，你可以调整并进一步微调这个选择区域，以确保它正好覆盖你想要的区域。

如果选择区域合适，你可以输入所选区域应占据的 X 和 Y 尺寸，然后按 apply。

## 缩放整个图像

"缩放整个图像"会把整张图像作为缩放的参考。
这可以通过设置目标网格单元格或目标像素来完成。
以网格单元格为目标会让图像覆盖指定数量的网格单元格，而以像素为目标则会根据输入调整图像大小。
两种方式都可以通过连接输入框右侧的"链接"符号来保持图像的宽高比。
