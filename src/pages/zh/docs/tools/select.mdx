# 工具 Select

Select 工具是最常用的工具之一。
顾名思义，它的用途是选择游戏桌面上的一个或多个形状，同时也可以进行移动。
所有玩家都可以通过屏幕右下角的工具栏访问它，但其行为会因当前[模式](/zh/docs/tools-overview/#toolbar-and-modes)而异。

此外，在 Build 模式下，它还允许你旋转和调整形状大小。

## 选择基础

你可以单击单个形状，或者拖出一个方框圈住一组形状，以便将它们一起移动。

要向现有选区添加形状，请按住 `Ctrl` 并选择新的形状。

要取消选择形状，只需在游戏桌面上的空白处单击，或使用键盘快捷键 `d`。

_进行批量选择时，只会选中你实际拥有的形状。这与普通的单击行为不同，后者也可以选中非你拥有的形状。_

## 移动

你可以通过在桌面上直接拖拽来移动你的选区。

DM 可能会将某些物体定义为不可通行（例如一堵墙）。
这些物体会阻止移动。
DM 和所有副 DM 可以在按住 `shift` 键的同时忽略移动限制。

在工具栏中启用 `select` 工具按钮上方的 `show ruler` 开关后，拖动物体时还会显示一条标尺，用于测量移动的距离。
该标尺与[独立的 Ruler 工具](/zh/docs/tools/ruler/)工作原理相同，并且会共享其设置。

## 调整大小

_要调整形状大小，你必须处于 'build' 模式_

调整大小只需抓住形状的一个角并拖动到其他位置即可。
大多数缩放操作只会影响被拖动的角，其余角保持不动。

目前唯一的例外是圆形，它在缩放时会增大/减小半径。
这种行为将来可能会改变。

## 旋转

_要旋转形状，你必须处于 'build' 模式_

Build 模式中会显示一个特殊的旋转界面，包含一个锚点和一个方框。

当你移动锚点时，整个方框会围绕其中心点旋转。

旋转形状不仅限于单个形状，也可以应用于整个组。
请记住，方框的中心将用作旋转点。

## 选择顺序

游戏桌面上的形状按一定的顺序绘制，这个顺序决定了形状重叠时应选择哪个形状。

你可以通过右键单击某个形状并将其移动到堆叠的底部或顶部来更改顺序。
