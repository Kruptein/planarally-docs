# 工具 Spell

所有玩家都可以通过屏幕右下角的工具栏访问 Spell 工具，但只能在 [Play 模式](/zh/docs/tools-overview/#toolbar-and-modes)下使用。

它与 Draw 工具有一些相似之处，但专门用于在游戏过程中施放法术。

你可以选择法术形状（正方形/圆形/锥形），并配置其大小、范围、颜色，以及你的法术是否与其他玩家共享，还是仅供自己使用。

在法术形状列表中明显缺少的是直线，而直线在施法中是一种常见的模式。
我们认为现有的 Ruler 工具在这里已经足够，没有必要为 Spell 工具增加额外的冗余功能。

## 基本操作

除非范围设置为 0，否则当 Spell 工具处于激活状态时，你的法术将始终跟随鼠标。

默认的法术模式仅用于快速测量，例如查看你能命中多少人。
如果你切换工具，法术就会消失。

如果你有一个不是即时生效、而是会在战场上停留更长时间的法术，你可以**左键单击**将其变为真实的形状。
你会自动切换到 Select 工具。

如果你误点击了，或者法术效果已结束，你可以像删除其他形状一样删除该法术。
还要注意，如果你关闭了 'show public'，那么在你 '施放' 法术的那一刻，它就会获得 'invisible' 属性！
施放后没有什么能阻止你移除该属性。

右键单击也会让你返回到 Select 工具，但不会施放法术。
这是作为 '取消' 操作提供的。

## 选择上下文

锥形和范围参数只有在主动选中某个形状时才可用。

前者是因为我找不到任何不以自身为目标施放的锥形法术的例子，
也是因为我在非自我施法的情况下，对旋转相关的用户体验（UX）有些难以想象。

后者是因为否则就没有参考点。

## 大小

大小参数决定法术覆盖的区域。
对于正方形来说，它是一条边的长度。
对于圆形和锥形来说，它是法术的半径！

就像光环一样，这些数字是以配置的单位大小定义的，默认为 5 ft.（参见 DM 网格设置）。

## 范围

_如上所述，只有在你选中了一个活动形状时，才能配置法术的范围。_

如果范围设置为 0，则假定为自我施法，法术会自动以你选中的形状为中心。

如果范围是任何大于 0 的数字，则会显示一个黑色圆圈，其半径等于配置的范围。
