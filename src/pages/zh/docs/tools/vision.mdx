# 工具 Vision

Vision 工具可以在游戏桌面右下角的工具栏中访问，在两种[模式](/zh/docs/tools-overview/#toolbar-and-modes)下都可用。
它有助于追踪多个棋子的视野。
它对玩家和 DM 的行为是不同的。

## 玩家

如果点击，Vision 工具会打开一个列表，列出所有为玩家[配置了视野权限](/zh/docs/game/shapes/#access)的对象。
默认情况下，它们会在列表中显示为活动状态，以彩色背景标示。
所有模式和工具都只会显示那些在 Vision 工具中拥有*活动*条目的棋子的视野。

点击后，条目将被停用，现在显示灰色背景。
同时，该棋子的视野将不再显示在游戏桌面上。

## DM

默认情况下，DM 总是能看到一切。
仅使用 Vision 工具并不会改变这一点。
不过，他们可以[冒充玩家](/zh/docs/dm/settings/#fake-player)来达到与上述类似的效果。
在这种情况下，他们使用 Vision 工具来定义想要查看哪位玩家的视野。
