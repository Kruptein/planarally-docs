# 工具 Ruler

Ruler 工具可以在游戏桌面右下角的工具栏中访问，与[模式](/zh/docs/tools-overview/#toolbar-and-modes)无关。
它是一个简单的工具，让你可以测量距离。

从你点击的位置开始会画出一条线，并显示到鼠标光标的距离数字，直到你松开鼠标。
途中按 `space` 可以设置途经点，这样你就可以轻松测量绕过物体的距离。
它显示一位小数，以支持在采用英制单位设计的游戏中使用公制系统（例如 D&D 中的标准 5 英尺网格换算为 1.5 米）。

如果你打开工具栏中 `Ruler` 按钮上方出现的 `Share with others` 选项，这条线将对该会话中的所有玩家**公开**可见。
如果你关闭此选项，则只有你自己能看到尺子。
此设置也会被 [Select 工具](/zh/docs/tools/select/) 内置的尺子所使用。

绘制所用的颜色可以由每个玩家在自己的[客户端设置](/zh/docs/game/settings/)中选择。
尺子还具有[吸附行为](/zh/docs/game/snapping/)，会尝试吸附到网格上的逻辑位置。
