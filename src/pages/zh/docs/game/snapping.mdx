# 吸附

PlanarAlly 中的许多元素都具有某种形式的吸附行为。
存在两种吸附类型：吸附到网格和吸附到点。

吸附到网格相当不言自明，如果你四处移动形状，你通常希望它们正确放置在网格上。
通过使用网格吸附，你无需非常精确，PlanarAlly 会为你完成这项工作。

第二种吸附形式是吸附到另一个现有点的能力。
这里的点定义为现有形状的点，例如矩形的角或多边形中的点。

默认情况下吸附处于启用状态，并作用于大多数操作（例如移动/调整大小/旋转）。
你可以在操作期间按住 `alt` 修饰键来禁用特定操作的此行为。

如果你想永久禁用它，可以在[客户端设置](/zh/docs/game/settings/)中反转该行为，这会使 `alt` 键充当启用吸附的修饰键。

## 示例

绘制多边形时，每次点击的点都会尝试吸附到附近的网格点或现有点。

调整点的大小时，它会尝试吸附到网格点或现有点。

旋转形状时，旋转会吸附到 45 度的倍数。
