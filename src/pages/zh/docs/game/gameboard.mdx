# 游戏桌面

这里是 PlanarAlly 的核心。
游戏中，你将主要与游戏桌面交互，在地图上移动棋子，地图会显示（或不显示）你角色的周围环境以及周围的其它 PC 和 NPC 角色。

<Warning title="巨大的红色边框">
    你执行的大多数操作都必须与服务器同步。如果连接因任何原因断开，屏幕周围会出现一圈粗红色边框来警告你。断线期间所做的任何更改都可能丢失。
</Warning>

## 概览

本文档对地点、楼层和图层这几个概念做了简要的技术性介绍。
这不是玩家的必读内容，但可能让你对某些系统的行为有更多了解。
作为 DM，DM 章节中有关于这些概念的更深入信息。

PlanarAlly 使用 3 个概念来组织战役。一个战役包含 1 个或多个**地点**，每个地点由 1 个或多个**楼层**组成，而每个楼层又由一组固定的**图层**组成。
所有这些共同构成了一个场景，并绘制在屏幕上供你交互。

作为玩家，你通常无法更改活动地点、楼层或图层，
但每当你移动形状时，你仍然会与这些概念打交道。

## 地点

组织结构的顶层是地点的概念。
一个战役至少有 1 个地点，也可以有多个地点。

可以将地点看作游戏世界的一个特定实例。
它可以是队伍正在探索的特定建筑，也可以是村庄的更高级视图，甚至是世界地图。

玩家在任意时刻都只会与恰好 1 个地点交互，但 DM 可以在玩家们穿行于世界时移动他们。

更多信息请参阅[关于地点的 DM 文档](/zh/docs/dm/locations/)。

## 图层

当你加载一个地点时，一些内容必须绘制在你的屏幕上。
你期望看到地图、你的角色棋子，也许还有一些光线或阴影。

尽管所有这些内容看起来都在同一个 2D 平面上，但 PlanarAlly 实际上会将多个**图层**堆叠在一起。

作为玩家，你只能与 _tokens_ 图层交互。
这是你移动棋子和绘制的形状的主要图层。

玩家还可以看到一些其它图层，但无法交互：地图图层和网格图层是最明显的例子。
这两个图层都渲染在 tokens 图层下方。

还有一些图层对玩家完全不可见。
例如 DM 图层只对 DM 可见，可用于隐藏秘密，直到它们变得相关为止。

关于不同图层的更深入解释，请查看[DM 文档](/zh/docs/dm/layers/)！

## 楼层

仅仅有地点和图层，我们就已经可以开始游戏了。
然而 PlanarAlly 还有一个额外的妙招。

一组图层称为一个**楼层**。
一个地点总是至少有 1 个楼层，但可以扩展为多个楼层。

当你探索一座阴森的宅邸时，你必定会上下楼梯。
当你走上楼梯时，你自然不希望 DM 花费太多功夫把你的棋子移动到该楼层的地图上。
也许可以使用另一个 PA 地点，或当前地点中的另一个区域，但这太笨拙了。

PA 楼层是一种工具，让 DM 能够更流畅地组织这类事情。
就像真实的建筑一样，PA 楼层是相互叠放在一起渲染的，因此你也许能看到你所在楼层下方的楼层。

一个常见的例子就是窗户、阳台，甚至是地板上的洞。
所以如果你的视线没有任何阻碍，你仍然可以看到下面楼层发生的一些事情（例如从窗户往下看时）。

如果 DM 允许你手动切换楼层，你可以在屏幕左下方的菜单中访问它们，或使用其中一个快捷键。
请注意，根据[照明](/zh/docs/dm/lighting-vision)以及你是否拥有该楼层棋子的足够权限，你可能无法看到另一楼层上的所有内容。
