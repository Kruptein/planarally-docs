# PlanarAlly 文档

PlanarAlly 是一款开源的虚拟桌面，你可以自托管并在没有网络连接的情况下运行。
本文档涵盖以玩家或 DM 身份使用 PlanarAlly，以及自行托管服务器。

## 核心功能

**照明与视野** —— 战争迷雾、动态光源和视线，让玩家只能看到他们的角色所能看到的内容。
[文档 →](/zh/docs/dm/lighting-vision/)

**图层、楼层与地点** —— 将地图元素叠放在图层中，把建筑拆分成楼层，并在各地点之间整理场景。
[概览 →](/zh/docs/game/gameboard/)

**素材与模板** —— 上传地图和棋子，将它们整理到文件夹中，并保存形状预设以供复用。
[文档 →](/zh/docs/dm/assets/)

**工具** —— Ruler、Draw、法术区域、先攻跟踪等等——在 Build 和 Play 模式下均可使用。
[概览 →](/zh/docs/tools-overview/)

**笔记** —— 战役笔记，支持搜索、标签，并可选择附加到形状上。
[文档 →](/zh/docs/game/notes/)

**自托管** —— 运行你自己的服务器，完全掌控你的数据。设置完成后可离线使用。
[设置指南 →](/zh/server/setup/)
