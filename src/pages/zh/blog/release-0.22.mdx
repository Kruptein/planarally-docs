距离上一个版本发布已经过去两个多月了，我们早就该更新了！
这个版本没有很多新功能，但有一个重磅功能：旋转！
这个版本中的其他内容包括一系列性能改进、一些楼层的 QoL 更改，以及一些较小的更改和修复。

## 旋转

旋转形状是一个经常被要求的功能，原因显而易见。
不过，这是一个更偏技术性的更改，需要对绘制逻辑的核心进行一些调整，但最终都解决了。

旋转在 Select 工具中完成，但只能在 Build 模式（就像调整大小一样）。
当你进入 Build 模式时，会出现一个旋转专用 UI（一条带球体的线）。
抓住球体并移动，就可以围绕形状中心自由旋转。

当选中多个形状时，旋转 UI 将围绕整个组绘制，并允许一次性旋转所有形状。
这次旋转同样是围绕这个旋转框的中心进行的！

此外，当你使用吸附时，旋转会吸附到整洁的 45 度角。

## 楼层 QoL 改进

我真的很喜欢楼层功能，但仍有一些较小的痛点，我希望在这里解决。

### 可访问性

DM 现在可以切换楼层的可访问性。具体来说，他们可以阻止玩家手动前往某个特定楼层。

**这不会阻止在实际游戏场地中看到某个楼层**（例如，上层楼层的玩家透过窗户看到下面的草地）

### 重命名

楼层现在可以重命名了，太棒了。

### 显示顺序

弹出菜单中楼层的显示顺序现在被反转了。现在遵循更合理的顺序，最顶部的条目是最高楼层。

### 重新排序

现在还可以通过拖拽来重新排序楼层。这样你就不再需要预先规划好一切，或手动移动一堆东西了！

### 迷雾 bug

下层楼层被添加了不必要的迷雾，使它们变得更暗。

## 性能改进

进行了一系列性能调整，应该会产生很大的影响！

### 启动时间

WebSocket 处理的一些更改使客户端现在对服务器数据的响应快得多，这反过来应该会体现在所有地图更快的视觉加载上。

此外，楼层现在在启动时分别加载，最后访问的楼层会先加载。
这应该能显著改善楼层较多的地图的首次渲染时间。

整个 UI 中使用的 Fontawesome 图标现在通过一个 vue 库加载。过去，所有图标都通过 fontawesome.js 脚本加载，现在我们只加载实际使用的图标，节省了大量数据！

游戏循环现在只在第一个楼层到达时启动，从大局来看这是一个相当小的改进，但无论如何都是一个不错的改进。

### 其他

另一个重大改进是形状移动。组移动的处理更高效，每次形状移动所需的数据也更少。

最后一个改进是，平移会延迟更新不可见的楼层，直到平移操作结束，这同样有利于楼层较多的地图。

## 其他

- 选择 UI 中现在有锁定/解锁切换图标
- Ruler 距离的可读性得到改进
- 网格像素大小现在是一个客户端功能，允许玩家根据他们使用的显示方式选择该值（例如投影仪 vs 笔记本电脑屏幕）

## Bug 修复

- 棋子位于可见画布之外时光环不显示
- Firefox 中打开左侧菜单时的位置滚动条
- 一些严重的性能瓶颈
- 如果客户端未在启动前构建，服务器现在会退出并提示查看文档/教程
- 优先使用吸附点而非网格吸附
- 移除左上角菜单 UI 中的白色图标
- 用键盘移动多边形时只会移动原点
- 三角剖分中的退化情况
    - 三角剖分代码在处理 1e-15 量级的微小数字差异时可能遇到退化情况
    - 现在三角剖分代码只会考虑小数点后的前 10 位，以防止数值不稳定。
- 某些情况下不会触发 mouseleave 事件（例如 alt tab），这可能导致某些形状（如 Ruler）残留在屏幕上
- Map 工具调整大小不会同步
- 带重复点的多边形中心计算
- 移动到其他地点的形状现在会在旧地点正确消失
