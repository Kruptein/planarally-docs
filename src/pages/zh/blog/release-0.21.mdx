本次发布我们带来了一些新的形状属性、出生点系统、翻译、一批生活质量改进，以及和往常一样的多项 Bug 修复。

## 形状

形状属性新增了一些好东西，同时移动时的碰撞检测也得到了改进。

### 隐形开关

现在可以将形状标记为隐形。对于所有没有该形状视野权限的玩家来说，它将是不可见的。
有视野权限的玩家则能正常看到该形状。

这对于隐形使魔之类的东西特别有用，对各种发光物体也是如此。
后者之所以有趣，是因为隐形开关不会作用于这些隐形形状的灵气。
如果你想在场景中添加一盏灯，又不想让玩家看到发光来源的难看圆圈，这就非常理想。

### 锁定开关

另一个新开关是锁定开关，启用后棋子将无法被移动和/或调整大小。
这对 DM 特别有用，可以确保不会意外移动地图或照明边界。

还有一个快捷键（ctrl + L），它对更大的选区同样有效，这样你就不必为每个形状单独打开属性面板。

需要注意的是，锁定的形状不会包含在选区中，除非所选区域内只有锁定的形状。

### 移动权限

在上个版本中，权限部分新增了"仅视野"权限，适用于不允许编辑形状但可以查看其私有视野的其他玩家。

本次发布增加了一个额外的权限，允许其他用户移动形状。

### 碰撞改进

与墙壁的碰撞箱碰撞检测一直非常严格，有时甚至过于严格（由于微小的舍入误差）。
这在游戏中试图穿过狭窄走廊或门时会造成不愉快的体验。

从本次发布开始，用于碰撞检测的碰撞箱在移动时会小得多，带来更流畅的游戏体验。

## 出生点

本次发布引入了一个新概念：出生点。
这是 DM 的功能，决定棋子切换地点时会出现的位置。

现在 DM 图层上总会有一个特殊的形状，DM 可以自由移动它（也可以在各楼层之间移动）。
当 DM 将棋子移动到其他地点时，棋子会出现在上述出生形状的中心。

目前每个地点只限制一个出生点，但未来将支持多个出生点。

## i18n

国际化（i18n）已加入到代码库中，这意味着现在可以开始进行翻译工作。在撰写本文时，已有中文和德语翻译。

登录界面中有一个语言选择元素，可以在当前支持的语言之间切换。

## 生活质量改进

本次发布包含了一系列较小的生活质量改进。

### Build/Play 模式

最显著的变化之一是新的"工具模式"。随着每个版本的发布，工具栏变得越来越庞大。
此外，有些工具在大多数游戏会话中并不相关，只在 DM 的准备阶段有用。

因此，工具栏现在分为两种模式：Build 模式和 Play 模式。
可以通过点击工具栏末尾的字母或在键盘上按 TAB 键来切换这两种模式。

现在有些工具只出现在其中一种模式中（例如 Draw 只在 Build 模式、Ping 只在 Play 模式）。

#### 调整形状大小

现在有些工具也会根据所处模式的不同而表现不同。

从 0.21.0 开始，Select 工具只能在 Build 模式下调整形状大小。Select 工具的其他所有功能在 Play 模式下仍然可用。

之所以引入这一改动，是因为玩家在尝试移动形状时经常不小心调整了大小，而在游戏过程中调整形状大小并不常见。

### 更新日志

另一个值得注意的变化是，现在会有一个更新日志弹窗，告知玩家服务器已更新。

![显示更新日志](./0.21/changelog.png)

### 公开 Ruler 开关

Ruler 工具现在也有一个小的选项弹窗，就像 Draw 和 Map 工具一样。
它只有一个设置：一个开关，用于决定你的 Ruler 是私有的还是公开的。

### 先攻

当你和其他玩家同时输入先攻时，常常不得不重试，因为有人更快，导致先攻列表重新排序，而你会因此失去输入焦点。

从现在开始，当你在先攻对话框中聚焦于某个输入框时，UI 会暂停更新，直到你离开该输入元素。

### 限制玩家 UI

之前有些地方玩家可以访问本应只供 DM 使用的选项。

从本次发布开始，玩家不再能移除或添加楼层，也不能再自行将形状移动到其他图层/楼层/地点。

## 杂项

- 创建新楼层时不再自动将所有人移动到该楼层
- 游戏内左上角显示的版本号现在将仅限于最新的发布版本
- 基础棋子的默认名称现在将设置为标签，而不是'未知形状'
- 移动设备用户现在不再能通过简单移动触发过度滚动刷新
- 将鼠标悬停先攻列表中的图像上时，现在会显示形状的名称
- 多边形工具现在在吸附方面也与其他形状表现一致。除非你禁用吸附，否则每个顶点都会吸附到网格线上。

## Bug 修复

- 使用初始顶点列表创建多边形时会导致会话崩溃
- 玩家的楼层位置未被记住
- Ruler 不显示小数点
- Firefox 上 DM 设置/网格单位大小对浮点数显示无效输入
- 服务器显示 JSON 解码错误
- 玩家无法更新先攻效果
- 重新加载时活动图层有时会重置
- DM 可以把自己踢出
- 形状重置时某些 UI 组件未能正确更新
- 图层选择器右侧的区域阻止了 Draw/Select 操作
- 未定义棋子时键盘居中会报错
- 先攻同步存在多个 Bug
- 地点特定选项无法正确加载/保存的三个 Bug
- Firefox 中当地点栏无法适配屏幕时页面底部出现滚动条
- 半径为 0/0 的光源会阻挡该形状所有光线的 Bug

## 接下来

人们经常问我路线图上的下一步是什么，所以我想分享一些我打算在接下来的版本中处理的主题。
这个列表既不全面也不确定，不会全部出现在下一个版本中，它只是对可能到来的内容的一个展示。

##### 元数据/导出/导入的准备工作

在 discord 服务器上有人讨论过为素材添加元数据，以及将这些数据导入/导出到其他服务器的可能性。
在处理主要问题之前，需要完成一些准备工作。

##### 旋转

旋转功能在 PA 中缺失已有一段时间，终于应该得到解决了。

##### 重做启动序列

当前的启动序列（游戏加载时事件到达的顺序）应该重做。在这里调整一些顺序可以提升性能，而且有些内容是不必要发送的。

##### 迁移到 fontawesome-vue

PA 中的图标由 fontawesome 提供，目前是通过加载 fontawesome.js 库实现的。这是一个很大的文件，会占用加载时间，可以通过使用只包含实际使用图标的 vue 专用库来解决。

##### 游戏内异步素材列表

启动时 DM 会收到完整的素材列表，以便显示在侧边栏中。
这是浪费资源，游戏内的素材管理器应该像完整的素材管理器一样，在需要时向服务器请求数据。

##### 多边形改进

多边形很棒，但还可以增加一些功能，比如在现有多边形上添加和移除顶点。

##### 楼层工具改进

应该可以重新排序和重命名楼层，并提供对玩家隐藏楼层的选项。

##### 扩展灵气选项

灵气可以增加一些新功能，比如边框颜色，以及其他形状如锥形灵气。

##### 楼层的公开可见性

楼层信息目前对所有玩家公开，这应该像 PA 中的许多其他内容一样，得到一些公开/可见性处理。

##### 改进 Draw 工具中的光标

Draw 工具使用自定义鼠标光标以提供更流畅的绘制体验。然而，它并不总是清晰可见，这非常烦人。

##### 六边形网格

过去已多次有人请求支持六边形网格，所以我迟早应该为这种网格类型添加一些支持。

一些现有逻辑是基于矩形网格的，所以初始版本可能只支持六边形渲染，而不支持吸附功能。有待研究。

##### 快速加载当前楼层

目前加载地点时，游戏会一直等待，直到所有楼层都加载完毕。
可以改进为先加载当前激活的楼层，然后再加载其他楼层。

##### Blurhash

有些图片，尤其是地图，加载需要较长时间。我想提供一个快速的 blurhash 作为视觉提示，让用户知道图片正在加载，直到完整图片可用。

##### 多个出生点

如发布说明中所述，新的出生点系统不支持在一个地点设置多个出生点。
扩展这一功能是可行的，而且主要是一个 UI 问题，应该相对简单。

##### 更多分组选项

复制粘贴形状时有一些分组逻辑，但没有其他能力。
诸如将棋子添加到组、合并组、拆分组等功能由于各种原因都很有意思。

为组自动应用组先攻开关是我打算添加的另一项生活质量改进。
