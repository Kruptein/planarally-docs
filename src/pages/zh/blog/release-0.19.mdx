0.19.0 是我们今年的第一个版本！它带来了一些大型新功能（楼层和徽章），以及大量小的体验修复和改动。

本次版本更新提到的主题列在左侧，完整的变更日志可以在 [github](https://github.com/Kruptein/PlanarAlly/releases/tag/0.19.0) 上找到。

_我还建立了一个 [patreon 账户](https://www.patreon.com/planarally)，欢迎去看看 :)_

## 视野

### 楼层

本版本最大的新增内容之一就是引入了楼层。就像现实中一栋建筑可以由多个楼层组成一样。
到目前为止，如果你想在 PA 中模拟这一点，就必须使用单独的地点，或在一个地点中使用不同的区域来表示不同的楼层。
这两种方式都需要大量的来回切换，这终究是令人不满意的。

本版本改变了这一点，DM 可以使用左下角、紧挨着图层选择器的楼层按钮来创建/删除楼层。该框中显示的数字就是当前激活的楼层号。

视野和照明可以自然地跨楼层工作；上层楼层的棋子可以通过窗户看到花园里带灯的棋子，同样，花园里的人也能看到上层阳台上的那个人。_请注意，这并不是真正的 3D 渲染，因此可能会出现一些由于某些物品的高度未知而产生的小的边界情况。_

上面的示例展示了楼层视野的工作方式，左侧代表拥有第一层楼上 Y 棋子所有权的玩家，右侧代表可以访问两个棋子的 DM。

要切换楼层，请点击左下角的楼层按钮并选择你想要的楼层。要更改一个形状或一组形状的楼层，请右键单击它们并使用楼层子菜单。

**实用提示：** 有一些专用于楼层的额外快捷键，可以让你无缝切换。Page Up/Down 可让你向上或向下移动一层。你也可以通过快捷键把选中的形状移动到其他楼层；Ctrl + Page Up/Down 会把棋子向上/下移动一层，如果你想立即跟随移动，请改用 Ctrl + Shift + Page Up/Down。

请注意，目前玩家可以自由移动到任何想要的楼层。未来会添加额外的访问控制，但只要视野设置得当，这实际上应该完全没问题！

每个楼层本质上都是一整套全新的图层。这也意味着每添加一个楼层，客户端都会增加额外的加载负担。未来会为那些可能无法承受额外加载负担的玩家添加一个仅渲染当前楼层的选项。只有一个楼层的默认情况，与之前的版本相比不会有额外的开销。

### 可用的模式

基于包围体层次（bvh）的旧视野模式现已从游戏中移除，任何仍在使用它的地图都应切换为基于三角形扩展的默认模式。

此外，还提供了一种新的视野模式。它是基于三角形的默认视野模式的实验性升级，无需重新计算整个场景，而是迭代工作。这应该能为拥有大量视野元素的地图带来明显的性能提升，但仍可能包含会破坏视野的 bug，如果发生这种情况，重新加载页面应该就能解决。

## 形状

### 徽章

另一个新功能是由 @adunis 在 github 上建议的，那就是引入徽章；它们是出现在棋子右下角的小型编号图标。

徽章的显示可以按棋子分组单独开启或关闭。这里的棋子分组定义为复制粘贴同一个棋子所产生的所有实例。_（例如，我拖一个兽人棋子到桌面上并复制粘贴几次，所有这些棋子属于同一个分组。再拖一个全新的兽人棋子到桌面上则是另一个分组。）_

徽章的背景色取自形状的描边颜色，边框颜色和字体颜色则根据最佳可读性选择黑色或白色。棋子编号会在粘贴时自动递增。

## 工具

### 吸附

多边形工具是我经常使用的工具，尤其是不会自动闭合的版本。不过，我经常遇到的一个问题是，没有可靠的方法能精确地在多边形上添加一个与现有点完全重合的点（例如连接墙壁）。这会导致在这些开放多边形相接的区域周围出现非常小但明显的照明问题。

本版本新增了吸附功能，当你的鼠标光标靠近附近某个现有点时，它会自动被吸附过去。这种吸附行为只在调整大小或使用 Draw 工具时生效。Draw 工具现在在激活时还会高亮显示可吸附的点（根据反馈，这可能是我将来会移除的东西）。

### 触控手势

触控支持一直以来充其量都很不稳定。这是让触控设备能够以更直观的方式与 PlanarAlly 交互的第一步。

这些改动的加入主要限于使用触控与各种界面元素进行交互，一些更「高级」的手势（例如捏合缩放等）尚未加入。

_这个功能由 github 上的 @ZachMyers3 贡献_

### Select 修复

有一批与 Select 工具相关的 bug 可能会导致糟糕的用户体验，希望这些问题现在已经解决。

特别是拖动一组棋子时，常常会一开始出现突然意外的跳动，这是由于糟糕的向量计算造成的，现在一次拖动多个形状应该会好很多。

在多选状态下，调整大小的光标也无法在所有形状上正确显示。

此外，如果你把一个角拖过另一个角，调整大小整体上也会出问题。

## 设置

### 账户设置

我们创建了一个非常基础的账户设置页面。仪表盘中的齿轮图标现在终于有了实际用途！

![账户设置](./0.19/accountsettings.png)

可以看到它的功能范围相当有限，但你现在可以更改用户名、添加电子邮箱、修改密码，如果愿意，还可以删除账户。

请注意，PA 不会以任何方式使用该电子邮箱（也不是必填的），但它为将来可能的变化而存在，或者服务端管理员想给其用户群发邮件时也会用到。

## 杂项

### ctrl 0

鉴于 PA 拥有无限大的地图，在平移/滚动之后，你有可能找不到自己真正的地图了。

作为简单的解决办法，现在有一个 ctrl+0 快捷键，可以将你的视角重置到地图的原点。

_这个功能由 github 上的 @LDeeJay1969 贡献_

### /\_load

希望大多数用户都没有注意到这一点，但 PA 过去有一个特殊的 /\_load 路径，用于在路径之间切换。
不过，如果你使用浏览器的后退按钮返回，就可能落在这个没有任何可交互内容的特殊页面上。

现在加载机制已经改变，不再需要这个特殊路径了。

_这个功能由 github 上的 @ZachMyers3 贡献_

### 版本号

为了让你能看到所在服务端实际使用的 PA 版本，登录面板现在会在标题中显示版本号。

![版本号](./0.19/version.png)

_这个功能由 github 上的 @ZachMyers3 贡献_

### 移除 js 构建产物

这是一项仅与代码贡献者相关的技术性更改。

过去，js 构建产物会存储在 git 仓库中，这样服务端文件夹无需任何额外的 js 构建就可以直接使用。
然而，这会导致大量的合并冲突和仓库中不必要的文件。

如果你想在本地测试，现在需要自己正确构建 js 文件。
