这个版本的内容类型相当丰富，包括一些 UI 重新设计、新的工具选项、生活质量改进等！

同样值得注意的是，这个版本还包含 Discord 服务器上多位贡献者的贡献，特别感谢 scoodle 和 mischievous！

## 仪表盘重新设计

我们先来看看最明显的变化之一：仪表盘！
仪表盘是你登录后看到的页面，也是你选择要游玩/主持的战役的地方。

这个页面被完全重新设计，现在看起来像这样：

![仪表盘重新设计](./0.26/dashboard.png)

### 菜单

左侧边栏充当菜单，让你可以即时访问各种视图。

菜单的第一部分与游戏相关：play（游玩）列出你作为玩家参与的所有会话，run（主持）列出你作为 DM 主持的所有会话。最后的 Create（创建）选项允许你创建新战役。

第二部分与素材相关。Manage（管理）菜单会打开素材管理器，这是一个以前只能在游戏内访问的组件。这里的 Create 选项目前还不可用，但会在未来的版本中开放！

最后，我们还有打开设置和注销的操作。

一个重要的说明：设置和管理器目前仍在原有的组件中打开，但目的是重新设计它们以适配这个新的仪表盘 UI。

### 主持/游玩

在主持和游玩模式下，右侧会出现第二个栏，其中包含当前所选战役的更多详细信息。

值得注意的新增功能包括：设置图标（仅限 DM）、创建与战役相关的个人小笔记、查看上次在该战役中游玩的时间，以及离开/删除战役的操作。

## 工具

### 擦除楼层模式（DM）

DM 的绘制模式新增了「擦除」模式。

这种特殊模式允许你让当前楼层上的区域变为透明，从而让你和玩家看到下层楼层正在发生什么。

你可以用它来处理突然爆炸在地板上炸出洞的情况，或者也许你只是在预处理时忘了让某些内容透明，想直接在 PA 中编辑。

![擦除模式](./0.26/erase.png)

上图中有 2 个楼层。
底层包含一个青色的矩形。
上层包含所有其他形状。

右边那个大致像粗箭头的多边形形状，是用擦除模式绘制的形状。
它让我们可以看到底层。

这个形状和任何普通形状一样属于绘制堆栈！你可以看到红色矩形位于这个多边形形状之上，仿佛有一根圆木横跨在地板的开口上。如果你把多边形移到最前面（或把红色物体移到最后面），只有未被多边形覆盖的红色部分才会可见！

最后一个重要方面是，绘制时这个形状会自动创建在 Map 楼层上。不过，没有任何东西阻止你将它移到其他楼层。

### 文本形状

绘制工具新增了一个非常直接的选项：绘制文本，所有人都可以使用。

这个第一个版本相对简单，当你选中此形状并左键单击时，会弹出文本输入提示。
该形状可以像其他形状一样旋转/调整大小。

未来还会有进一步的增强。

### Ping 和 Ruler 尺寸更改

你绘制的 Ping 和 Ruler 尺寸始终保持一致。
然而，当其他玩家绘制它们时，其尺寸会受他们所在的缩放级别影响，而不是你所在的级别。
这可能导致某些 Ruler 在你的屏幕上显得很粗或很细，或 Ping 很难发现。

这个版本改变了这些形状的规则，它们将始终以完全相同的尺寸绘制。你或绘制者的缩放级别不再影响这一点。

### Spell 锥形图标更新

一个小型 QoL 更新：Spell 锥形图标现在是实心锥形。
感谢我的朋友 Jiri。

## 设置

### 客户端设置重新设计

仪表盘并不是唯一获得焕新的 UI，客户端设置也换上了新装！

![客户端设置重新设计](./0.26/client.png)

客户端设置不再位于侧边菜单中，而是像 DM 设置一样在模态框中打开。
这提供了更多呼吸空间，也为更多选项留出了余地。

作为这次重新设计的一部分，现在还引入了战役专属客户端设置的概念。
当你更改某个设置时，会注意到旁边出现两个图标，表示该设置已偏离默认设置。

左侧图标将该值重置为全局设置，而右侧图标则将这个新值设为新的全局默认值。

在以后的版本中，全局设置也可以在仪表盘-设置视图中编辑。

### 禁用滚动缩放

使用触控板的玩家经常抱怨的一件事，就是需要一个选项来禁用滚动时触发缩放，因为使用触控板时很容易意外触发。

这个新选项现在可以在客户端设置的「行为」（behaviour）下找到！

### 联合 DM 选项（DM）

作为 DM，你现在可以在你的主 DM 设置中将玩家提升为联合 DM（co-dm）角色。

## 形状

### 击败

这个版本的形状只有一个小的更改，那就是「击败」（defeated）属性。
当你在形状属性中勾选此框，或选中一个或多个形状后按下 'x' 时，所有受影响的形状都会被画上一个红色 X。

Tracker 与上一版本中的光环一样，获得了 UI 全面改造。

## 加载墙体信息（DM）

一些 DM 有时面临的另一个困扰，是为视野系统绘制墙体的繁重工作。

这个版本新增了 2 个从其他来源「导入」墙体信息的选项。

### dungeondraft

Dungeondraft 是一个流行的工具，用于在将地图导入 VTT 之前准备地图。
它们提供自定义 dd2vtt 文件格式的导出。

PlanarAlly 现在可以理解这种格式，当你将一个此类文件作为素材拖放到游戏桌面上时，它会附带这些信息。

出于技术原因，与 dd2vtt 文件关联的墙体、门和灯光不会立即添加到场景中。
你可以先调整素材大小/映射到满意的形态，然后转到形状属性的「Extra」标签页，点击「Apply ddraft info」按钮来加载所有额外信息。

所有信息都会作为真正的 PlanarAlly 形状添加到游戏桌面上，这意味着你可以调整大小、移除不需要的灯光等。

### svg

另一个可用的方法是给任何素材附加一个包含墙体信息的 svg。与 dungeondraft 文件类似，这可以在形状属性的「Extra」标签页中完成。

**一个非常重要的警告**：保持这些 svg 简单，否则你会非常痛苦。

这些 svg 旨在只包含墙体信息，所以添加前请确保移除墙体、背景等内容。

最后需要注意的是，这些墙体不可交互，它们纯粹是形状内部的，所以目前无法调整大小等。

## 生活质量改进

### 大红色边框

现在，当与服务器的连接中断时，屏幕周围会出现一个大红色边框。

根据问题的不同，连接应该会自动恢复，但你在断开期间修改的所有内容都可能会丢失。
这种情况一直如此，但现在你应该能清楚地知道何时可能会丢失进度。

### Mac 快捷键

所有使用 ctrl 键的快捷键，在 mac 电脑上现在将使用 cmd 键。

### 字体加载

PlanarAlly 使用的 opensans 字体现在将从服务器获取，而不是从 Google Fonts。
否则在离线游玩时可能会导致字体问题。

## 服务器

### 指定公共主机名

默认情况下，当 DM 设置中显示邀请链接时，它会使用当前浏览器 URL 来确定主机。
然而，当 DM 通过本地 IP 或 localhost 连接时，其他玩家将无法使用该 URL。

新的服务器配置设置允许你设置 `public_name`，设置后将始终用作根主机。

_由 Discord 上的 mischievous 贡献！_

## 值得注意的 bug

### 楼层名称重复（DM）

不再可能创建与已有楼层同名的楼层。
这可能导致与这两个楼层交互时出现多个问题。

这是一个快速修复，但无论如何也不应造成太多限制。

### 文件上传中断

添加了一个修复，防止大型文件上传在短时间内停止。

_由 Discord 上的 scoodle 贡献！_

### 离开墙体时棋子吸附

在移动棋子时，如果你把鼠标移入墙体，当鼠标从墙体返回时，你可能会与形状失去同步。
这个问题现已修复。

### 使用非默认网格大小放置模板

当在游戏桌面上放置带有包含尺寸信息的模板的形状，但使用了非默认网格大小时，形状会被错误地调整大小。

### 变体形状显示

使用实验性的变体功能时，所有玩家都能随时看到任何变体形状。

### 上下文菜单超出屏幕

在屏幕底部或右侧边缘打开上下文菜单时，内容会超出屏幕。
这些菜单现在会感知屏幕边缘并相应调整。

### 向后导航

使用浏览器后退按钮或鼠标上的按钮向后导航时，URL 会正确更新，但页面不会有任何变化。这个问题现已修复。
