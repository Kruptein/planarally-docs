作为今年的第二个版本，我的发布可能比平时小一些，但它确实有冲击力。

本版本包含了一些玩家也会真正喜欢的功能！

## 光环重做

首先是本版本中我个人最喜欢的功能之一：光环的重做！

<Image src={EditAssetTrackersPicture} width={1000} aspectRatio={1371 / 958} alt="资产跟踪器示例" />

大多数人会立刻注意到光环部分 UI 的戏剧性变化，但眼光敏锐的人也会注意到新增了 3 个功能。

### UI 更改

UI 已经更改，默认只显示基本信息（名称 + 启用/禁用），当你打开一个光环时可以看到所有细节。
另一个重大更改是，晦涩难懂的光环图标现在有了专门的文字标签，希望能避免任何混淆。

### 启用/禁用

过去没有明确的方法来禁用一个光环，你只能移除它或将其范围值设置为 0。

这两种操作都有些烦人，所以现在终于有了一个始终可见的专用开关。

### 边框

过去边框是不可见的，但现在可以为边框指定颜色。

这对于非光源光环尤其有用，你可能想跟踪某些东西，但不想让整个光环都填满颜色，因为如果有大量光环，它可能会变成视觉上的混乱。所以现在你可以让光环透明，但给它一个实心黑色边框，例如。

### 锥形

最后一个更改是能够让光环不覆盖整个圆，而是限制为锥形。

角度参数包含 2 个输入工具，第一个是常规数字字段，用于选择角度的宽度，
第二个用于选择光环应该朝向的实际方向。

这是一个更小众的功能，我预计不会经常被使用，但人们可以用它来实现一些硬核视野规则、特殊光源或任何想到的用途！

## Undo/Redo

一个经常被要求的功能，也是有充分理由的，就是能够撤销操作。

本版本添加了撤销和重做功能的首个版本，仅限于一组初始操作。
这些操作是：

- 形状移动
- 形状旋转
- 形状调整大小
- 楼层更改
- 图层更改
- 形状创建/移除

这应该涵盖了一些基本内容（四处移动），以及最令人烦恼的重要事情：意外移除形状。
所以像特定属性更改之类的东西还不能撤销，但已经有了可以继续开发的基础。

ctrl+z 用于撤销操作，ctrl+shift+z 用于重做操作。

目前有一个硬编码的 50 个操作记忆。

_为什么不用 ctrl+r 重做？这会覆盖常见的浏览器刷新键，我宁可不用它。_

## 施放法术

我收到过几次的请求是提供某种让法术可以施放的东西，或者至少提供一些工具来查看某些敌人是否会被某个法术击中。

你现在会在工具栏（Play 模式下）看到一个新工具，恰如其分地命名为 'Spell'，它将允许你做到这一点！

以下是你所期待功能的小预览：

正如所见，你可以在 3 种基础形状（圆形/正方形/锥形）中进行选择，并配置法术大小和范围等。

默认行为专注于仅仅测量，查看法术的影响会是什么，
但当你左键单击时，你实际上"施放"了法术，效果会留在战场上！

有关 Spell 工具如何工作的更多信息，请参见 [文档](/zh/docs/tools/spell/)

## 地点归档

当战役进行很长时间时，总有一刻你的地点栏可能会被填满。
你可以接受这种情况并向右滚动，也可以手动将活动地点拖到左侧。

在本版本中，现在有了归档地点的选项。这只是把它们从栏中隐藏起来，但其他方面保持不变。
归档从地点设置中完成。

地点栏左侧新增了一个 UI 按钮，用于将已归档的地点恢复到栏中。

一个较小的功能是，现在有一个选项可以让形状注释公开。

## 值得注意的修复

### （DM）地点栏

玩家的地点现在会在他们作为传送至出生点的一部分被移到另一个地点时实时准确更新。

### 视野工具私有光环

当你在 1 个屏幕上控制多个角色时，Vision 工具是一个很好用的工具。
但它没有正确考虑光环的公开/私有设置，即使你禁用了其中一个棋子的视野，它也会始终显示你控制的棋子的所有光环。

### 新楼层在刷新前不能工作

创建新楼层时，你不再需要因为它们没有被正确三角化而刷新。

### 形状名称同步

切换形状名称可见性时存在一些同步问题，现在已经解决了。

### 多楼层视野

最近引入了一个错误，允许一个楼层上的光环也照亮它下面的楼层。
