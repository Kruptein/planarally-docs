距离上次发布又过去了几个月，所以闲话少说，这里有一些新东西 :)

### 弃用通知重申

正如上个版本中所宣布的，标签/过滤器系统已弃用，将在下一个版本中移除。

## 简单的聊天系统

这个版本引入了一个简单的聊天系统，让你可以在战役中与其他玩家聊天。

![聊天按钮 消息等待](../docs/game/assets/chat.png)

它的设计简单直接。提供一些 markdown 格式，图片 URL 会自动转换成图片。

需要注意的是，目前发送的消息不会存储在服务器上。所以任何刷新或重新连接到会话，都会清空聊天记录。

我不太容易判断是哪些类型的群组在使用 PA，这也是为什么聊天功能相对精简。
如果持久的聊天记录或其他聊天功能对你的群组有帮助，请联系我们！

有关聊天的更多信息，请参见[文档](../../docs/game/chat)，关于 markdown 的信息可以在[这里](../../learn/dm/Markdown_Tutorial/markdown/)找到。

## 骰子改进

这个版本的很大一部分时间都花在了改进骰子投掷系统的各个方面。

### 骰子工具 UI

骰子工具的 UI 被完全改版了。

![骰子工具](./2024.3/dice.png)

#### 非 3D 模式

过去，掷骰子的唯一方式是用 3D 物体来模拟。
这可能很有趣，但由于各种原因并不总是最好的选择。

从现在开始，有一个选项可以在不进行 3D 模拟的情况下自动结算骰子结果。

#### 输入改进

之前的版本有一个文本输入和一个简单的点击 UI，可以不输入文字就能选择骰子（例如在 'd6' 上点击 3 次会把 3d6 添加到文本框）。

这能用，但相当受限。"点击" UI 被大幅扩展了。

骰子解析器的语法也得到了扩展，现在支持一些更复杂的表达式，比如 "kh2（保留最高的 2 个）"之类。

#### 结果分享

现在你可以完全私密地掷骰子，连 DM 也看不到结果。

收到其他玩家投掷结果的用户，现在可以点击通知弹窗来查看投掷的详情。

#### 结果 UI 与历史

显示骰子投掷结果的 UI 也略有改变。

为了减少杂乱，一组投掷中的单独结果（例如 3d6）不再显示，但将鼠标悬停在组上即可显示。

投掷历史也略有调整，点击历史中的一行会再次显示完整的结果 UI。

### 3D 库更新

3D 模拟使用了 babylonjs 游戏引擎。它已从版本 4 升级到 7。
这一变化还包括所用物理引擎的变化，因为 babylonjs 现在使用 havok 引擎而不是 ammo。

3D 投掷逻辑也略有改动，但在大多数情况下，行为应该与之前一致。

### planarally-dice 库和骰子系统

目前，骰子 UI 的很大一部分围绕 d20 系统展开，这在 D&D 中很常见，但也有一些其他系统使用。

话虽如此，骰子库本身已经被重写，因此它可以支持各种各样的骰子系统。
不过，PA UI 还没有切换系统的方法，所以目前默认使用 d20 系统。

我正在考虑如何在 PA 中最好地提供其他骰子系统。
（例如，在你的 DM 战役设置中增加一个 "骰子系统" 设置，也许甚至是一个通用的 "rpg 系统" 设置。）

所以未来可能还会有一系列与 rpg 系统/骰子相关的改动。

## 更容易的地城机动

在几个有拐角的狭窄走廊中移动一组棋子，有时会因为与墙壁碰撞而很麻烦。
起初，我经常手动把它们紧密地编成一组，到达某个位置又再次重要起来的地方后，再把它们散开。
最近，我通常只移动 1 个形状，然后用 shift 移动把其他形状挪到最终位置，只是因为这样省事。

但两种方案都不太理想，所以这个版本添加了一个新功能，以更省力的方式把这两种方法结合起来。

现在你可以右键点击一组形状，选择 "Collapse"，它们会全部移动到以你开始折叠的那个形状为中心的周围。
现在，当你只移动那一个形状时，其他所有形状都会自动跟随。到达某个位置后，你可以右键点击 "Expand"，
这会把所有形状推回到相对于你开始折叠的那个形状的原始位置。

还有一个键盘快捷键：按住字母 'c'（collapse 的缩写）时，你的选区会折叠；松开鼠标按钮或再次按 'c' 时会自动展开。

## 战役功能

另一个小补充是 DM 可以禁用某些功能。
具体来说，从本版本开始，聊天和骰子工具可以被禁用。

这更像是一个测试性功能，因为我还不确定该怎么做。
这些设置也许更适合作为用户偏好。

## 工具

### 工具栏 UI 变化

对工具栏 UI 的一处小改动：所有工具的扩展 UI 现在将完全右对齐，而不是悬停在相关工具上方。
这也意味着，那个连接工具 UI 和工具栏的小箭头现在也不见了。

在修改选择工具（见下文）时，我注意到越靠近中间的工具 UI 存在一些问题。
要么工具的 UI 不能太大，要么它会占据主屏幕很大一块空间。

通过把所有工具 UI 移到右侧，它们可以占用更多空间，而不会与屏幕中央的空间争夺。

### select 与 ruler 状态

当一个形状被选中时，选择工具的 UI 会提供一个选项，为该形状的移动添加尺子。

这相当不错，但该尺子的设置（例如它对其他玩家是否可见）只能在尺子工具中配置。
这意味着你经常不得不在两个工具之间来回切换，来更改或确认尺子设置。

现在选择工具也会显示尺子设置，并允许你直接修改。

![选择工具的尺子设置](../docs/tools/select-ui.png)

### 法术工具中的六边形

上个版本对六边形做了大幅升级，但并没有覆盖所有可能用得上六边形的地方。

这个版本让法术工具能够感知你正在使用的网格类型，现在提供以各种六边形尺寸创建法术效果的选项。

![法术工具的六边形尺寸](../docs/tools/spell-hex.png)

### Bug 修复

- 绘制工具：点击绘制工具视野设置中的 "blocks movement" 标签，现在会正确切换相关的复选框
- 尺子工具：网格模式下，空格键不能正确地向其他玩家同步吸附后的端点
