这是一个非常小的版本，目的是发布一些杂项 bug 修复、清理旧的服务器配置方案，并用内置的管理面板取代原先独立的 admin 客户端。

## 管理面板迁移

在本次发布之前，服务器所有者可以在主 PlanarAlly 服务器之外，额外运行一个仅供管理员使用的特殊 Web 服务器。
这个 admin 服务器可以用于一些非常简单的事情，比如列出所有用户、重置密码等。

它相当小众，需要一些技术知识来搭建，而且让服务器配置变得更加复杂。
由于它是一个独立的应用程序，它也经常被我忽略，导致依赖项过期，总体上收不到更新。

所以我决定彻底去掉它，直接把它并入主应用程序。
新增了一个配置选项 "admin_user"（参见[配置手册](/zh/server/management/configuration/#field-admin_user)），可以把它配置为将某个特定用户指定为主管理员。

这个用户会在他们的仪表盘中看到一个额外的 "Admin" 部分，打开后就是管理仪表盘。它与原来的管理面板数据大体相同，但有一些小的补充。

将来的目标是把它扩展，包括：

- 修改服务器配置
- 授予其他用户查看/管理某些内容的权限
- 显示自 2025.2 以来收集的统计数据

但这些要留到以后的版本了 ;)

## 缩放滚动改进

当放大到很远时，缩放级别会出现很大的跳跃，相当突兀和烦人。

现在缩放体验应该会平滑很多。

## 先攻修复

Rexy 对先攻行为做了一系列修复！

- 回退一个回合会减少效果计时器
- 移除先攻条目可能导致一些状态不一致

现在，当你移除一个先攻条目时，列表中的下一个条目会成为当前激活的条目。

## "Behind" 视野模式修复

"behind" 视野阻挡模式是在 [2024.1](/zh/blog/release-2024.1) 中引入的。

它最初是用一种巧妙的 hack 实现的。不过，最近有人（就是前面提到的 Rexy）提醒我，在某些情况下这会导致错误的渲染结果。

![错误的 Behind 视野渲染](./2025.3/behind-vision-wrong.png)

在上面的图片中，蓝色矩形被配置为 "behind" 视野阻挡模式，但不知为何，它的一大部分本不该可见的地方却显示出来了。

细节相当技术化，不过我花了几天时间处理这个问题，完全重写了 "behind" 视野模式的逻辑，现在它应该很稳健了 (TM)。

## 素材搜索修复

服务器代码中一个隐蔽的语法 bug 会导致在游戏内素材管理器中搜索时，显示出其他玩家的素材。

在修复这个 bug 的同时，我还注意到搜索素材时没有查询共享素材。
默认把它们包含进来是开销更高的操作，所以在搜索栏中新增了一个开关，可以选择搜索那些与你有共享的素材。

## 移除旧配置方案

在上一个版本中，配置格式被完全改掉了。从那以后，配置就存储在 `data/config.toml` 中，而不是原来的 `server_config.cfg`。

由于原来的配置被纳入了版本控制，我不想在升级时因为文件突然被移除而让大家措手不及。
事后想想，我本应该直接把它删掉（或者在文件里加一个大大的提示横幅），因为那些已经不再使用的文件仍然存在，造成了一些困惑。

算是吸取教训吧！

不管怎样，旧的配置文件已经被移除了。

## 无效的服务器配置

现在，当遇到未知/错误的配置数据时，服务器将不再启动，而是报告错误。

这是一项额外的措施，用来防止那些以为自己配置正确、但实际上并没有的人遭遇意外。

## 统计数据

我们对内部 API 做了一些小改动，特别是对 PA 主统计服务器的导出现在会分块进行，以免长时间未导出时产生巨大的数据包。

此外，玩家网络问题导致的快速连接/断开不再计入统计，因为那会灌入大量没有实际价值的数据。

## 杂项 bug 修复

- 重新选择后不再重新打开形状属性
- X 轴或 Y 轴上的最后一条网格线有时不渲染
- 重新排序后重命名楼层会重命名错误的楼层
