又到了发布新版本的时候！和其他版本一样，我们修复了一堆 Bug，但也还有其他令人兴奋的内容。
一些 UI 元素的重做、出生点的改进、模板系统等等！

**服务器所有者请注意** 本版本在 server_config 中新增了一个部分，请务必更新你的 server_config：要么用你自己的自定义改动覆盖新配置，要么把新增的部分添加到现有配置中。

## 出生点改动

本版本为出生点系统带来了两项改动：多出生点支持，以及对初始出生点系统的更改。

### 移除自动创建出生点

出生点系统的第一个版本会自动为你创建出生点。
实际上这个体验并不好。出生点有时不会在第一次就创建成功，有时会出现两个，有时它干脆不在你期望的位置。
此外，并不是所有地点都需要出生点。

因此我们决定不再进行这种自动创建。
现在你可以按需手动创建出生点。

### 多出生点

除了上述改动，每个地点只能有 1 个出生点的限制也已被移除。
创建出生点时，会提示你为其命名。

将形状移动到其他地点时，会弹出一个提示，让你在该地点定义的出生点中进行选择。
如果只有 1 个出生点，则会跳过该提示。

## 模板

也许最令人兴奋的改动是可以保存素材模板以备将来复用。
你可以在任何时候通过右键上下文菜单保存素材的状态。

该状态包括默认属性，也包括追踪器、灵气和尺寸（宽和高）。

当你把带有模板的素材拖放到游戏桌面上时，会出现提示让你选择模板，而不是使用基础的空预设。

## UI 重新设计

### 登录页面

登录页面已重新设计，现在更有格调了 :)
此外，注册流程更加明确，因为旧的行为对每个人来说都不是很清楚。

### 编辑对话框

每隔几个版本就会向编辑对话框添加一些内容，导致它变得越来越庞大。
因此，本版本为编辑对话框添加了一些子部分，以便更好地组织内容，而不至于占满整个屏幕。

## 系统通知

服务器所有者新增了一个选项，可以创建服务器消息。
这些消息将广播给所有当前玩家和未来的访客。
消息将一直可见，直到玩家将其关闭或服务器所有者将其移除。

这些消息的主要用途是告知用户即将到来的停机维护等信息。

有一个单独的 API 端点可用于发布这些消息，语义遵循简单的 REST。
server_config（ApiServer）中新增了一个专门用于配置该 web 服务器的部分。
它的配置方式与主 web 服务器相同，但默认是 `localhost` 而不是 `0.0.0.0`，默认端口为 8001。

关于有哪些端点可用的更多信息，请查看 [API 文档](/zh/docs/server/api/)。

## 生活质量改进

### Ruler 吸附

Ruler 现在也具有[吸附行为](/zh/docs/game/snapping/)，会尝试吸附到某个网格单元的 9 个点之一。
网格单元的 4 个角、它们的边中点和绝对中心都是吸附位置。

### 注释 Markdown

形状编辑对话框中的注释字段现在支持 markdown。
显示注释的 UI 也进行了一些小更新。

![Markdown 注释](./0.23/annotations.png)

### 服务器备份

服务器存档现在将保存到专门的子目录中。
在本版本之前，它们会存储在主服务器文件夹中，这可能会让东西变得非常杂乱。

旧的存档不会被改动，不过你可以随意将它们移动到新的子目录中。

## 杂项修复

- 以非 root 身份运行 docker 容器
- 通过快捷菜单解锁形状时不再使形状进入拖动模式
- Map 允许一些无效输入（负数、0 以及任何非数字内容）
- 笔记和注释文本框的初始高度不正确
- 尝试移动无权访问的楼层时出现控制台错误
- 私有形状的名称对有权限的用户显示为 ?
- [技术] 根据响应正文显示错误消息
