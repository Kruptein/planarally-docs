有一段时间没更新了！不过过去一个月我有很多空闲时间，所以这个版本包含了一些令人兴奋的新功能，还有大量 bug 修复！

在新版本中打开一张地图之前，先提醒一下：
由于修复了非默认网格尺寸的缩放 bug，你第一次加载某张地图时，画面可能会和上次相机所在的位置略有偏移。不过通常不会偏离原始位置太远。
如果你找不到原来的东西，可以试试按空格键将视野居中到棋子，或按 ctrl+0 前往世界中心。
如果仍有问题，请联系我，我可以给你一些控制台代码。

## 六边形

六边形支持是经常被要求的功能，这很合理。现在，我终于可以说已经有了*部分*支持。

作为 DM 网格设置的一部分，现在你可以选择网格类型，默认为方格，但可以改为平顶六边形或尖顶六边形。这可以在战役或地点层面进行配置。

## 分组改进

分组是一种组织形状的方式，可以给每个形状添加一个可选标记来区分（例如 ogre 5）。
在一个组内，每个形状都有一个唯一的值，也就是它的标记。

在之前的版本中，复制粘贴形状时会隐式地应用一种分组概念。

这个版本大大扩展了分组系统，使其更加可配置和明确。

![编辑素材分组](./0.24/edit-asset-group.png)

编辑素材对话框现在为形状所有者/DM 新增了一个选项卡。
这个选项卡可以配置与所选形状所属分组相关的各种内容。

可以配置字符集，目前有 2 个预设字符集，你也可以自由设置自定义字符集（例如 `α,β,γ,δ,ε,ζ,η,θ,ι,κ,λ,μ,ν,ξ,ο,π,ρ,ς,τ,υ,φ,χ,ψ,ω`）。

标记可以单独切换，也可以一次性切换整个分组。可以移除单个成员，也可以移除整个分组。

标记现在还可以随机化，以抑制可能的元游戏（metagaming）玩家。

## 变体

_这是**实验性**功能，我预计会出现一些边界情况，所以如果你遇到任何 bug，请一定告诉我！_

形状的一个新功能是能够添加变体。变体可以宽泛地定义为：你想切换到的任何其他形状，而不必新建棋子再移除原来的棋子。比如荒野形态、替换画风、多阶段 Boss、惊喜揭露……

任何时候只有一个变体可见，并且可以切换到另一个变体。每个变体都保留自己的大小、属性和计数器，但计数器和光环可以配置为在所有变体之间共享。

#### 已知限制

创建新变体时，它不会有基础变体已应用的任何设置。包括访问权限、常规形状属性（例如名称、是否为棋子等）或注释！

目前你只能添加素材管理器中的素材作为新变体。不过基础形状可以是任意形状。将来你还可以选择基础棋子作为备选，而不只是从素材管理器中选择。

目前还无法将带变体的形状保存到数据库，将来当你也能把其他自定义形状保存到数据库时，这会成为可能。

## 工具

### 先攻

先攻工具做了一些小改动，增加了一个显式的移除效果按钮，不再只依赖负数自动移除的行为。

此外，回合计数器现在从 1 而不是 0 开始，并且修复了很多与先攻同步相关的 bug。

### Map

Map 工具现在有了保持宽高比功能！配置网格数值时，可以切换一个锁图标来强制锁定宽高比。

另一个新功能是你可以跳过调整大小的选区，直接缩放整个素材。可以按网格单元格数或像素来缩放。

### Ruler

Ruler 工具新增了一个快捷键，让你可以折弯标尺。按下空格键可以从上一条标尺的端点开始一条新标尺。显示的距离是当前所有标尺的总和。

现在你也可以在 Select 工具上切换“显示标尺”，在移动形状时显示标尺。它会从形状的原始位置开始显示一条标尺，并跟随你正在移动的形状。它也支持用空格键测量拐角后面的距离。

在 Select 模式下使用标尺时，它会保留 Ruler 工具的隐私模式（即公开/私密）。

![多段标尺](./0.24/multiruler.png)

### Vision

Vision 工具在取消选中最后一个形状时的行为发生了变化。过去它会立刻重新全选。但这非常违反直觉且烦人，所以已被移除。

为了让视觉上更清楚你在将视野限制到一组选定的棋子，Vision 工具在不显示全部内容时会使用不同的背景色。

## 素材导入/导出

上一版本加入了模板功能。现在你可以把素材从素材库导出到本地电脑，然后上传到另一台 PA 服务器，或者留作某种备份。

导出的文件将以 `.paa` 结尾，这是 planar ally assets 的缩写。它会保留你原有的确切文件夹结构和命名方案，包括所有模板信息。

导入 paa 文件时，它会把所有内容解压到你当前查看的文件夹中。请注意，同名文件不会被覆盖，但新的文件和文件夹始终会被创建。

## 常规 UX 改进

### 打开编辑对话框

编辑对话框一直都可以通过右键点击形状的上下文菜单，或右上角的快速选择信息来打开。

现在，你还可以在选中形状时按回车键，立即打开这个窗口。

### 移动

现在你可以使用小键盘来移动视野，这也支持完整的六边形移动。按 5 会将屏幕居中到原点。

### 创建棋子对话框

输入框现在会自动获得焦点，按回车键就会提交信息！

### 常规工具

现在大多数工具都支持在选中的形状上使用右键上下文菜单，无需切换到 Select 工具。

有两个例外：Draw 和 Map。它们有自己的右键行为。

此外，filter 和 Vision 工具允许在不切换的情况下使用更多 Select 工具的选项。

最后，当切换到当前工具不支持的 Tool 模式时，会自动切换到 Select 工具。

### 删除性能

一次移除多个形状（尤其是与视野/照明相关的）时，客户端可能会出现严重的性能下降，甚至完全卡死，只执行部分移除。

这是因为视野/照明的三角剖分重算效率很低。现在改进了算法，结果**明显**更加流畅。

## 值得注意的修复

### 形状选择

针对旋转形状的形状选择做了两个修复：

当你点击一个旋转过的形状以选中它时，如果你点击的是未旋转形状所占的位置，代码也会选中该形状。已修复。

进行分组选择时，多边形（和其他形状）会使用最大的包围盒来判断碰撞。这相当不精确，现在已改为精确判断。

## 其他更改

还做了一些不会立即影响最终用户的小型技术更改：

- 升级到 socket.io v3
- 减少了用于确定棋子最小视野范围的计算次数
