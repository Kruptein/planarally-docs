## UI 改动

### 仪表盘重新设计

我们在 0.26（2021 年 3 月）时重新设计过一次仪表盘，但这次我们又来了 \:D

游戏版块已从 3 个导航入口（run/play/create）合并为只有一个版块。
此外，之前的"详细信息"侧边栏在屏幕较小的设备上占用了大量空间。
这个版块现在经过了重新设计，点击列表中的游戏时即可使用大部分选项。

![仪表盘](../docs/dashboard/assets/dashboard.png)

同样值得一提的是，这次的重新设计确实包含了素材管理器。
希望这能让一些人高兴，因为之前的版本完全是另一回事 \:D

![仪表盘素材](../docs/dashboard/assets/dashboard-assets.png)

### 工具栏图标

另一个视觉改动是，工具栏现在使用图标而不是文字标签。

如果你不喜欢这样，可以通过用户设置改回文字标签。

![GM 处于'Build'模式时的工具栏示例，Select 工具已激活，模式可以切换为 Play 模式；此时过滤工具可以使用，但 Vision 工具不行。](../docs/assets/toolbar-example.png)

## 在画布上快速跳转

有时我们会忘记自己在游戏桌面上的位置，或者想切换到其他角色的视角。

有经验的 PA 用户会知道，通常可以用空格键来实现这一点。
不过在这个版本中，我增加了两个视觉元素来改善这一体验。

### 返回内容

第一个功能专门针对在无限画布上迷失、只看到满屏迷雾的情况。

如果发生这种情况，屏幕底部会弹出一个新的 UI 元素。
点击该元素后，视图将以你可见的最近元素为中心。

它会考虑到战役的视野模式（战争迷雾和视线设置）。

### 棋子方向

另一个新增功能是，屏幕外（你有权限的）棋子现在会显示在屏幕边缘，并带有指向其方向的箭头。
点击箭头后，视图会以对应的形状为中心。

![棋子方向示例](./2022.3/token-directions.png)

它们使用与你配置的 Ruler 颜色相同的颜色。
这个功能也可以通过新的客户端设置关闭。

## 生活质量改进

本次加入了一批生活质量改进。

### 平移

之前已经可以用鼠标中键平移，现在拖动时右键也会进入平移模式。

这主要是为了改善使用触摸板的用户的体验，因为对他们来说点击中键不太方便。

### 行为提醒

现在，Draw 工具和 Vision 工具在行为被修改时会显示橙色背景。
这样当你修改了某些内容后来却忘了时，能引起你的注意。

对于 Vision 工具，只要没有激活所有棋子，它就会高亮显示。

对于 Draw 工具，当逻辑和/或视野标签页中有内容处于激活状态时会高亮显示。

### 复杂追踪器表达式支持

使用追踪器时，快捷选择信息可以让你在游戏中快速修改追踪器，这一点非常有用。
不过到目前为止，你只能输入一个数字，并可以在前面加上 `+` 或 `-` 来表示相对于原始值的增量。

从本版本开始，该界面已修改为支持更复杂的表达式。
现在几乎支持任何数学表达式（由 math.js 提供支持）。

它现在也有两种模式：绝对模式和相对模式。相对模式会把表达式的结果加到原始值上。

还新增了一个客户端设置，用于选择启动游戏时默认使用哪种模式。

一些示例：

如果你的追踪器值为 50，并运行以下表达式：

`-(10 + 20 + 5 * 2) + sqrt(4)`

在绝对模式下追踪器将变为 `-38`，在相对模式下将变为 `12`（`50-38`）

同样，再从 50 开始：

`12`

绝对模式下将变为 `12`，相对模式下变为 `62`（`50+12`）

### Vision 工具 - 私有灵气

在 Vision 工具中取消选中某个形状后，其私有灵气将不再可见。

### 导入/导出

导入和导出代码做了一些调整。

DM 可以在仪表盘的游戏列表中导出自己的战役。
导入可以通过进入"新建游戏"来完成。

现在导入和导出都会显示一个单独的页面，可以看到进度信息。
这应该能更清楚地显示导入/导出是否在进行中，或者在哪里失败了。

### 骰子

现在每次投掷的单个骰子结果也会与小计和总计一起显示。

这是为了适应单个骰子结果可能影响总结果的游戏系统。

## DM：玩家

### 客户端矩形

DM 可以在 DM 设置中选择查看特定玩家的视口。
当你的玩家只登录一次（即拥有 1 个客户端）时，这个设置工作正常。

当玩家在多个浏览器上登录（即超过 1 个客户端）时，显示给 DM 的视口总是跟随最近移动过的客户端。
这令人困惑，也不符合预期。现在，每个已连接的客户端都会显示一个独立的矩形。

需要注意的是，一个客户端的移动仍然会同步到其他客户端。

### 在线玩家

现在左侧边栏也会为 DM 增加一个玩家版块，列出所有已连接的玩家。
点击列表中的名字会将视图居中到该玩家的当前视口。

这是一个临时的设置，因为我打算更深入地探索玩家概念，但自从开始这个粗略的原型后一直没有时间。

## 性能

本次加入了一些性能改进。

### 限制楼层渲染

现在有一个用户选项，可以只渲染当前激活的楼层。

当有玩家在使用多楼层地图时注意到性能不佳时，这个选项会很有用。

### 形状中心计算

形状的中心在很多地方都会用到，以前每次需要时都会即时计算。

现在中心只会计算一次并被记住，直到某个操作导致中心发生变化（例如形状移动），此时才会重新计算。

大多数形状不会经常改变位置（例如墙壁），所以理论上这*应该*能提高性能。

### 扇区

渲染场景时，每个图层只考虑屏幕内可见的形状。
之前这是通过遍历形状并执行 visibleInCanvas 检查来完成的。

本版本的新特性是将形状按扇区（或区块）排列，只检查视图中可见的扇区。

这可能需要进一步微调。

## 服务器

### 素材文件的备用位置

现在可以更改素材文件文件夹的位置，所有素材都从这个文件夹提供。

### 服务器启动

为了更方便地管理服务器，文件已被重新整理。
这会影响服务器启动方式，你现在应该调用 `planarally.py` 文件而不是 `planarserver.py` 文件。

它接受与原始脚本相同的参数等。

docker 镜像已修改，如果你使用它，就不需要更改任何东西。

### 导入/导出

导入和导出现在应该更稳定，并且已默认在 server_config 中重新启用。

## Bug 修复

### 形状逻辑修复

- 以玩家身份启动时传送区域未能正确触发
- 传送区域未能正确落在目标中心
- 玩家门开关未同步到服务器/无法持久化
- Door/Tp 区域预览无法切换楼层

### 追踪器/灵气

- 共享的追踪器/灵气未显示在选择信息中
- 共享的追踪器/灵气被移除后，客户端需刷新才显示

### 先攻

自 2022.1 中的一项技术改动以来，当客户端存在未知形状时，先攻系统一直表现异常。
未知形状可能由多种原因导致（例如形状已移动到另一个地点、形状位于 DM 图层上因而玩家无法知晓，等等）。

下面的一些条目与上述已解决的问题相关，但也有一些是完全独立的问题。

- 服务器应能更好地检测先攻列表中的客户端错误并拒绝错误数据
- 修改先攻时在更多情况下应保留当前激活的角色
- 移除形状导致了一些先攻不一致
- 在 DM 图层和玩家可见图层之间切换有时会干扰先攻
- 先攻的镜头锁定无法切换楼层

### 素材

- [DM] 素材无法移动到上级文件夹
- [DM] 如果存在链接到该素材的形状，则素材无法删除
- [DM|服务器] 使用子路径配置时素材管理器不再可用

### 杂项

- 提示弹窗中的错误不可见
- 注释的可见信息需刷新后才能同步到其他客户端（仅 UI）
- 切换地点时玩家状态被清除
- 触摸板的缩放灵敏度
- 地点菜单中的拼写错误
- 游戏内 AssetPicker 弹窗 UI 修复
- 提示弹窗未正确清除错误信息
- 工具详细信息并不总是在正确位置（例如切换模式时）
- 精简选择信息中多余的空格
- 跳转到标记无法切换楼层
- 将复合/变体形状移动到其他楼层并跟随时会显示多余的选框
- Draw 图层渲染在迷雾下方（例如 Ruler、Ping 等）
- 多楼层设置下移除遮挡形状时视野未能正确重新计算
- AssetPicker UI 出现位置过低
- 平移时多边形编辑 UI 残留在原处
- 多边形旋转时移动其顶点
- 普通形状有时被错误识别为出生点
- 骰子有时会跑出屏幕
- 键盘移动不会带动 Select 工具的旋转辅助控件
- [DM] 移除玩家权限后，注释在刷新前仍然可见
- [DM] 重置地点特定设置后，需刷新才能立即同步到客户端
