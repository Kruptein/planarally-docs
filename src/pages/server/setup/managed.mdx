# External Services

By far the easiest option regarding setup is the use of an online service that provides PlanarAlly to you and your players.

## Official server

There is historically no fully official first party server. I do however host a public instance on https://app.planarally.io but that has historically been running the development branch.
I'm considering changing this to the latest release and have an alternate beta version as well.

## Known third party providers

_If you host or know someone who hosts PA publicly, feel free to let me know!_

<Warning>
    These services are **not** operated by me and thus I cannot guarantee that the software has not been altered with
    malicious intent.
</Warning>

[Dice.Quest](https://planarally.dice.quest/) (Previously dndbox.com) v2024.3 is hosted in Switzerland/Europe and hosts a number of [open source projects](https://dice.quest) including PlanarAlly. Support is offerred on [reddit](https://reddit.com/r/dndbox/).

[10leej.com](https://planarally.10leej.com/) v2025.1.1 hosted in Atlanta, Georgia/USA support provided by 10leej use contact information found on the [website frontpage](https://10leej.com/) for support.
