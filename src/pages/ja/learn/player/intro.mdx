# はじめに

おめでとうございます。あなたのグループが次のゲームに PlanarAlly を検討していますね。
では、実際にどう使うのでしょうか。

この入門ガイドでは、アカウントの作成方法、ゲームへの参加方法を確認し、
ゲームを開いたときに表示される主要な UI 要素を見て、実際に触っていきます。

## アカウント作成

<Info title="PA サーバー">
    PlanarAlly
    のサーバーは単一ではなく、誰でも自分のバージョンをホストして、他の人に公開または非公開にすることができます。
    通常はグループの誰かがどの PA サーバーでプレイするかを決めていますが、そうでない場合は誰かが
    [サーバーのドキュメント](/ja/server/setup/)を読んで、共通のサーバーを決める必要があります。
</Info>

選択したサーバーのホストを訪問すると、すぐにログインページが表示されます。
PlanarAlly で新しいアカウントを登録する際に特別なものは必要ありません。
ユーザー名とパスワードだけで、任意でメールアドレスを追加できます。

現在、メールアドレスは PA 自体では何にも使用されていませんが、
サーバー管理者が今後のダウンタイムなどをユーザーに知らせるために使用する可能性があります。

## ゲームへの参加

ログインすると、メインのダッシュボードが表示されます。そこには参加しているゲームが表示され、後で自分がゲームをホストすることにした場合も、ここに表示されます。

![Main Dashboard after logging in](./assets/dashboard.png)

ただし、ここにゲームを表示させるには、まず招待される必要があります。

ホストが URL を送ってくれます。その URL を訪問すると、自動的にあなたのアカウントと接続が設定され、ゲームに入れます。
今後、ゲームは上記のようにメインのダッシュボードに表示されます。

## UI の簡単な紹介

ゲームを開くと、すぐにさまざまな UI 要素が表示されます。

![An example in-game session](./assets/in-game.png)

画面の大部分を占めているのは、あらゆる VTT の核となる、トークン、視野、照明を備えたマップです。
これは DM が事前に準備しておくものです。

<Warning title="真っ黒?!">
    表示されるのが真っ黒な虚空だけという可能性もあります。しかし心配しないでください。おそらく DM がまだ
    あなたにシェイプへのアクセスを許可していないだけです。

    それでも何も表示されない場合は、<kbd>space</kbd> を押して、視野アクセスを持つトークンに画面の中心を合わせてみてください。

</Warning>

次の章では、マップとの正しい操作方法、パンやズーム、キャラクターの移動などを見ていきます。

まず、PA が他の主要な UI 要素を配置する画面の四隅を紹介しましょう。

左上には <Cog /> があり、これをクリックするとサイドバーが開きます。
これは主にあまり使用しない設定を構成するためのもので、現在のゲームを離れてメインのダッシュボードに戻る方法でもあります。

右上には、マップのズームレベルを制御するズームスライダーがあり、現在選択されているキャラクターに関する情報を表示する UI 要素も見えます。

さらに時計回りに進むと、右下にアイコンのグループと Build/Play の切り替えがあります。
これらはすべて PA が提供するさまざまなツールに関連しています。ドローツールからルーラー、ダイスまでさまざまです。
詳しくは次の章で説明します。

最後に左下の角がありますが、上のスクリーンショットでは空です。
この領域は主に DM 専用のものですが、DM が「フロア」という PA の特別な機能を使用している場合は、プレイヤー側にも表示されることがあります。
この機能を DM が有効にしている場合は、テキストチャットもここに表示されます。

この簡単な紹介ではまだ触り始めただけです。詳しくは、これらのツールが何なのか、キャラクターとどう操作するのかを[次の章](/ja/learn/player/interaction/)で見ていきましょう。
