# はじめに

新しい VTT を使い始めるのは、どのプラットフォームにも独自のニュアンスや機能があるため、常に少し大変なものです。
このガイドシリーズの目的は、ゲームの準備と進行という最も一般的な基本的な流れを始めるのに役立つことです。

先に[プレイヤーガイド](/ja/learn/player/intro/)を読んでおくことをお勧めします。そちらはとても短いもので、ここではカメラの移動などの基本的なことは繰り返し説明しません。

## サーバーの選択

最初の重要なステップは、どの PA サーバーでゲームを開催するかを決めることです。
セルフホストすることも、既存のオープンサーバーに参加することもできます。どちらでも構いません。

この選択についての詳細は、[サーバーのドキュメント](/ja/server/setup/)を参照してください。

## ゲームの作成

サーバーの選択が終わったら、ゲームを作成しましょう。
ログイン後にメインのゲーム一覧を開くと、右上に大きな NEW GAME ボタンがあります。

これをクリックすると、ゲームを最初から作成するか、別のサーバーからゲームをインポートするかを選択できます。

![Create Campaign Screen](./assets/create-campaign.png)

<Info>
    これはつまり、ゲームをエクスポートすることもできるということです。別のサーバーに移りたい場合は、 それが可能です。
</Info>

新しいキャンペーンを作成したいので、最初から作成しましょう。続けていきます。
名前を選び、必要に応じてロゴを追加して、さあ始めましょう。

ゲームを作成した後、最初に目にするのは、まだ何も置かれていない大きな白いキャンバスです。
これはもちろん修正していくもので、[次の章](/ja/learn/dm/first-map/)で行います。
