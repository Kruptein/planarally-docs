# PlanarAlly ドキュメント

PlanarAlly は、オープンソースの仮想テーブルトップです。セルフホストでき、インターネット接続なしでも動作します。
このドキュメントでは、プレイヤーや DM としての PlanarAlly の使い方と、サーバーのセルフホスト方法について説明します。

## 主要な機能

**照明と視野** — 戦争の霧、動的な照明、視線により、プレイヤーは自分のキャラクターが見えるものだけを見られます。
[ドキュメント →](/ja/docs/dm/lighting-vision/)

**レイヤー、フロア、ロケーション** — マップ要素をレイヤーに重ね、建物をフロアに分け、シーンをロケーションごとに整理できます。
[概要 →](/ja/docs/game/gameboard/)

**アセットとテンプレート** — マップやトークンをアップロードしてフォルダーに整理し、シェイプのプリセットを保存して再利用できます。
[ドキュメント →](/ja/docs/dm/assets/)

**ツール** — ルーラー、描画、スペル範囲、イニシアチブの管理など。Build モードと Play モードの両方で利用できます。
[概要 →](/ja/docs/tools-overview/)

**ノート** — 検索、タグ、シェイプへの任意の添付ができるキャンペーンノート。
[ドキュメント →](/ja/docs/game/notes/)

**セルフホスト** — データを完全に管理して独自のサーバーを運用できます。一度設定すればオフラインでも動作します。
[セットアップガイド →](/ja/server/setup/)
