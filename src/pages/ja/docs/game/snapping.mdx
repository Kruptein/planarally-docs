# スナップ

PlanarAlly の多くの要素には、何らかのスナップ動作があります。
スナップには、グリッドへのスナップと点へのスナップの 2 種類があります。

グリッドへのスナップはかなり自明です。シェイプを動かすとき、多くの場合、それらがグリッド上に正しく配置されることを望むでしょう。
グリッドスナップを使用すれば、超正確である必要はなく、PlanarAlly がその作業を代行します。

2 つ目のスナップ形式は、既存の他の点へのスナップ機能です。
ここでの点とは、既存のシェイプの点、たとえば長方形の角やポリゴンの頂点などを指します。

デフォルトではスナップは有効で、ほとんどの操作（例：移動・サイズ変更・回転）に適用されます。
特定の操作でこの動作を無効にするには、操作中に `alt` 修飾キーを押します。

完全に無効にしたい場合は、[クライアント設定](/ja/docs/game/settings/) で動作を反転できます。これにより、`alt` キーがスナップを有効にする修飾キーとして機能するようになります。

## 例

ポリゴンを描画するとき、クリックされたすべての点は、近くのグリッド点または既存の点にスナップしようとします。

点のサイズを変更するとき、グリッド点または既存の点にスナップしようとします。

シェイプを回転するとき、回転は 45 度の倍数にスナップします。
