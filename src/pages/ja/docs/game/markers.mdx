# マーカー

マーカーにはサイドメニューからアクセスできます（ブラウザウィンドウの左上にある <Cog /> アイコンをクリックするとメニューが開きます）。

マーカーは、マークしたシェイプがクイックリファレンスとして表示される場所です。マーカーの 1 つをクリックすると、画面が対応するシェイプの中央に移動します。

シェイプをマークするには、シェイプを右クリックして「Set marker」オプションを選択します。一度マークすると、マーカーメニューから、またはシェイプを右クリックして「Remove marker」を選択することで、マークを削除できます。
