# ツール概要

PlanarAlly は、ゲームや他のプレイヤーと操作するための一連のツールを提供します。
DM には、そのニーズに適した追加ツールも用意されています。
これらのツールのほとんど(すべてではありません)は、画面の右下にあるツールバーからアクセスできます。

## ツールバーとモード

ツールバーが多数のオプションで埋め尽くされないように、ツールはツールバーモードに応じて表示されます。
現在は「Play」と「Build」の 2 つのモードがあります。前者はプレイ中に実際に使用するツールに重点を置き、
後者は主に DM の準備中に使用するツールに重点を置いています。

モードを切り替えるには、目的のモードをクリックするか、`Tab` キーを使用します。

以下は、すべてのツールと、各ツールが利用できるモードの概要です。
一部のツールは、モードによって動作が変わる場合があることに注意してください。

## ツールのクイックリファレンス

| ツール                                   | アクセス | モード   | 説明                                                     |
| ---------------------------------------- | -------- | -------- | -------------------------------------------------------- |
| [Select](/ja/docs/tools/select/)         | すべて   | 両方[^1] | シェイプの選択、移動、回転、リサイズ。                   |
| [Pan](/ja/docs/tools/pan/)               | すべて   | 両方     | ゲームのビューポートをパンします。                       |
| [Draw](/ja/docs/tools/draw/)             | すべて   | Build    | さまざまな基本形状のシェイプを作成します。               |
| [Spell](/ja/docs/tools/spell/)           | すべて   | Play     | スペルの測定と詠唱。                                     |
| [Ruler](/ja/docs/tools/ruler/)           | すべて   | 両方     | 距離を測定します。                                       |
| [Ping](/ja/docs/tools/ping/)             | すべて   | Play     | 全員に見える一時的なビーコンを表示します。               |
| [Map](/ja/docs/tools/map/)               | DM       | Build    | アセット(主にマップ)をグリッドに合わせてリサイズします。 |
| [Vision](/ja/docs/tools/vision/)         | すべて   | Play[^2] | 視野に寄与するキャラクターを制限します。                 |
| [Zoom](/ja/docs/tools/zoom/)             | すべて   | 両方[^3] | ゲームの一部をズームイン/アウトします。                  |
| [Initiative](/ja/docs/tools/initiative/) | すべて   | 両方[^3] | イニシアチブの順序と時間制限の効果を追跡します。         |
| [Undo/Redo](/ja/docs/tools/undo/)        | すべて   | 両方[^3] | 特定の操作を元に戻したりやり直したりします。             |

[^1]: 機能はモードによって異なります。

[^2]: 実際に使用できる場合にのみツールバーに表示されます。

[^3]: ツールバーの一部ではありません。
