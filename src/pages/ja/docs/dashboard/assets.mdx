# アセット

<Image src={DashboardAssets} alt="ダッシュボードのアセット" />

**アセット**セクションでは、キャンペーンで使用できるアセットを管理または作成できます。
_使用方法については、[DM アセット](/ja/docs/dm/assets/)セクションをご覧ください_。

<Info>
    現在、アセットは主に DM
    にとって重要なものです。将来的には、プレイヤーがアセットをアップロードできる場所にもなる予定です。
</Info>

右上には、フォルダの作成、新しいアセットのアップロード、現在選択しているものの削除ができる小さな操作バーがあります。

## フォルダの移動

メイン画面にはフォルダエクスプローラーが表示され、ダブルクリックするとフォルダに入ることができます。
現在のフォルダパスは、「MANAGE ASSETS」タイトルの直下にパンくずリストとして表示されます。

前のフォルダに戻るには、「..」フォルダをダブルクリックしてください[^1]。
パンくずリストの任意の部分をクリックすると、一度に複数のフォルダを戻ることもできます。

## アセットのアップロード

アセットは、操作バーのファイル追加アイコンをクリックするか、アセットマネージャーにドラッグ＆ドロップすることでアップロードできます。

## アセットの移動

アセットを目的のフォルダにドラッグして移動できます。
アセットをひとつ上のフォルダに移動したい場合は、「..」フォルダの上にドラッグしてください。

複数のアセットを一度に移動することもできます。複数のアセットを含むフォルダをドラッグするか、複数のアセットを選択してドラッグしてください。

## アセットの選択

アセットをクリックすると選択され、他のすべてのアセットの選択が解除されます。

選択範囲を広げたい場合は、ctrl+クリックまたは shift+クリックを使用できます。
前者はクリックしたファイルだけを選択範囲に追加しますが、
後者は最後に選択したファイルから新しい選択までの間にあるすべてのファイルを追加します。

<Info>
    現在の動作は以前のアセットマネージャーからの名残であり、一般的なファイルエクスプローラーの操作を模倣したものです。

    ただし、現在の選択の表示方法では直感的ではないため、
    将来的に変更される可能性があります。

</Info>

[^1]: これは UNIX の世界の概念です。
