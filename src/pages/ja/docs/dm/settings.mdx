# 設定

DM には、特別なオプションウィンドウがあります。
これにより、アクティブなキャンペーンの設定を構成できます。

DM 設定にはサイドメニューからアクセスできます（ブラウザウィンドウの画面左上にある <Cog /> アイコンをクリックするとメニューが開きます）。

## Admin

<Image src={SettingsPicture} width={600} aspectRatio={659 / 543} alt="DM 設定" />

Admin セクションでは、管理オプションを提供します。

### プレイヤー

プレイヤーセクションでは、現在のプレイヤーのリストを確認できます。
個々のプレイヤーの名前の横で、キャンペーン内での役割を設定できます。

<Warning title="注意！">
    プレイヤーを DM に設定すると、キャンペーン **全体** への **無制限の** アクセス権が付与されます！
</Warning>

<Eye /> アイコンを有効にすると、DM レイヤー上にプレイヤーのビューポートが表示されます。
これにより、プレイヤーがどこを見ているかを追跡でき、プレイヤーがどこを見るかを変更することもできます。

「kick」をクリックすると、特定のプレイヤーをキャンペーンから削除できます。

### 招待 URL

招待 URL を使用すると、プレイヤーをキャンペーンに招待できます。
URL の右側には、URL をクリップボードにコピーするボタンがあります。
「Refresh invitation code」を押すと、URL が更新されます。

### セッションのロック

「Lock this Session」ボタンは、キャンペーンをロックまたはロック解除します。
ロックすると、キャンペーンにアクセスできるのは DM のみになります。
この機能は、マップを編集している間にプレイヤーが覗き見してしまわないようにしたい場合に便利です。

### セッションの削除

「Remove Session」は、PlanarAlly サーバーからキャンペーンを **完全に** 削除します。すべてのデータは復元できません。 **注意して使用してください！**

## Grid

<Image src={GridPicture} width={600} aspectRatio={690 / 256} alt="グリッド設定" />

グリッド設定では、グリッドの設定を微調整したり、グリッドを完全に無効にしたりできます。
これらの設定はキャンペーンデフォルトであり、[個別のロケーション設定](/ja/docs/dm/locations/#grid) で上書きできます。

### Use Grid

グリッドを有効または無効にします。これはすべてのプレイヤーにも適用されます。

### Grid Type

PA は、正方形グリッドを完全にサポートし、ヘックスベースのグリッドを最小限サポートしています。

ヘックスグリッドには2つのバリアント（pointy & flat）がありますが、正方形グリッドが持つ完全な機能セットはありません。
最も重要なのは、[スナップ動作](/ja/docs/game/snapping) がヘックス対応に更新されていないことです。

### Size Unit

サイズ単位を使用すると、単位のデフォルト表示を ft（dnd の標準）から別のものに変更できます。
これはすべてをメートルに変更するために使用できます（端数も含みます。例: dnd 標準では 1.5&nbsp;m が 5&nbsp;ft に相当します）。また、キロメートルやマイルで縮尺された世界地図を持つロケーションを作成するのにも使用できます。

### Unit Size

単位サイズは、ゲームシステムで1つのグリッドセルが表す距離です。Ruler ツールで距離を測定するとき、この情報が変換に使用されます。

## Vision

<Image src={VisionPicture} width={600} aspectRatio={675 / 402} alt="視野設定" />

視野は DM にとって最も重要な設定の1つです。
これらの設定により、プレイヤーが何を見るか、どのように見るかを変更できます。
これらは [照明と視野](/ja/docs/dm/lighting-vision/) の DM セクションでも参照されています。

このダイアログで定義された設定はキャンペーンデフォルトであり、[個別のロケーション設定](/ja/docs/dm/locations/#vision) で上書きできます。

### Fake Player

これを有効にすると、画面は DM 特権なしでレンダリングされます。
代わりに、[Vision ツール](/ja/docs/tools/vision/) で選択したすべてのプレイヤーの視野を使用してレンダリングされます。
これは、準備中やゲーム中でも、視野の設定が正しいかどうかを確認するのに役立ちます。

[Quick Toggles](/ja/docs/tools/quick-toggles/#fake-player) を使用すると、これをすばやくオン/オフできます。

### Fill entire canvas with FoW

_FoW は Fog of War（戦争の霧）の略です_

このオプションを有効にすると、画面上のすべてがデフォルトでプレイヤーに非表示になります。
エリアに視野を与えるには、光を追加する必要があります。

このオプションを無効にすると、画面上のすべてがデフォルトでプレイヤーに表示されます。
エリアから視野を取り除くには、FoW を追加する必要があります。

### Only LoS

_LoS は Line of Sight（視線）の略です_

このオプションは、高度な照明モードを切り替えます。

無効にすると、画面内の光源のあるすべての場所が表示されます。
その場所にプレイヤーがいるかどうかは関係ありません。

有効にすると、プレイヤートークンの視線内にあるものだけが画面に表示されます。
光が画面に表示されるには、プレイヤーがその光を見える必要があります。

このトピックの詳細については、[照明のドキュメント](/ja/docs/dm/lighting-vision/) を参照してください。

### FoW Opacity

この設定により、DM は DM 側での非表示エリアの不透明度を選択できます。
プレイヤーは自分にとってこの設定を常に 1.0 に保ち、編集することはできません。

フェイクプレイヤーモードでは、あなたも 1.0 に固定されます。

### Vision Mode

<Warning>これは技術的な設定であり、何をしているか理解している場合にのみ触れるべきです。</Warning>

実験的な視野モードは、デフォルト版とは異なる方法で照明・視野を計算します。

実験版では、光・視野の変更は、変更のたびに完全に再計算するのではなく、段階的に行われます。利点は非常に明白ですが、その結果としてテストが不十分であり、エラーが発生した場合は完全に動作しなくなる可能性があります。

マップ上に光・視野関連のオブジェクトが多く、何かを移動するときに画面の更新が遅い場合には、このオプションの使用を検討できます。

### 最小/最大視野

これらの設定は、[視野システム](/ja/docs/dm/lighting-vision/) の調整要素です。
すべてのトークンの視野の限界を決定します。

5000 ft. に及ぶ、完全に照らされた広大で開けたフィールドがあるとします。
このフィールドの中央に立っているトークンからは、その全域が見えると期待されるかもしれません。
しかし、人間や人間以外の目には限界があるため、これらの設定が導入されました。

最小視野の範囲内にあるものはすべて通常どおり見えます。
最大範囲を超えたものは見えず、戦争の霧になります。  
その間にあるものは、視野の端に向かうほど不透明度が増して表示されます。
