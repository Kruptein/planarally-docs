# ロケーション

Locations ツールは、それぞれ独自の設定を持つ [レイヤー](/ja/docs/dm/layers/) のセットを複数のインスタンスとして提供します。以下、各インスタンスを _ロケーション_ と呼びます。

## ロケーションバー

ロケーションに積極的にアクセスして操作できるのは DM のみです。
これは、画面の左上隅にある <Compass /> シンボルをクリックすることで行います。
これは「DM 専用」の機能であるため、プレイヤーはこのボタンを見ることはできません。
プレイヤーは一度に1つのキャンバスとしか対話しません。プレイヤーにとって、各ロケーションは別のマップ（つまり、積み重ねられた [レイヤー](/ja/docs/dm/layers/) の別のセット）のように見えます。

開くと、ロケーションバーの最初の行には、左側に新しいロケーションを作成するボタンがあり、その後にキャンペーンの各ロケーションの項目が続きます。
現在のロケーションは白いテキストと <Cog /> で強調表示されますが、他のロケーションのテキストとボタンは赤みがかった白で表示されます。
リストの各項目は、ロケーションをドラッグするためのハンドル、ロケーション名の表示、ロケーション個別の設定にアクセスするための <Cog /> ボタンで構成されています。

プレイヤーがいるロケーションには、そのロケーションにいる個々のプレイヤーのリストを表示するために展開できる「Players」というタブも表示されます。

2行目には、アーカイブされたロケーションにアクセスするためのボタンが表示されます。
アーカイブされたロケーションがない場合、ボタンは少し透明に見えますが、少なくとも1つのロケーションがアーカイブされると完全に不透明になります。

<Compass /> シンボルをもう一度クリックすると、ロケーションバーが閉じます。

## ロケーションの作成と並べ替え

ロケーションバー左側の「+」ボタンをクリックすると、ロケーションの名前を尋ねるダイアログが開きます。
この名前は後で編集できます。

「9つのドット」のシンボルをクリックして押し続けると、ビデオに示すように、バー上でロケーションを自由に並べ替えることができます：

## ロケーション設定

新しく作成したロケーションは、[設定](/ja/docs/dm/settings/) で定義されたキャンペーンデフォルト設定を継承します。
そこで定義された設定の一部は、セッションごとに個別に上書きできます。

ロケーション設定には、ロケーションバー内の各ロケーションの項目にある <Cog /> シンボルからアクセスできます。
ロケーション設定では、Admin、Grid、Vision の3つのタブを持つダイアログが開きます。

キャンペーンデフォルトを上書きするように設定されたすべての設定は、リセットされるまでそのまま維持されます。
キャンペーンデフォルトと同じ値になるように設定を手動で定義しても、デフォルトとのリンクは再確立されません。キャンペーンデフォルトがさらに変更されても、この値が維持されます。

### Admin

ロケーション設定の _Admin_ タブでは、ロケーションの名前の変更、アーカイブ、削除ができます。

アーカイブされたロケーションは、ロケーションバーから消えます。
アーカイブされたロケーションをロケーションバーに復元するには、ロケーションバーの `Show archived locations` ボタンからアーカイブにアクセスします。
アーカイブされたすべてのロケーションのリストが開きます。
`select` をクリックすると復元されます。

<Image src={RenameLocation} alt="ロケーション名の変更メニュー" />

アーカイブまたは削除できるのは、プレイヤーも DM も誰もいないロケーションのみです。

### Grid

[キャンペーン設定の「Grid」](/ja/docs/dm/settings/#grid) を参照してください。

### Vision

## ロケーションの変更

ロケーションバーを開いた状態で、DM は目的のロケーションの名前が表示されたブロックをクリックするだけで、ロケーションを変更できます。

プレイヤーは自分でロケーションを変更することはできません。
招待を受けたプレイヤーは、プレイヤーがいる既存のロケーションに参加します（そのプレイヤーがその時点でログインしているかどうかは関係ありません）。
キャンペーンに他のプレイヤーがいない場合、最初に招待に応じたプレイヤーは、DM がアクティブにしているロケーションに参加します。
プレイヤーは、DM に別のロケーションへドラッグされるまで、アクティブなロケーションに留まります。

プレイヤーは、ここに示すように、グループとして、または個別にドラッグできます。

別のロケーションに送られたプレイヤーは、自分が操作しているシェイプを一緒に持ち込むことは _できません_。
代わりに、それらのシェイプは DM がそのロケーションに送る必要があります。

## シェイプを別のロケーションに移動する

ロケーションにスポーンが1つ以上ある場合、シェイプは右クリックのコンテキストメニューから、個別に、またはグループとしてそのロケーションに移動できます。

DM は、スポーンを配置したい領域を右クリックして 'create spawntoken' アクションを選択することで、1つまたは複数のスポーンを作成できます。

別のロケーションに送信されると、シェイプは選択したスポーン位置を中心に表示されます。スポーン位置は、_dm_ [レイヤー](/ja/docs/dm/layers/#dm) に表示される特別なシェイプです。

<Image src={SpawnPicture} width={51} aspectRatio={51 / 51} alt="スポーン位置シンボル" />

スポーン位置マーカーは _dm_ レイヤー上で自由に移動できます。
0.23 以降、スポーン位置は好きなだけ削除したり作成したりできます。
