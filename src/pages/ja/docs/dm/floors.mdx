# フロア

積み重ねられた [レイヤー](/ja/docs/dm/layers/) の完全なセットを _フロア_ と呼びます。

フロアは互いの上に描画されます。
したがって、新しく作成したフロアでは、その下にあるフロアが完全に見えます。
これは、他に何も覆われていないゲームボードのすべての部分に当てはまります。_map_ レイヤー上のアセットであれ、_tokens_ レイヤー上のシェイプであれ、同様です。

<Image src={FloorsPicture} width={300} aspectRatio={314 / 277} alt="フロアメニューを開いたフロアボタン" />

フロアには、画面左下のフロアボタンからアクセスできます。
フロアには番号（開いたメニューの左側に表示）と名前（右側に表示）があります。
フロアボタンには、アクティブなフロアの番号が常に表示されます。

**便利なヒント**: [移動のキーバインド](/ja/docs/reference/#movement) を確認すれば、フロアの移動が簡単になります！

どの [ロケーション](/ja/docs/dm/locations) にも常に少なくとも1つのフロアがあります。したがって、ロケーションを作成すると、最初のフロアが自動的に作成されます。
最初のフロアは `ground` という名前で、番号は `0` になります。`0` は常にスタックの最下部にあるフロアの番号です。

フロアは表示順に一覧表示されます。一番高いフロアが最初に表示されます。

フロアは没入感や演出を高めるための非常に便利なツールであり、該当する場合には積極的に使用することをお勧めします。ただし、フロアごとにレンダリング時間が増加することに注意してください。この負荷を軽減するための最適化（例: 高い位置にあるフロアはレンダリング・計算されない）はありますが、念頭に置いておいてください。

## 新しいフロアの作成

`Add new floor` をクリックすると、新しいフロアを作成できます。
ポップアップでフロアの名前を入力するよう求められます。

<Info title="重複不可">1つのロケーション内のフロアに同じ名前を付けることはできません。</Info>

## フロアの並べ替え

フロアを別の位置にドラッグすると、並べ替えることができます。フロア上のすべてのオブジェクトは、そのフロアに紐付けられたままです。

## フロアの操作

### 名前の変更

鉛筆アイコン <PencilAlt/> をクリックするとポップアップが表示され、フロアの新しい名前を入力できます。

### プレイヤーのアクセス権を切り替える

目アイコン <Eye/> をクリックすると、プレイヤーがこのフロアに手動でアクセスできるかどうかを切り替えられます。

**注意**: これはフロアを隠すわけではありません！ フロアが見える窓がある場合があります。

### 削除

フロアの削除は、開いたメニューで <TrashAlt /> ボタンをクリックするだけの簡単な操作です。
_この操作は元に戻せないため_、フロアの削除を確認する必要があります！

削除すると、フロアはスタックから取り除かれて破棄されます。フロア上のすべてのオブジェクトも削除されます。
