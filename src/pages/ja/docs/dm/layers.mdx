# レイヤー

<Image src={LayersPicture} width={800} aspectRatio={861 / 404} alt="レイヤー情報" />

PlanarAlly はゲームボードを複数のレイヤーに整理しています。
レイヤーは互いの上に描画されます。
これらの複数のレイヤーが、プレイ時に表示される結果を作り出します。

各レイヤーにはそれぞれ専用の用途があります。
DM がそれぞれの目的を理解することが重要です。
各レイヤーの概要については、[クイックリファレンス](/ja/docs/reference/) ドキュメントを確認してください。
より詳しい内容については、このまま読み進めてください！

DM レイヤーを除き、すべてのレイヤーはプレイヤーのボードにも描画されます。
ただし、プレイヤーが操作できるのは tokens レイヤー上の要素のみです。

_現在、これらのレイヤーはハードコードされていますが、将来は自分の好みに合わせて調整できるようになる可能性があると考えています。_

## Map

描画スタックの最下部にあるのが map レイヤーです。
このレイヤーは、マップや建物のレイアウトなどを配置するためのものです。

このレイヤーは grid レイヤーの下に描画されます。
これにより、グリッド線をさまざまなダンジョンに合わせることができます。
それ以外は、このレイヤーは tokens レイヤーと同じように動作します。

## Grid

このレイヤーは手動で選択することはできませんが、[DM 設定メニュー](/ja/docs/dm/settings/) から設定できます。
このレイヤーは画面にグリッド線を描画します。

グリッド線は、正方形（デフォルト）または六角形のいずれかになります。
フラットトップとポイントトップの両方のヘックスグリッドを描画できますが、現在は実験的にのみサポートされています。

<Warning title="実験的">
    ヘックスグリッドは実験的な機能であるため、通常とは異なる動作が頻繁に発生する可能性があります。その一例が、
    ヘックスグリッドが表示されているにもかかわらず、グリッドスナップが正方形グリッドと同じように機能するというものです。
</Warning>

## Tokens

ゲームプレイの中核はこのレイヤーで行われます。
プレイヤーやノンプレイヤーキャラクター（NPC）が移動する場所です。
このレイヤーをアクティブにしていることが多いでしょう。

## DM

このレイヤーにアクセスできるのは DM のみです。
プレイヤーはこのレイヤーの内容を一切見ることができません。
事前にエンカウンターを計画するために使用できます。
重要な情報を記録するためのテキストラベルを配置するためにも使用できます。

シェイプのレイヤーを変更することもできます。
プレイヤーにまだ見せたくないアセットを DM レイヤーに隠しておくことで、プレイヤーが情報を事前に見てしまうのを防げます。

## FOW

このレイヤーには、視野をサポートする特別な動作があります。

壁を描くとき、壁は固定されたままにしたいはずです。
プレイヤーにまだ見せるべきでないマップの一部を見られてしまう可能性があるため、壁が変わってしまわないようにしたいものです。
壁を vision レイヤーに描くことで、tokens レイヤーを操作するときに壁を誤って動かしてしまうことがなくなります。
そのため、このレイヤーは次の2つの魔法のような処理を自動的に行います。

このレイヤーに描くシェイプのほとんどは壁やドアに使用されるため、このレイヤーに描画されたシェイプには 'blocks movement' と 'blocks vision' の設定が自動的に適用されます。
'Blocks movement' は、プレイヤーがこれらのシェイプを通り抜けるのを防ぎます。
'Blocks vision' は、プレイヤーがこれらのシェイプを見通すのを防ぎます。
不要であればこれらのオプションの選択を解除できますが、このレイヤーではデフォルトで適用されることを認識しておいてください。

このレイヤーに描画された **すべて** のものは、他のレイヤーでは見えません。
これは、通常、マップにはあらかじめ壁が描かれているためです。
照明システムに壁を知らせるために見苦しい黒い四角形を描いたとしても、tokens レイヤーでその見苦しい塊を見たくはないはずです。

このレイヤーは純粋に利便性のために用意されています。
自動設定や見えないという点が気に入らない場合は、tokens レイヤーを使用して、お好みの設定で壁を描くことができます。
