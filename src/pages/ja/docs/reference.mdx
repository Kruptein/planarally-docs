# クイックリファレンス

## デフォルトレイヤー

レイヤーの詳細については[レイヤーのドキュメント](/ja/docs/dm/layers/)を参照してください。

| 名前   | プレイヤーに表示 | プレイヤーが編集可能 | 簡単な説明                                                   |
| ------ | ---------------- | -------------------- | ------------------------------------------------------------ |
| Map    | はい             | いいえ               | 通常はマップアセットに使われるグリッドの下のレイヤー         |
| Grid   | はい             | いいえ               | DM でも選択できませんが、セッション設定で構成できます        |
| Tokens | はい             | はい                 | メインのゲームボード                                         |
| DM     | いいえ           | いいえ               | DM がプレイヤーに隠したオブジェクトを配置する場所            |
| Vision | はい             | いいえ               | このレイヤーのすべてのシェイプは、他のレイヤーでは見えません |

## キーバインド

Mac では、`Ctrl` の代わりに `Command` を使用してください。

### 移動

キーバインドの多くは、シェイプまたは画面の移動に割り当てられています。

| キー/修飾キー              | コンテキスト | 動作                                                    |
| -------------------------- | ------------ | ------------------------------------------------------- |
| 矢印キー、Numpad 1-4、6-9  | 選択なし     | 押した方向にボードを 1 グリッドセル分移動               |
|                            | 選択中       | 選択したシェイプを押した方向に 1 グリッドセル分移動     |
| Space、Numpad 0            |              | 画面を次のトークンに合わせる(所有トークンを順番に巡回)  |
| Shift                      | 選択中       | 移動をブロックする地形を通過してシェイプを移動(DM のみ) |
| Ctrl + 0、Numpad 5         |              | グリッドの原点 (0,0) に焦点を合わせる                   |
| Numpad 5                   | 選択中       | 選択範囲の中心に焦点を合わせる                          |
| マウス中クリック(長押し)   |              | 画面をパンする                                          |
| マウス中ホイール           |              | 現在のマウスポインターを基準にズームする。              |
| Page up/down               |              | カメラのフロアを上下に移動                              |
| Page up/down + alt         | 選択中       | 選択範囲のフロアを上下に移動                            |
| Page up/down + shift + alt | 選択中       | 選択範囲とカメラのフロアを上下に移動                    |

### 動作

| キー/修飾キー    | コンテキスト | 動作                                                   |
| ---------------- | ------------ | ------------------------------------------------------ |
| Tab              |              | モードの切り替え(Build/Play)                           |
| Alt (長押し)     |              | [スナップ動作](/ja/docs/game/snapping)を無効にする     |
| Ctrl + u         |              | UI の表示切り替え                                      |
| Ctrl + z         |              | 元に戻す                                               |
| Ctrl + shift + z |              | やり直す                                               |
| n                |              | [ノートマネージャー](/ja/docs/game/notes)を開く        |
| Space            | ruler        | [ルーラー](/ja/docs/tools/ruler)のウェイポイントを設定 |

### 選択 / シェイプの操作

| キー/修飾キー  | コンテキスト | 動作                                                   |
| -------------- | ------------ | ------------------------------------------------------ |
| Enter          | 選択中       | シェイプの編集ダイアログを開く                         |
| Ctrl           | 選択中       | Ctrl 選択したシェイプでアクティブな選択を拡張          |
|                | サイズ変更   | 縦横比を維持                                           |
| Space          | 選択中       | [ルーラー](/ja/docs/tools/ruler)のウェイポイントを設定 |
| Del、Backspace | 選択中       | アクティブな選択内のすべてのシェイプを削除             |
| d              | 選択中       | 現在選択されているすべてのシェイプを選択解除           |
| x              | 選択中       | シェイプを敗北としてマーク                             |
| Ctrl + l       | 選択中       | 選択したシェイプをロック/ロック解除                    |
| Ctrl + c       | 選択中       | 選択範囲をクリップボードにコピー                       |
| Ctrl + v       |              | クリップボードからボードに貼り付け                     |
