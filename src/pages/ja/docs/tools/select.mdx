# ツール Select

Select ツールは、最もよく使用されるツールのひとつです。その目的は、名前が示すとおり、ゲームボード上で1つまたは複数のシェイプを選択することですが、移動にも使用できます。
このツールは、画面右下のツールバーからすべてのプレイヤーがアクセスできますが、アクティブな[モード](/ja/docs/tools-overview/#toolbar-and-modes)によって動作が異なります。

さらに、Build モードでは、シェイプの回転とサイズ変更も行えます。

## 選択の基本

単一のシェイプをクリックするか、グループの周囲にボックスをドラッグすると、それらをまとめて移動できます。

既存の選択にシェイプを追加するには、`Ctrl` を押しながら新しいシェイプを選択します。

選択を解除するには、ゲームボード上の何もない場所をクリックするか、キーボードショートカットの `d` を使用します。

_グループ選択では、実際に所有しているシェイプのみが選択されます。これは、所有していないシェイプも選択できる通常のクリック動作とは対照的です。_

## 移動

選択範囲をマップ上でドラッグするだけで移動できます。

DM はオブジェクトを通行不可（例：壁）として定義できます。
これらのオブジェクトは移動を停止させます。
DM とすべての Co-DM は、`shift` キーを押している間、移動制限を無視できます。

ツールバーの `select` ツールボタンの上にある `show ruler` トグルを有効にすると、オブジェクトをドラッグした際に、移動した距離を測定するルーラーも表示されます。
このルーラーは[独立したルーラーツール](/ja/docs/tools/ruler/)と同様に動作し、設定も共有します。

## サイズ変更

_シェイプのサイズを変更するには、'build' モードである必要があります_

サイズ変更は、シェイプの角のひとつをつかんで別の場所にドラッグするだけで行えます。
ほとんどのサイズ変更操作はドラッグした角にのみ影響し、他の角はその場に留まります。

現在の唯一の例外は円で、サイズ変更時に半径が増減します。
この動作は将来変更される可能性があります。

## 回転

_シェイプを回転するには、'build' モードである必要があります_

Build モードでは、アンカーポイントとボックスを表示する特別な回転 UI が表示されます。

アンカーを移動すると、ボックス全体がその中心点を中心に回転します。

シェイプの回転は単一のシェイプに限定されず、グループ全体にも適用できます。
ボックスの中心が回転の基準点として使用されることに注意してください。

## 選択順序

ゲームボード上のシェイプは特定の順序で描画され、重なった場合にどのシェイプが選択されるかを決定します。

シェイプを右クリックして、スタックの背面または前面に移動することで、順序を変更できます。
