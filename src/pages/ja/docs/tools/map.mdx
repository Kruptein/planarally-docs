# ツール Map

Map ツールは、ゲームボードの右下にあるツールバーから利用できますが、[Build モード](/ja/docs/tools-overview/#toolbar-and-modes)かつ GM のみが利用できます。
カスタムシェイプをグリッドにフィットさせるための簡単な方法を提供します。
任意のシェイプのサイズ変更に使用できますが、主な用途はマップに焦点を当てています。

Map ツールを使用するには、まずシェイプを選択する必要があります。
選択されていない場合、Map ツールはその旨を通知し、Select ツールに切り替えることなく、Map ツール内からシェイプを選択できます。

シェイプを選択すると、このシェイプ内で参照として使用する領域を選択するか、画像全体を拡大縮小できます。
どちらの場合も画像全体が拡大縮小されることに注意してください。
「画像全体の拡大縮小」は、参照用に一部だけを選択するのではなく、画像全体を参照として使用します。

## 領域の選択

領域の選択は、その周囲にボックスをドラッグして行います。
たとえば、グリッド上の3×3の領域を表すべき領域を選択できます。
最初の選択後、この選択範囲をリサイズしたり微調整して、希望する領域を正確にカバーしていることを確認できます。

選択範囲が適切であれば、選択範囲が占めるべき X と Y の寸法を入力して、適用を押します。

## 画像全体の拡大縮小

「画像全体の拡大縮小」は、拡大縮小の参照として画像全体を使用します。
これは、ターゲットのグリッドセル数を設定するか、ターゲットのピクセル数を設定することで行えます。
グリッドセルをターゲットにすると、画像は指定された数のグリッドセルをカバーし、ピクセルをターゲットにすると、入力に応じて画像のサイズが変更されます。
どちらの方法でも、入力の右側にある「リンク」シンボルを接続することで、画像のアスペクト比を維持できます。
