# クイックトグル

DM ツールバーの下には、追加のアイコンがいくつかあります。これらはクイックトグルで、さまざまな用途に役立ちます。

<Image src={QuickTogglesImage} width={150} alt="イニシアチブツールの概要" />

## フェイクプレイヤー

これを有効にすると、DM の画面はフェイクプレイヤーモードであるかのようにレンダリングされます（[フェイクプレイヤー](/ja/docs/dm/settings/#fake-player)を参照）。

## 視線

このクイックトグルは、[視線](/ja/docs/dm/settings/#only-los)が有効になっている場合にのみ表示されます。

これにより、自分の画面でのみ LoS を無効にできます。フェイクプレイヤーのトグルと同様に、事前準備中の照明と視野の設定の確認に役立ちます。
LoS が有効な場合は緑色で表示され、（一時的に）無効になっている場合は赤色で表示されます。

特に、視野アクセス用のシェイプがまだ用意されていない可能性が高い新しいロケーションで作業する場合に、一時的なシェイプを作成することなく、設定した照明を確認するためにこれを使用できます。

## イニシアチブ

イニシアチブのクイックトグルは、他のトグルに比べて利便性の向上という側面が強いです。
有効にすると（再度クリックするまで）緑色になり、[イニシアチブ](/ja/docs/tools/initiative/)がアクティブであることを示します。

すべてのプレイヤーに対してイニシアチブ UI が自動的に開き、[Initiative 設定](/ja/docs/game/settings/#initiative)の一部が有効になります。
これらの設定は、このトグルを使用してイニシアチブが明示的に有効になっている場合にのみアクティブになります!
