# ツール Draw

Draw ツールは、画面右下のツールバーからすべてのプレイヤーが利用できますが、[Build モード](/ja/docs/tools-overview/#toolbar-and-modes)でのみ利用できます。

このツールでは、ゲームボード上にシェイプを描画でき、シェイプ、視野、ロジックの3つのセクションで構成されています。

## シェイプ設定

シェイプ設定では、描画するシェイプを選択できるほか、シェイプの一般的な基本プロパティも設定できます。

ほとんどのシェイプでは、塗りつぶし色や枠線の色を設定できます。

### 長方形

最もシンプルなシェイプの1つである*長方形*です。マウスボタンを押している間は、離したときにどのような長方形になるかのプレビューが表示されます。

### 円

*円*も長方形と同様に非常にシンプルです。描かれた円は、マウスボタンを押した位置を中心とし、マウスボタンを離した位置に基づいた半径を持ちます。

### ポリゴン / ライン

*ポリゴン / ライン*はおそらく最も複雑なシェイプですが、最も柔軟に利用できます。

他のシェイプとは異なり、描画中にマウスボタンを押し続ける必要はありません。代わりに、ゲームボード上のどこかをクリックするたびに新しいポイントが現れ、そのポイントと前のポイントが線で結ばれます。既存のポイントを交差させたり、再利用したりすることも自由です。

シェイプが完成したことを合図するには、現在はマウスの右ボタンを使用します。描画をキャンセルするには Escape キーを押します。

閉じたポリゴンのチェックボックスをオンにすると、シェイプの完成時に最後のポイントと最初のポイントが自動的に接続され、ポリゴンが塗りつぶし色で埋められます。

### 絵筆

もう1つの描画モードは*絵筆*です。これは自由描画のオプションで、自由に描画することができます。

<Warning title="パフォーマンス">
    _絵筆_での描画は、シェイプを表現するために大量のポイントを使用する必要があることに注意してください。パフォーマンス面では
    かなり劣るため、一般的には小さなものにのみ使用することをお勧めします。
</Warning>

### テキスト

最後の描画モードは*テキスト*です。
後からサイズ自体を変更することはできないため、描画前にフォントサイズを設定してください。
ただし、テキストオブジェクトは自由に拡大縮小できます。

他の描画モードのようなドラッグ操作ではなく、テキストの描画は1回のクリックで行います。
クリックすると、表示するテキストを尋ねるポップアップが開きます。

入力されたテキストは、シンプルなトークンに使用されるセリフフォントでレンダリングされ、最初の手順で*クリックした位置を中心に*配置されます。
他のシェイプと同様に、ドラッグやサイズ変更などが可能です。

<Tip title="編集">シェイプのプロパティダイアログで、後からテキストを編集できます!</Tip>

## 視野設定

視野設定では、描画するシェイプの照明と視野設定を事前に構成できます。

ブロック設定は、戦争の霧レイヤーとの切り替え時に自動的にトグルされますが、必要に応じて自由に変更できます。

ブロック設定が1つ以上有効になっている場合、ツールの<Eye />アイコンがオレンジ色の背景で表示され、視覚的なリマインダーになります。

### DM 限定モード

DM は、このセクションで追加の視野描画モードも選択できます。

*通常*モードは、期待通りデフォルトの動作です。

*表示*と*非表示*は、それぞれ「魔法の光」または「闇」を描画します。
詳細については、[魔法の光と闇のドキュメント](/ja/docs/dm/lighting-vision/#magical-lights-and-darkness)を参照してください。

*消去*は、描画スタック内で*下にある*すべてのオブジェクト（[フロア](/ja/docs/dm/floors/)を含む）を貫通する（持ち運び可能な）「穴」として機能するシェイプを作成します。
*消去*されたシェイプは自動的に[マップレイヤー](/ja/docs/game/gameboard/#map)にドロップされますが、任意のレイヤーに移動できます。

消去モードの詳細については、[0.26 リリースノート](/ja/blog/release-0.26#erase-floor-mode-dm)を参照してください。

## ロジック設定

これにより、シェイプのドアロジックを事前に構成できます。

壁やドアをマッピングする際に、多くの時間を節約できます!

詳細については、[シェイプロジック](/ja/docs/game/shapes/#logic)を参照してください。
