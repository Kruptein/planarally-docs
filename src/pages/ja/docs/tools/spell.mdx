# ツール Spell

Spell ツールは、画面右下のツールバーからすべてのプレイヤーがアクセスできますが、[Play モード](/ja/docs/tools-overview/#toolbar-and-modes)でのみ使用できます。

描画ツールといくつかの類似点がありますが、プレイ中にスペルを唱えることに特化しています。

スペルのシェイプ（四角形/円/円錐）を選択し、サイズ、射程、色、そして最後にスペルを他のプレイヤーと共有するか、自分のみにするかを設定できます。

スペルのシェイプのリストにライン（直線）が目立って欠けていますが、これはスペルを唱える際の一般的なパターンです。
既存のルーラーツールで十分に対応できると判断し、Spell ツールに余分な機能を追加する必要はないと考えました。

## 一般的な操作

射程が0に設定されていない限り、Spell ツールがアクティブな間、スペルは常にマウスに追従します。

デフォルトのスペルモードは、例えば何人のプレイヤーを対象にできるかをすばやく測定するためにのみ使用されます。
ツールを変更すると、スペルは消えます。

瞬間的な効果ではなく、戦場に長く留まるスペルがある場合は、**左クリック**することでスペルを実際のシェイプにできます。
自動的に Select ツールに切り替わります。

クリックを間違えた場合や、スペル効果が切れた場合は、他のシェイプと同様にスペルを削除できます。
また、'show public' がオフになっている場合、スペルを'唱えた'瞬間に、そのスペルは'invisible'プロパティを持つことになることにも注意してください。
一度唱えた後にこのプロパティを削除することを妨げるものはありません。

右クリックでも Select ツールに戻りますが、スペルは唱えられません。
これは'キャンセル'操作として用意されています。

## 選択コンテキスト

円錐シェイプと射程パラメータは、シェイプがアクティブに選択されている場合にのみ利用できます。

前者については、セルフキャストではない円錐が実際に使用されている例を見つけることができなかったためです。
また、セルフキャスト以外の場合の回転に関する UX の使い勝手を想像するのが難しかったためでもあります。

後者については、そうでなければ基準点がないためです。

## サイズ

サイズパラメータは、スペルがカバーする領域を決定します。
四角形の場合は1辺の長さです。
円と円錐の場合はスペルの半径です！

オーラと同様に、これらの数値は設定された単位サイズに基づいて定義され、デフォルトは5 ft.です（DM グリッド設定を参照）。

## 射程

_上記のとおり、スペルの射程は、アクティブなシェイプが選択されている場合にのみ設定できます。_

射程が0に設定されている場合、セルフキャストとみなされ、スペルは自動的にアクティブなシェイプの中心に配置されます。

射程が0より大きい数値の場合、設定された射程と等しい半径を持つ黒い円が表示されます。
