# ツール Vision

Vision ツールは、両方の[モード](/ja/docs/tools-overview/#toolbar-and-modes)でゲームボード右下のツールバーからアクセスできます。
複数のトークンの視野を追跡するのに役立ちます。
その動作は、プレイヤーと DM で異なります。

## プレイヤー

クリックすると、Vision ツールは、プレイヤー向けに[視野アクセスが設定されている](/ja/docs/game/shapes/#access)すべてのオブジェクトのリストを開きます。
デフォルトでは、色付きの背景で示されるアクティブな状態でリストに表示されます。
すべてのモードとツールは、Vision ツール内に*アクティブ*なエントリがあるトークンの視野のみを表示します。

クリックすると、エントリが非アクティブになり、背景色が灰色で表示されます。
同時に、このトークンの視野はゲームボードに表示されなくなります。

## DM

デフォルトでは、DM は常にすべてを見ることができます。
Vision ツールだけを使用しても、それは変わりません。
ただし、[フェイクプレイヤー](/ja/docs/dm/settings/#fake-player)を使用して、上記と同様の効果を得ることができます。
この場合、Vision ツールを使用して、どのプレイヤーの視野を見たいかを定義します。
