# ツール Ruler

Ruler ツールは、[モード](/ja/docs/tools-overview/#toolbar-and-modes)に関係なく、ゲームボードの右下にあるツールバーから利用できます。
距離を測定するためのシンプルなツールです。

クリックした場所から、マウスカーソルまでの距離を示す数値とともに線が描画され、マウスを離すまで表示されます。
途中で `space` を押すとウェイポイントが設定され、オブジェクトの周りの距離を簡単に測定できます。
ヤード・ポンド法を前提に設計されたゲームでメートル法を使用できるように、小数第1位まで表示します（例: D&D の標準的な5フィートのグリッドは 1.5 m に相当します）。

ツールバーの `Ruler` ボタンの上に表示される `Share with others` オプションをオンにすると、このルーラーはセッション内のすべてのプレイヤーに**公開**表示されます。
このオプションをオフにすると、ルーラーはあなただけに表示されます。
この設定は、[Select ツール](/ja/docs/tools/select/)に組み込まれたルーラーでも使用されます。

ルーラーの描画色は、各プレイヤーが[クライアント設定](/ja/docs/game/settings/)で選択できます。
ルーラーには[スナップ動作](/ja/docs/game/snapping/)もあり、グリッド上の論理的な位置にスナップしようとします。
