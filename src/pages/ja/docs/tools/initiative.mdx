# ツール Initiative

Initiative ツールは、移動可能なポップアップウィンドウで、さまざまなオブジェクト（通常はトークン）のイニシアチブの順番を管理できます。

<Image src={InitiativeOverviewPicture} width={462} aspectRatio={462 / 492} alt="イニシアチブツールの概要" />

## アクセス方法

Initiative ツールは、ユーザーインターフェースの右下にあるツールバーからは利用できません。
代わりに、コンテキストメニューからアクセスします。
マップ上の任意の場所を右クリックすると、コンテキストメニューでいつでも `Show Initiative` を選択でき、ツールを起動できます。
また、オブジェクト（シェイプ、アセット、トークン）のコンテキストメニューにも、オブジェクトが既にイニシアチブリストに登録されている場合、`Show Initiative` オプションが表示されます。
対象のオブジェクトがイニシアチブリストに（まだ）登録されていない場合、コンテキストメニューには `Add Initiative`（複数のオブジェクトを選択している場合は `Add all to Initiative`）が表示され、Initiative ツールを開くと同時にオブジェクトをリストに追加します。

Initiative ツールは移動可能なポップアップウィンドウを開き、右上隅の<WindowClose />をクリックすると閉じられます。

ウィンドウには、複数の個別エントリを含めることができるイニシアチブリストと、その下にいくつかの機能を持つバーが含まれています。

## イニシアチブリスト

イニシアチブリストは、基本的には6つの列と、イニシアチブリストに追加された各オブジェクトの行で構成される表です。
*アクティブ*な行/エントリは緑色の背景で強調表示され、そのオブジェクトのターンであることを示します。

エントリにカーソルを合わせると、登録されたシェイプの名前が表示され、マップ上の関連オブジェクトが赤い四角で囲まれて強調表示されます。
これは、同じアセット（つまり、似たようなモンスターなど）で描かれたオブジェクトがマップ上に複数ある場合に特に便利です。

### 識別子

各行の一番左には、イニシアチブに追加されたシェイプの識別子があります。
オブジェクトがアセットの場合、識別子はアセットの縮小版になります。
オブジェクトが Basic Token の場合、識別子はトークンに表示されているテキストになります。
オブジェクトが他のシェイプの場合、識別子は、オブジェクトがイニシアチブに追加されたときにプロパティに入力されたシェイプの名前になります。

### イニシアチブの値と並べ替え

識別子の次に、任意の数値を指定できるイニシアチブ値が続きます。
プレイヤーは、アクセスを許可されたオブジェクトのイニシアチブ値のみを変更できます。
DM はリスト内のすべてのオブジェクトのイニシアチブ値を変更できます。

エントリはこの値によって自動的に並べ替えられ、値が大きいものがリストの上部に、小さいものが下部に配置されます。
エントリにカーソルを合わせると、右下隅に切り欠きのある境界線で強調表示されます。
この切り欠きをクリックして押したままにすると、任意の項目をドラッグでき、自動並べ替えを無効にできます。

### 時間制エフェクト

次の列には<Stopwatch />と、それに続く数値（デフォルトは 0）が表示されます。
この列は、オブジェクトに割り当てられた時間制エフェクトの数を示します（下記参照）。
この機能は、時間経過でダメージを与えるバフやエフェクト（例: スペル）を簡単に追跡するために使用できます。

時間制エフェクトは、限られた時間（つまりラウンド）だけ有効な自由形式のエントリで、イニシアチブリストのエントリに割り当てられます。

<Stopwatch />
アイコンを左クリックすると、対応するエントリに関連付けられた新しい時間制エフェクトが追加されます。
エントリにカーソルを合わせると、強調表示された境界線に連動して、下に時間制エフェクトのリストが展開されます。
アクティブなエントリの時間制エフェクトのリストは常に展開されています。

時間制エフェクトはいつでも追加できます。
DM は任意のエントリにエフェクトを追加できますが、プレイヤーはアクセスを許可されたエントリにのみ追加できます。

各時間制エフェクトには、記述子と期間の2つの値があります。
記述子は左側に表示され（作成時のデフォルト: `New Effect`）、任意のテキストを指定できます。
期間は右側に表示され（デフォルト: `10`）、数値である必要があり、今後のラウンドでのエフェクトの持続時間を表します。
エントリが*アクティブ*になるたびに、期間が `0` になるまで1ずつ減少します。

期間が `0` に達した後、次にエントリがアクティブになるタイミングで、`0` から `-1` に変わる代わりに、時間制エフェクトは消滅します。
その横にあるゴミ箱<TrashAlt />ボタンをクリックすると削除できます。

### 表示

次の列には、エントリの表示を切り替える<Eye />が表示されます。

<Eye />
が灰色で表示されている場合、オブジェクトは非表示であり、つまりその行は DM だけが表示できます。
プレイヤーが追加したオブジェクトはデフォルトで表示され、DM
がイニシアチブに追加したオブジェクトはデフォルトで非表示になります。

### グループイニシアチブ

右から2番目の列には<Users />アイコンが表示されます。
アイコンをクリックすると、個別/グループイニシアチブが切り替わります。

エントリが*グループイニシアチブ*としてマークされている場合、ゴミ箱<TrashAlt />シンボルをクリックしても、関連するオブジェクトを削除しても、そのエントリは削除できません（下記参照）。
マウスオーバー時には関連トークンが強調表示されますが、現時点では複数のオブジェクトを一度に強調表示する機能はありません。

### 削除

一番右の列の<TrashAlt />は、リストからエントリを削除するためのものです。
DM はイニシアチブリストから任意のエントリを削除できます。
プレイヤーはアクセスを許可されたエントリのみを削除できます。

イニシアチブに追加されたトークンを削除したり、別のロケーションに移動したりすると、Initiative ツール内の関連エントリも削除されます。

グループイニシアチブに追加されたエントリ（上記参照）は削除できません。

## 機能バー

機能バーは1行で構成され、左側に現在のアクション/戦闘のラウンドを示す `Round` インジケーター、その右側に4つのボタンがあります。

### 視野オートロック

<Eye />
は視野の自動ロックを切り替えます。この機能は、複数のトークンを所有しているプレイヤーに便利です。有効にすると、アクションが別のオブジェクトに割り当てられるたびに（下記の[次のターン](/ja/docs/tools/initiative/#next-turn)を参照）、そのオブジェクトの視野のみが表示されます。これは各プレイヤーが個別にオン/オフを切り替えられます。視野の自動ロックは、プレイヤーが適切なアクセス権を持つオブジェクトの視野のみを表示します。

<Info title="Vision ツール">
    視野の自動ロックは、[Vision
    ツール](/ja/docs/tools/vision/)の再設定をトリガーします。そのツールを使用して、イニシアチブ外で
    表示したい視線を構成してください。
</Info>

DM は常にすべてを表示できるため、このボタンは DM には機能がありません。

### カメラオートロック

<Video />
はカメラの自動ロックを切り替えます。
カメラの自動ロックが有効な場合、アクションが別のオブジェクトに割り当てられるたびに（下記参照）、ビューポートがアクティブになったオブジェクトの中央に配置されます。
これは各プレイヤーが個別にオン/オフを切り替えられます。
カメラの自動ロックは、プレイヤーが操作できるオブジェクトにのみビューポートの中央を合わせます。 したがって、DM
の場合、_Next_ をクリックするたびにビューポートの中心が実質的に変わります。
プレイヤーのビューポートは、自分が操作するトークンがイニシアチブトラッカーに従ってアクティブになった場合にのみ変更されます。

### リセット

<SyncAlt />
ボタンはラウンドとターンをリセットします。 ラウンドはラウンド 0
にリセットされ、アクションはリストの先頭のオブジェクトに割り当てられます。
イニシアチブ値と時間制エフェクトはリセットされないことに注意してください。 この機能は DM のみが利用できます。

### 次のターン

<ChevronRight />
ボタン（_Next_）は、イニシアチブ順で次のプレイヤーを_アクティブ_として割り当てます（上記参照）。 この機能は DM
のみが利用できます。
