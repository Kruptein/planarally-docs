# ツール Ping

Ping ツールは、ゲームボードの右下にあるツールバーから利用できますが、[Play モード](/ja/docs/tools-overview/#toolbar-and-modes)でのみ利用できます。
これは、必要最小限の「ビーコン」ツールとして機能します。
マウスを押している間、現在のマウスの位置に2つの円がすべてのプレイヤーに表示されます。

Ping の円は、[クライアント設定](/ja/docs/game/settings/)で設定したルーラーの色と同じ色を使用します。
