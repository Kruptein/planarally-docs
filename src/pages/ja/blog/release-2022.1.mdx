前回のリリースから*かなり*長い時間が経ってしまいました。半年以上かかってしまい、その理由はいろいろあるのですが、結局はお詫びしかありません。近いうちにもっと定期的にリリースできることを願っています :)

## バージョン形式の変更

_本当に変わったことだけ知りたい方は、この部分は読み飛ばして構いません!_

PlanarAlly に詳しい方なら、バージョン番号が変わったことにも気付くでしょう。これは 2021 年の総括記事でほのめかしていたことで、2022 年の最初のバージョンで実装することにしました。

元のバージョニング方式にも必ずしも問題があったわけではありませんが、私の意見では、1.0.0 に変更するほどの劇的な変化は見込めなかったため、最初の番号は実質的に意味を失ってしまいます。右肩上がりに増え続けるマイナーバージョン番号も良い解決策とは思えなかったので、何か新しいものに切り替える時期だったのです。

バージョンスキームを major.minor.patch 形式から year.minor.patch 形式に変更し、毎年 1.0 から新しく始まるようにします。これにより、バージョン番号を小さく保ち、容易に把握できるようになるとともに、明確な期間に位置付けられます。一方、0.18.0 では過去 3 年のどの時点のものか分かりませんでした。

## ロジックシステム

今回のリリースの主な新機能は、シェイプに追加できる小さなロジックモジュールです。今回はドアとテレポートゾーンの 2 種類が追加されます。

シェイプ編集ダイアログに新しいタブが追加され、これらのモジュールの有効化・無効化・動作設定ができるようになりました。

#### 権限

どちらのモジュールも権限システムで設定できます。DM は常にアクセス権を持ち、既定ではそれ以外のプレイヤーにはありません。既定のアクセス権を変更できるほか、特定のプレイヤーに対して有効/リクエスト/無効のいずれかに設定できます。リクエストを選択した場合、DM に許可・拒否の通知が届きます。

### ドア

プレイヤーが別のエリアへのアクセスを妨げるシェイプに遭遇した場合、DM がこの障害を乗り越えられるようにする方法はいくつかあります。DM は shift キーの魔法の力でオブジェクトの上にプレイヤーを移動させたり、シェイプを削除したり、シェイプのプロパティで「視界を遮る」と「移動を遮る」プロパティを無効にしたり、Build モードに入ってプレイヤーが通り抜けられるようにシェイプをドラッグしたりできます。

私は個人的に最後の方法を使うことが多かったのですが、私のドアはたいてい戦争の霧レイヤー上にあったため、レイヤーとモードの両方を切り替える必要があり、要するに少し面倒でした。

そこで役立つのがドアモジュールです。シェイプをドアとして設定すると、Play モードで任意のレイヤーからシェイプをクリックするだけで、遮断プロパティを即座に切り替えられます。簡単で便利ですね!

さらに使いやすくするため、Draw ツールで描画中のシェイプにもこれを自動的に適用できるようになりました。詳細は後述します!

### テレポートゾーン

2 つ目のモジュールも生活の質を向上させる機能です。名前からも想像できるように、シェイプを特殊なゾーンとして設定し、シェイプがそこに入ると別のロケーションにテレポートさせられます。

この機能の利用例としては、他のフロアへの階段、トラップ、そして...テレポーテーションサークルなどがあります!

テレポートゾーンの移動先は既存のスポーン地点です。まず最初にそれらを設定してください! スポーン地点は別のロケーションにあってもよいので、異次元間の移動も問題ありません。

既定では、テレポートゾーンは即座に発動しません。その代わり、プレイヤーがゾーン内にいる間は通知が表示され、任意のタイミングで発動できます(たとえば、プレイヤーが階段の上に立っているだけで上に移動するつもりがない場合など)。ただし、即座に発動するように設定することもできます(落とし穴のトラップは、通常、任意では済まされません!)

## UI

ツール UI に小さな変更が 2 つ加えられました。

### Draw ツールの再構成

Draw ツールのポップアウトが混雑してきており、新しいものを追加する妨げになっていました。今回のリリースではこのポップアウトの見た目を再設計し、3 つの独立したタブで構成される構造に変更しました。

ベースタブには、普段いちばん頻繁に触る設定が含まれており、これから描画するオブジェクトの実際の見た目に関連するものです。

2 つ目のタブは戦争の霧の動作に焦点を当てています。DM はここで描画モードを選択できます。さらに、描画するシェイプの遮断プロパティも Draw ツールから変更できるようになりました。これらの設定は、戦争の霧レイヤーを選択すると自動的に有効になり、別のレイヤーを選択すると再び無効になります。ただし今後は、これから描画するすべてのシェイプにこの設定を適用し、後から 1 つずつ修正する必要がなくなります。

最後のタブは新しいロジックシステム用で、現在は描画するすべてのシェイプにドアモジュールを自動的に設定するオプションのみを提供しています。マップの作成時には、まずすべての壁を作成してから、この設定を有効にした状態でドアの作業を行うことをお勧めします。(さらに、移動の遮断のみを有効にした状態で窓の作業も行いましょう!)

### ポリゴン編集 UI

ポリゴン編集 UI の小さな改善として、ドラッグ中は UI が非表示になります。以前は視覚的なノイズとなり、ドラッグ操作の妨げになることがありました。

## アセット管理

### フォルダーのドロップ対応

ほとんどのブラウザで、アセットマネージャーにフォルダーをドロップできるようになりました!

この単純な機能は、当然のことながらよく要望されていましたが、使用する機能の一部でブラウザの対応がまだ標準化されておらず、今回ようやく対応できるようになりました。

### 寸法情報

アセットの名前に寸法情報が含まれている場合、ゲームボードにドロップすると、期待される数のグリッドセルを自動的に占有します。

PA は特に ?x? というパターンを探します。ここで ? は 1 桁以上の数字を表します(例: 20x20 や 5x12)。数字は X 方向と Y 方向のグリッドセル数を表します。

## サーバー管理

PA サーバーを運用している方にも、楽しい変更があります!

### 登録の無効化

新しいアカウントの登録を無効化し、実質的にサーバーをプライベートにすることが可能になりました。サーバー設定ファイルで `allow_signups` オプションを設定するだけで完了です。

サーバー所有者(または他の誰か)が特定の人を許可する仕組みはまだありません。ただし、python に詳しければ新しいユーザーを手動で追加することも、短時間だけ登録を有効にすることも可能です。

### 管理ダッシュボード

最小限の管理ダッシュボードを有効にできるようになりました。API サーバーと同じポートで動作します。

このダッシュボードでは、登録されているすべてのユーザーを一覧表示したり、パスワードをリセットしたり、完全に削除したりできます。さらに、すべてのキャンペーンも一覧表示できます。

### Docker の arm64 サポート

ニッチな機能ですが、PA は release ブランチと dev ブランチ用に arm64 の Docker イメージもビルドするようになりました。

### [BREAKING] サブパス処理

今回のリリースでは、サブパスでのホスティングの処理方法が変更されました。サブパスで PlanarAlly サーバーをホスティングしている場合は、設定を更新してください。

#### サブパスを使用していますか?

ここでのサブパスホスティングとは、ドメインのルート(例: `http://somedomain.org/`、`http://somedomain.org:2345/`、`http://subdomain.somedomain.org/`)ではなく、サブパス(例: `http://somedomain.org/planarally/`)で PA をホスティングしている構成を指します。

今後は、クライアントがサブパス情報を含めてビルドされていることが前提になります。つまり、ビルド時に PA_BASEPATH 環境変数を設定する必要があります。

さらに、パスは明示的にスラッシュで終わる必要があります。

Docker を使用していた場合は、クライアントのビルドステップに追加情報を提供する必要があるため、従来の `--env PA_BASEPATH` ではなく、`--build-arg PA_BASEPATH='/subpath/'` フラグを使用してイメージを自分でビルドする必要があります。

## バグ修正

今回のリリースでは多くのバグが修正されました!

- 「プレイヤーを呼び寄せる」操作後の再読み込みでフロアが記憶されない問題
- シェイプの貼り付けでバッジカウンターが正しく増加しない問題
- 既定の視野シェイプが(isToken に関係なく)常にトークンとして動作する問題
- Map ツールのアスペクト比ロックが機能しなくなる問題
- ウィンドウのリサイズでモーダルが画面外に出る場合に、モーダルの位置が変わるように修正
- ダイスキャンバスのサイズ設定が厳密でないためにスクロールバーが表示される問題を修正
- トークンレイヤーでの移動時に移動ブロッカーが自分自身と交差する問題を修正
- サブパス構成でアセットが見えなくなる問題を修正(新しいアセットのみに適用)
- カラーピッカーで rgba/hsla/hex の値を手動で変更できない問題を修正
- アカウント削除後にログイン画面へ正しくリダイレクトされない問題
- 公開(reveal)モードで描画されたシェイプを選択しても、選択中に影が削除されないように修正
- アセットを削除すると、それをロゴとして使用しているキャンペーンも削除される問題
- オーラの方向の数値入力がサーバーに同期されない問題
- ロケーション変更時のメモリリーク
- 読み込みが遅い画像に対するフロアの照明動作
- アセットマネージャーで DDraft のアップロードが進行しない問題
- DDraft の照明が正しく設定されない問題
- [asset-manager] フォルダー削除時にアセットマネージャーが古いファイルをチェックしない問題
