新年、そして新しいリリース！

いつものようにいくつかのバグが修正されましたが、今回のリリースの二大目玉は、ノートシステムの全面改修と、
没入感を高める新しい視線ブロックモードの導入です。

## 新しい視線ブロックモード

### なぜ追加のモードが必要なのか？

これまで、視線ブロックは二者択一でした。つまり、オブジェクト越しに見通せるか、視線を完全に遮るかのどちらかです。
これは多くのケースで問題ありませんが、小さめのオブジェクト（例: 木の幹、柱、岩）を扱う場合は、
DM として選択を迫られることがよくあります。

- オブジェクトを完全に隠し、視線ブロックとしては正しい動作にする。ただし、何が視線を遮っているのか分からないランダムな円が何なのかプレイヤーには分からないため、結局没入感が損なわれる
- 視線ブロックのシェイプを少し小さくしてオブジェクトの一部を見せる。ただし、その分正確さが失われる

### 新しいモード

このリリースでは、`behind` と呼ばれる新しい視線ブロックモードが導入されます。
これは、`complete` に名前が変更される既存の視線モードに並ぶモードです。

新しいモードが有効な場合、視線ブロックとしてマークされたシェイプは、視線ブロックのシェイプではないかのようにレンダリングされますが、
その背後にあるすべては完全に隠されます。
これにより、例えば視線ブロックになる木の幹を配置しつつ、
プレイヤーには自分が何を見ているのか（つまり木の幹）を見せることができます。

この新しいモードのもう1つの良い用途は、ドアです。
背後をブロックするように設定すれば、ドアのオブジェクト全体に正しい視野が与えられ、
プレイヤーにとって自分が何を見ているのかがより明確になります。

**完全ブロック（Complete blocking）:**

![完全な視線ブロック](./2024.1/vision-complete.png)

**背後ブロック（Behind blocking）:**

![背後をブロックする視線ブロック](./2024.1/vision-behind.png)

#### 制限事項

この特別なモードは、閉じたシェイプでのみ機能します。
実際には、ほとんどの通常のシェイプ（例: 長方形/円）では機能しますが、
ブラシツールやテキストシェイプなどの特別なシェイプでは機能しません。

ポリゴンは開いたり閉じたりできます！
このモードをポリゴンツールで不規則なシェイプを表示するために使いたい場合は、
ポリゴンを閉じた状態にマークしておいてください。
（これは Draw ツールのオプションです）

もう1つの特殊なケースとして、このモードが有効なオブジェクトの中に配置されたライトは、
あなたのオーラがシェイプに届かない場合にレンダリングされることがあります。
これは実装上のエッジケースですが、視線ブロックのシェイプの中にライトを置く理由はあまりないため、
実際にはそれほど問題にはならないはずです。

## ノートと注釈

このリリースのもう1つの大きな変更は、ノートシステムの全面改修です。

PlanarAlly にはこれまで2つのノートの概念がありました:

- キャンペーンノート（ルーズノート）
    - タイトルと自由形式のテキストを持つ
    - 常にプライベート
    - 開いたままにできる / ドラッグで移動できる
- シェイプノート（注釈（annotations）としても知られる）
    - Markdown 対応の自由形式テキストを持つ
    - パブリックまたはプライベートにできる
    - シェイプごとに1つに制限される
    - 関連するシェイプをホバーすると、レンダリングされた Markdown が画面の上部に表示される

### さまざまな問題

これら2つの概念は、それぞれ独自の問題を抱えており、互いに一貫性がありません:

- キャンペーンノートの場合
    - 検索手段がない
    - フィルタリング手段がない（例: 現在のロケーションに関連するノートだけを表示するなど）
    - 他のユーザーと共有する手段がない
    - 同時に開けるノートは1つだけ
    - Markdown のレンダリングがまったくない
- シェイプノートの場合
    - プライベートとパブリックの両方の情報を持つことができない
    - シェイプを選択せずにポップアウトしてアクセスする手段がない
    - シェイプのために書いた情報が必要な場合、シェイプがどこにあっても探さなければならない
    - キャラクターでない限り、シェイプが削除されるとノートも失われる

### 統一されたソリューション

これらの問題を解決するために、統一されたノートシステムが作成されました。

この新しいシステムでは、シェイプノートとキャンペーンノートの区別はもうありません。
ノートは単一の概念となり、シェイプに添付でき、Note Manager（ノートマネージャー）と呼ばれる新しい UI 要素で管理できます。

![NoteManager の一覧](../docs/game/assets/note-manager-list.png)

### 注目すべき変更点

新しいノートシステムの完全な概要については、[ノートのドキュメント](/ja/docs/game/notes/)を確認してください。
このページは新しいシステムを反映するように更新されており、複数の画像とより詳細な説明が含まれています。

#### UI の変更

ノートマネージャーは、<kbd>n</kbd> キーバインドまたは左側メニューのノートセクションをクリックすることで開ける新しい UI 要素です。
これは新しいノートシステムの中核であり、すべてのノートを管理できます。

ノートマネージャーには検索バーがあり、すべてのノートを検索できます。
ノートには任意のタグを付けられるようになり、検索にもコンテキストの追加にも使えます。

ただし、ノートマネージャー（およびその他のいくつかの場所）からノートをポップアウトして、他のことをしながら開いたままにすることもできます。
複数のノートを同時にポップアウトでき、それぞれ個別にドラッグして移動できます。

さらに、ポップアウトしたノートは、タイトルだけを表示するように折りたたむこともできます。
これは、短時間に頻繁にアクセスする必要があるノートに便利で、画面を散らかしません。

![ノートのポップアウト](../docs/game/assets/note-manager-edit-popout.png)

#### アクセス

ノートを他のユーザーと共有し、ノートごとに細かいアクセス権を定義できるようになりました。

つまり、特定のノートが表示されたときに全プレイヤーに閲覧アクセスを許可したり、特定のプレイヤーに、そのプレイヤーだけが閲覧・編集できるプライベートノートを渡したりできます。

プレイヤーが作成したノートは、PA の中で DM から見えない数少ないものの1つです！つまり、明示的に共有しない限り、本当にプライベートです。

#### シェイプ

ノートはオプションでシェイプに添付できます。
1つのノートを複数のシェイプに添付でき、1つのシェイプに複数のノートを添付することもできます！

これにより、パブリックとプライベートの両方の情報をシェイプに添付できます。

さらに、シェイプにノートアイコンを表示するように設定できる新しいノート設定もあります。
重要なノートの存在を覚えておくのに便利です。
また、関連するシェイプをホバーしたときにノートを画面上部に表示するかどうかを指定する設定にもなりました。
これはデフォルトではオフです！

![ノートマネージャーのトリガー](../docs/game/assets/note-manager-edit-triggers.png)

シェイプを選択したときに画面右側に表示されるクイック情報セクションにも、シェイプに添付されたすべてのノートの情報が表示されるようになりました。
ノートにホバーすると内容をすばやく確認できますが、そこからポップアウトすることもできます。

特定のシェイプのすべてのノートの概要を確認するには、クイック情報セクションのノートアイコンをクリックするか、選択したシェイプのコンテキストメニューを使用します。

#### グローバルとローカル

新しいノートを作成するとき、グローバルノートにするかローカルノートにするかを選択します。

つまり、グローバルノートはキャンペーンに依存せず、すべてのキャンペーンで表示されます。
一方、ローカルノートは現在のキャンペーンに関連し、さらに作成された特定のロケーションにも関連します。

グローバルノートはすべてのキャンペーンで利用できるため、
多くのノートはすべてのキャンペーンに関連するわけではないので、作りすぎないように注意する必要があります。

ただし、グローバルノートの良い用途はステータスブロックです。特定のモンスターのステータスブロックをすべてのキャンペーンで再定義したくはありません。
[アセットテンプレート](/ja/docs/dm/assets/#templates)と組み合わせれば、ゴブリンをボードにドロップするだけで、自動的にステータスブロックが添付されます。

## アセットのドロップ比率（Asset Drop Ratio）

これは新機能であると同時にバグ修正でもあります。
ロケーションのグリッド設定に新しい設定を追加します。

PA には、アセットの名前に特定の形式が含まれている場合、ドロップ時に自動的にスケーリングするオプションがあります。
たとえば、goblin_1x1 は通常、グリッドセルちょうど1つ分に収まるはずで、dragon_3x3 はグリッドセル3x3分にリサイズされるはずです。

既存の実装では、これを5ft システムに基づいた方法で誤って行っており、
ロケーションのサイズが大きい場合（例: 10ft のマップでは something_2x2 が自動的に1セルに収まる）に自動調整されていました。

しかし、これは5ft システムを使わないすべてのものでは完全に壊れてしまいます。SI 単位を使う場合も、カスタムのシステムを使う場合も、サイズをピザ単位で定義するのが好きな場合もです。

簡単な修正はそのシステムを無効にすることですが、そうするとスケールが異なるマップにアセットをドロップするときに正しく機能しなくなります。
その問題にも対処するために、「アセットのドロップ比率（Asset Drop Ratio）」という新しい設定が追加され、アセットをマップにドロップしたときにどのようにスケーリングするかを定義できます。

ドロップ比率1がデフォルトで、アセットが指定された寸法どおりにのみリサイズされることを意味します（つまり、goblin_1x1 は10ft を表していてもグリッドセル1つ分を占めます）。
ドロップ比率0.5の場合、something_2x2 は1x1 にリサイズされます。

## ダイスの履歴

_SuikaXhq 氏によるコントリビューション_

ダイスの UI と動作をリワークする大きな計画がありますが、ゆっくり進めている間に、
SuikaXhq 氏が既存のダイス履歴に素晴らしい改善をコントリビューションしてくれました。

ダイスの履歴には、誰がダイスを振ったかがより目立つように表示されるようになり（以前はホバー時のみ表示）、
最終結果だけでなく、特定のロールの詳細も含まれるようになりました。

## 選択情報の改善

_SuikaXhq 氏によるコントリビューション_

前述のとおり、画面右側の選択情報セクションに、選択したシェイプに添付されたノートの情報が含まれるようになりました。

しかし、これは選択情報への唯一の変更ではありません！

トラッカーとオーラは、現在の数値の情報を表示し、それらの数値をすばやく変更できるようになりました。
ただし、オーラの場合これはあまり便利ではなく、ほとんどの場合、頻繁に変更したいものではありません。

このリリースでは、詳細なトラッカー設定を開かずに、オーラを有効/無効にするトグルをオーラセクションに追加しました。
さらに、オーラの角度が制限されている場合（つまり360度でない場合）、オーラの回転をすばやく変更できる回転スライダーも表示されます。

![クイック情報の更新](../docs/game/assets/note-manager-selection-notes.png)

## バグ修正

- ポリゴン編集 UI: シェイプの回転が考慮されていなかった
- テレポート: 追従なしでテレポートされたシェイプは、ローカル同期が更新されないため、動いていないように見えることがあった
- ダイスツール: 何も入力されていない場合は GO ボタンを無視する
- キャラクター: バリアントに関する一連のバグが修正された
- トラッカー: トラッカーが多い場合の UI を修正するために、max-height とスクロールを追加
- 回転スライダー: 同期の問題を修正
- 回転スライダー: 特定の角度でスライダーのアンカーがレールに留まらない問題を修正
- \[サーバー\] 一時的なシェイプが移動されたときの「unknown」シェイプのログスパム
