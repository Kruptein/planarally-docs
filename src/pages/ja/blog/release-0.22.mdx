前回のリリースから 2 か月以上が経過したので、そろそろ更新の時期です!
このリリースには新機能がたくさんあるわけではありませんが、大きなものが一つあります: 回転です!
その他には、多数のパフォーマンス改善、フロアの品質改善、そして多くの小さな変更と修正が含まれています。

## 回転

シェイプの回転は、明らかな理由からよく要望される機能でした。
しかし、これはより技術的な変更であり、描画ロジックの核となる部分にいくつかの調整が必要でしたが、
最終的にはうまくいきました。

回転は選択ツールで行いますが、ビルドモードでのみ可能です（リサイズと同様）。
ビルドモードに入ると、回転専用の UI（ボールの付いた線）が表示されます。
ボールを掴んで動かすと、シェイプを中心の周りで自由に回転できます。

複数のシェイプが選択されている場合、回転 UI はグループ全体の周りに描画され、すべてのシェイプを一度に回転できます。
この回転も、この回転ボックスの中心を基準に行われます!

さらに、スナップを使用している場合、回転はきれいな 45 度の角度にスナップされます。

## フロアの品質改善

私はフロアがとても気に入っていますが、まだいくつかの小さな痛点があり、ここで対処したいと思います。

### アクセシビリティ

DM はフロアのアクセシビリティを切り替えられるようになりました。具体的には、プレイヤーが特定のフロアに手動で移動するのを防ぐことができます。

**これは実際のプレイフィールドでのフロアの視界を妨げるものではありません**（例: 高いフロアのプレイヤーが下の草原を見下ろす窓から外を見るような場合）

### 名前変更

フロアの名前を変更できるようになりました。わーい。

### 表示順序

ポップアップメニューでのフロアの表示順が逆になりました。これで、一番上の項目が最も高いフロアという、より論理的な順序になりました。

### 並べ替え

フロアをドラッグして並べ替えることもできるようになりました。事前にすべてを計画しておく必要や、手動で多くのものを移動する必要はもうありません!

### 霧のバグ

下のフロアに不要な霧が多く追加され、暗くなってしまう問題がありました。

## パフォーマンス改善

大きな影響を与えるはずの多数のパフォーマンス調整が行われました!

### 起動時間

websocket 処理の変更により、クライアントがサーバーデータにずっと速く反応するようになりました。
これにより、すべてのマップでの視覚的な読み込みも速くなるはずです。

さらに、フロアは起動時に個別に読み込まれ、最後に訪れたフロアが最初に読み込まれます。
これにより、フロアの多いマップでの初回描画までの時間が劇的に改善されるはずです。

UI 全体で使用される Fontawesome アイコンは、vue ライブラリで読み込まれるようになりました。これまではすべてのアイコンが fontawesome.js スクリプトで読み込まれていましたが、現在は実際に使用されるアイコンのみを読み込むため、データを節約できます!

ゲームループは最初のフロアが届いたときにのみ開始されるようになりました。これは全体から見ればかなり小さな改善ですが、それでも良い改善です。

### その他

もう一つの大きな改善はシェイプの移動です。グループ移動がより効率的に処理され、各シェイプの移動に必要なデータも少なくなりました。

最後の改善は、パン操作が終了するまで非表示のフロアの更新を遅らせることです。これもまた、フロアの多いマップにメリットをもたらします。

## その他

- 選択 UI にロック/アンロックのトグルアイコンが追加されました
- Ruler の距離の読みやすさが改善されました
- グリッドのピクセルサイズはクライアント側の機能になり、プレイヤーは使用する表示方法（例: プロジェクターとノートパソコンの画面）に応じてこの値を選択できるようになりました

## バグ修正

- トークンが表示可能なキャンバスの外にあるときに Aura が表示されない問題
- 左メニューが開いているときの Firefox のロケーションスクロールバー
- いくつかの重大なパフォーマンスのボトルネック
- 起動前にクライアントがビルドされていない場合、サーバーが終了し、docs/tutorial を参照するようになりました
- グリッドスナップよりスナップポイントを優先するようになりました
- 左上メニュー UI の白いアイコンを削除
- キーボードでポリゴンを移動すると原点だけが移動する問題
- 三角分割の退化ケース
    - 三角分割コードは、1e-15 程度のわずかな数値の差を扱う際に退化ケースに遭遇する可能性がありました
    - 現在は、数値的不安定性を防ぐため、三角分割コードは小数点以下 10 桁のみを考慮するようになりました
- 一部のケースでマウスリーブイベントがトリガーされない問題（例: alt tab）。これにより、一部のシェイプ（例: Ruler）が画面に残ることがありました
- Map ツールのリサイズが複製されない問題
- 繰り返しポイントを持つポリゴンの中心計算
- ロケーションに移動したシェイプが、古いロケーションで適切に消えるようになりました
