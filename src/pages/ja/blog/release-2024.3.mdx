### 非推奨のお知らせ(再掲)

前回のリリースでお知らせしたとおり、ラベル/フィルターシステムは非推奨となり、次のリリースで削除されます。

## シンプルなチャットシステム

今回のリリースでは、キャンペーン内の他のプレイヤーとチャットできるシンプルなチャットシステムを導入します。

![チャットボタン メッセージ待機中](../docs/game/assets/chat.png)

シンプルで要点を押さえた設計になっています。マークダウンによる書式設定が一部利用でき、画像 URL は自動的に画像に変換されます。

重要な点として、送信されたメッセージは現在サーバーに保存されません。そのため、ページを更新したりセッションに再接続したりすると、チャット履歴は消去されます。

PA をどのようなグループが使っているのかを把握するのは必ずしも容易ではないため、チャット機能は比較的最小限にしています。永続的なチャット履歴やその他のチャット機能が役立つようでしたら、ぜひお知らせください!

チャットの詳細については[ドキュメント](../../docs/game/chat)を、マークダウンについては[こちら](../../learn/dm/Markdown_Tutorial/markdown/)を参照してください。

## ダイス機能の改善

今回のリリースでは、多くの時間をダイスロールシステムのさまざまな側面の改善に費やしました。

### ダイスツール UI

ダイスツールの UI は完全に刷新されました。

![ダイスツール](./2024.3/dice.png)

#### 非 3D モード

以前は、ダイスを振る唯一の方法は 3D オブジェクトでシミュレートすることでした。これは楽しいものですが、さまざまな理由から必ずしも最良の選択とは限りません。

今後は、3D シミュレーションなしでダイスの結果を自動的に解決するオプションが利用できます。

#### 入力の改善

以前のバージョンには、テキスト入力と、入力せずにダイスを選択するためのシンプルなクリック UI がありました(たとえば、'd6' を 3 回クリックすると、テキストボックスに 3d6 が追加されました)。

これは機能していましたが、かなり限定的でした。この「クリック」UI は大幅に拡張されました。

ダイスパーサーの文法も拡張され、「kh2 (上位 2 個をキープ)」などのより複雑な式を扱えるようになりました。

#### 結果の共有

DM にも結果が見えない、完全にプライベートなダイスロールが可能になりました。

他のプレイヤーからロール結果を受け取ったユーザーは、通知のポップアップをクリックしてロールの詳細を確認できるようになりました。

#### 結果 UI と履歴

ダイスロールの結果を表示する UI も少し変更されました。

見た目の煩雑さを減らすため、グループ(例: 3d6)内の個々のロールは表示されなくなりましたが、グループにカーソルを合わせると表示できます。

ロール履歴も少し変更され、履歴内の行をクリックすると、再び完全な結果 UI が表示されます。

### 3D ライブラリの更新

3D シミュレーションには、babylonjs ゲームエンジンが使用されています。バージョン 4 から 7 にアップグレードされました。この変更には、使用される物理エンジンの変更も含まれます。babylonjs は ammo の代わりに havok エンジンを採用したためです。

3D ロールのロジックも少し変更されましたが、動作はほぼ同じであると期待してよいでしょう。

### planarally-dice ライブラリとダイスシステム

現在、ダイス UI の多くは d20 システムを中心に構成されています。これは D&D で一般的ですが、他のいくつかのシステムでも使用されています。

とはいえ、ダイスライブラリ自体は、さまざまなダイスシステムをサポートできるように書き直されました。ただし、PA の UI にはシステムを切り替える方法がまだないため、現在は d20 システムが既定になっています。

PA 自体で他のダイスシステムを最適に提供する方法を現在検討しています。(たとえば、DM のキャンペーン設定に「ダイスシステム」設定を設ける、あるいは一般的な「RPG システム」設定を設けるなど。)

そのため、将来、RPG システムやダイス関連の変更がさらに加えられる可能性があります。

## ダンジョンでの移動がより簡単に

角のある狭い廊下をトークンのグループで進むことは、壁との衝突のため手間がかかることがあります。当初は、よく手動でトークンをぎゅっとまとめてから、位置が重要になる地点に到達したら再び広げていました。最近では、作業量が少ないという理由で、1 つのシェイプだけを移動させ、他のシェイプは shift 移動で最終地点まで移動させることが多かったです。

どちらの方法もあまり良いものではないため、今回のリリースでは、この 2 つの方法を手動操作を減らして組み合わせる新しい機能が追加されました。

シェイプのグループを右クリックして「Collapse」(折りたたみ)を選択すると、折りたたみを開始したシェイプを中心にすべてのシェイプが移動します。その後、その 1 つのシェイプを移動するだけで、他のシェイプはすべて自動的に追従します。目的の位置に到達したら、右クリックして「Expand」(展開)を選択すると、折りたたみを開始したシェイプに対する元の位置に、すべてのシェイプが押し出されます。

キーボードショートカットもあります。'c' キー(collapse の c)を押している間、選択範囲は折りたたまれ、マウスボタンを離すか 'c' をもう一度押すと自動的に展開されます。

## キャンペーン機能

小さな追加として、DM が特定の機能を無効化できるようになりました。特に、チャットツールとダイスツールは、今回のリリースから無効化できます。

これはどちらかというとベータ版の機能です。私自身、この機能をどう評価してよいかまだ確信が持てていません。これらの設定は、むしろユーザー設定として用意する方が適しているかもしれません。

## ツール

### ツールバー UI の変更

ツールバー UI の小さな変更: すべてのツールの拡張 UI は、該当するツールの上にホバー表示されるのではなく、完全に右寄せで表示されるようになりました。つまり、ツール UI とツールバーを結んでいた小さな矢印もなくなりました。

Select ツールの変更(下記参照)に取り組む中で、中央に近いツールの UI にいくつかの問題があることが明らかになりました。ツールの UI を大きくできないか、またはメイン画面のかなりの部分を占拠してしまうかのどちらかでした。

すべてのツール UI を右側に移動することで、画面中央の領域と競合することなく、より多くのスペースを確保できるようになりました。

### Select と Ruler の状態

シェイプを選択すると、Select ツールの UI に、シェイプの移動に Ruler を追加するオプションが表示されました。

これはかなり便利ですが、その Ruler の設定(たとえば、他のプレイヤーに見えるかどうか)は Ruler ツールでのみ設定できました。つまり、Ruler の設定を変更したり確認したりするために、2 つのツールを行き来しなければならないことがよくありました。

現在は、Select ツールでも Ruler の設定が表示され、直接変更できるようになりました。

![Select ツールの Ruler 設定](../docs/tools/select-ui.png)

### Spell ツールでのヘックス

前回のリリースで六角形が大幅にアップグレードされましたが、ヘックスが役立つ可能性のあるすべての場所を網羅していませんでした。

今回のリリースでは、Spell ツールが使用中のグリッドタイプを認識するようになり、さまざまなヘックスサイズで呪文エフェクトを作成するオプションが提供されます。

![Spell ツールのヘックスサイズ](../docs/tools/spell-hex.png)

### バグ修正

- Draw ツール: Draw ツールの視野設定で「移動を遮る」ラベルをクリックすると、関連するチェックボックスが正しく切り替わるようになりました
- Ruler ツール: グリッドモードでスペースキーを押した際、スナップされた終点が他のプレイヤーに正しく同期されない問題
