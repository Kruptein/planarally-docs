# インストール

> インストールの記事は**DM のみ**[^1]が読む必要があります。

PlanarAlly は各プレイヤーがインストールする必要はありません。プレイヤーの場合は、そのまま[こちら](/ja/docs/)で PlanarAlly の始め方や完全なドキュメントに進んでください。

DM としては、PlanarAlly を自分でホストするか、既存のオンラインサービスを利用するかを選択する必要があります。どちらの方法にも長所と短所があります。

すでに使用したいものを決めている場合は、[外部サービス](/ja/server/setup/managed/)または[セルフホスト](/ja/server/setup/self-hosting)を参照してください。まだ決めていない場合は、両方の選択肢について詳しく知るために読み進めてください!

## ホスティングオプションの比較

PA を自分でホストすることと、オンラインサービスを利用することの長所と短所を把握することが重要です。
より深く理解するために、2 つの選択肢で異なるいくつかの側面について見ていきます。

### 複雑さ

セルフホストはオンラインサービスと比較してはるかに複雑です。オンラインサービスはインストールがまったく必要ないのに対し、セルフホストでは手動での作業が必要です。プレイヤーがサーバーにアクセスできるようにするには、ポート転送などのことを調べる必要があるでしょう。これが大変に思える場合は、遠慮なく私に連絡してください。または、こうしたことを心配する必要のないオンラインサービスを選ぶのが簡単です。

### 柔軟性

セルフホストは複雑ですが、その分柔軟性も高くなります。サーバー設定を好みに合わせて構成し、ソフトウェアを自由に調整できます。色を変更したい、ロゴをどこかに配置したい、といったこともできます。あらかじめ設定されたオンラインサービスではこうしたことはできません。

とはいえ、ほとんどの人はあまり変更しないだろうと思います。

### オフラインサポート

オンラインサービスはインターネットへのアクセスが必要なため、オフラインをサポートするのはセルフホストだけです。地下室のどこかでサーバーを起動しておけば、プレイヤーは同じネットワークにいる限り接続できます。

[^1]: 技術的には誰でもサーバーをホストできます。DM である必要はありません
