# マネージド

セットアップに関して言えば、あなたとプレイヤーに PlanarAlly を提供するオンラインサービスを利用するのが、はるかに簡単な選択肢です。

現時点では、PlanarAlly サーバーを公開ホストするだけのリソースはありませんが、将来的には追加したいと考えています。

<Warning>
    これらのサービスは私が運営しているものでは**ありません**。そのため、ソフトウェアが悪意のある意図で改ざんされていないことを保証することはできません。
</Warning>

## 既知のプロバイダー

_PA を公開ホストしている方、またはそのような人を知っている方がいましたら、ぜひ教えてください!_

[Dice.Quest](https://planarally.dice.quest/)(旧 dndbox.com) は v2024.3 で、スイス/ヨーロッパでホストされており、PlanarAlly を含む多数の[オープンソースプロジェクト](https://dice.quest)をホストしています。サポートは [reddit](https://reddit.com/r/dndbox/) で提供されています。

[10leej.com](https://planarally.10leej.com/) は v2025.1.1 で、アメリカのジョージア州アトランタでホストされています。サポートは 10leej が提供しています。サポートを受けるには、[ウェブサイトのトップページ](https://10leej.com/)にある連絡先情報を使用してください。
