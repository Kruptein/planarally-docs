# Introduzione

Iniziare con un nuovo VTT è sempre un po' una sfida, perché ogni piattaforma ha le proprie particolarità e funzionalità.
L'idea di questa serie di guide è di aiutarti a iniziare con il flusso di base più comune per preparare e gestire una partita.

Dovresti probabilmente dare una lettura alla [guida per giocatori](/it/learn/player/intro/), che è piuttosto breve, dato che non ripeteremo alcune delle cose di base spiegate lì (ad es. spostare la telecamera, ecc.).

## Scegliere un server

Un primo passo importante è proprio scegliere su quale server PA intendi far girare la tua partita.
Puoi auto-ospitare, oppure unirti a un server aperto esistente: la scelta è tua.

Per maggiori informazioni su questa scelta, consulta la [documentazione sui server](/it/server/setup/).

## Creare una partita

Scelta fatta sul server, creiamo una partita.
Se visiti la panoramica principale delle partite dopo l'accesso, c'è un grande pulsante NUOVA PARTITA in alto a destra.

Questo farà apparire una scelta tra creare una partita da zero o importare una partita da un altro server.

![Schermata di creazione campagna](./assets/create-campaign.png)

<Info>
    Questo significa anche che puoi effettivamente esportare le tue partite! Se alla fine vuoi spostarti su un altro
    server, è sicuramente possibile.
</Info>

Visto che vogliamo creare una nuova campagna, partiremo da zero; continuiamo.
Scegli un nome, aggiungi opzionalmente un logo e via!

La prima cosa che vediamo dopo aver creato una partita è una grande tela bianca ancora vuota.
Questo è qualcosa che ovviamente sistemeremo, e lo faremo nel [prossimo capitolo](/it/learn/dm/first-map/).
