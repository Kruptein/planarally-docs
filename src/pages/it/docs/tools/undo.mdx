# Undo

Questo "strumento" non ha un posto nella barra degli strumenti né alcun altro elemento dell'interfaccia, ma è controllato da 2 combinazioni di tasti.

Con ctrl+z puoi annullare un'operazione, con ctrl+shift+z puoi ripetere un'operazione.

La lista delle azioni attualmente supportate è:

- spostamento di una forma
- rotazione di una forma
- ridimensionamento di una forma
- cambio piano
- cambio livello
- creazione/rimozione di una forma
