# Outil Ping

L'outil Ping est accessible dans la barre d'outils en bas à droite de la table de jeu, mais uniquement en [mode Play](/fr/docs/tools-overview/#toolbar-and-modes).
Il sert d'outil « balise » minimaliste.
Tant que le bouton de la souris est maintenu enfoncé, il affiche deux cercles à tous les joueurs à l'endroit où se trouve actuellement votre souris.

Les cercles de ping utilisent la même couleur que la couleur de votre règle dans vos [paramètres du client](/fr/docs/game/settings/).
