# Outil Zoom

Bien qu'il ne s'agisse pas d'un outil sélectionnable dans la barre d'outils, il existe un outil Zoom dédié en haut à droite de votre écran.

Vous pouvez également utiliser la molette de votre souris pour zoomer.
Ce comportement peut être désactivé dans les [paramètres du client](/fr/docs/game/settings/#behaviour).

Une différence cruciale entre la molette et l'outil Zoom est que la première zoome par rapport à votre pointeur de souris tandis que le second défile par rapport au centre de l'écran.
