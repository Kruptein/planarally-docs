# Outil Vision

L'outil Vision est accessible dans la barre d'outils en bas à droite de la table de jeu dans les deux [modes](/fr/docs/tools-overview/#toolbar-and-modes).
Il aide à suivre la vision de plusieurs pions.
Son comportement diffère pour les joueurs et les DMs.

## Joueur

Si vous cliquez dessus, l'outil Vision ouvrira une liste de tous les objets [configurés avec un accès de vision](/fr/docs/game/shapes/#access) pour le joueur.
Par défaut, ils apparaissent actifs dans la liste, signalés par un arrière-plan coloré.
Tous les modes et outils n'afficheront la vision que des pions ayant une entrée _active_ dans l'outil Vision.

Au clic, une entrée sera désactivée, affichant alors un arrière-plan gris.
Simultanément, la vision de ce pion ne sera plus affichée sur la table de jeu.

## DM

Par défaut, les DMs voient toujours tout.
L'utilisation de l'outil Vision seul ne changera pas cela.
Ils peuvent toutefois [se faire passer pour un joueur](/fr/docs/dm/settings/#fake-player) pour obtenir un effet similaire à celui décrit ci-dessus.
Dans ce cas, ils utilisent l'outil Vision pour définir la vision de quel joueur ils souhaitent voir.
