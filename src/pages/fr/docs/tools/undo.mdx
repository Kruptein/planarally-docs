# Undo

Cet « outil » n'a pas de place dans la barre d'outils ni aucun autre élément d'interface, mais est contrôlé par 2 raccourcis clavier.

Avec ctrl+z vous pouvez annuler une opération, avec ctrl+shift+z vous pouvez la rétablir.

La liste des actions actuellement prises en charge est :

- déplacement de forme
- rotation de forme
- redimensionnement de forme
- changement d'étage
- changement de calque
- création/suppression de forme
