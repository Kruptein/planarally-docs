# Outil Pan

L'outil Pan est accessible dans la barre d'outils en bas à droite de l'écran, quel que soit le [mode](/fr/docs/tools-overview/#toolbar-and-modes).
Lorsque cet outil est sélectionné, vous pouvez faire glisser l'écran en maintenant votre souris enfoncée tout en la déplaçant.

## Déplacement rapide

Comme le déplacement est une action si courante, échanger les autres outils peut être pénible.

PA déclenche aussi le déplacement lors d'un glisser avec le clic du milieu ainsi qu'avec le clic droit.
