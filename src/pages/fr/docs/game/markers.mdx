# Marqueurs

Les marqueurs sont accessibles depuis le menu latéral (cliquez sur l'icône <Cog /> en haut à gauche de la fenêtre de votre navigateur pour ouvrir le menu).

C'est l'endroit où les formes que vous avez marquées apparaissent comme référence rapide. En cliquant sur l'un de vos marqueurs, l'écran se centre sur la forme correspondante.

Pour marquer une forme, faites simplement un clic droit dessus et sélectionnez l'option « Set marker ». Une fois marquée, vous pouvez retirer le marqueur depuis le menu des marqueurs ou en faisant un clic droit sur la forme et en sélectionnant « Remove marker ».
