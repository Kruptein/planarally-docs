# Подкаталог

PlanarAlly можно без особых усилий размещать на корневом уровне (например, https://www.planarally.io) или на поддомене (например, https://app.planarally.io).
Однако при размещении в подкаталоге необходимо выполнить некоторую дополнительную работу (например, https://www.planarally.io/dnd/).

Нужно дать понять и серверу, и клиенту, что они должны работать в подкаталоге.
Кроме того, вам, возможно, потребуется внести некоторые изменения в ваш прокси.

В остальной части этой документации иногда упоминается переменная окружения PA_BASEPATH, которая должна соответствовать нужному подкаталогу.
Например:

```bash
export PA_BASEPATH="/planarally/"
```

<Warning title="Изменённое поведение">
С версии 2022.1 в обработке подкаталогов произошли некоторые изменения,
обязательно перечитайте эту документацию, если вы использовали её в прошлом!

В частности, клиент теперь всегда нужно собирать вручную, а docker-контейнер использует --build-arg вместо --env.

</Warning>

## Изменения на стороне клиента

Если вы хотите использовать подкаталог, вам придётся [собрать клиент самостоятельно](/ru/server/setup/self-hosting/#manual-installation).
Информация о подкаталоге должна быть зашита в файлы сборки.
Это можно сделать просто, собрав клиент при установленной переменной окружения PA_BASEPATH.

## Изменения на стороне сервера

Серверу также нужно знать о подкаталоге: просто убедитесь, что переменная окружения PA_BASEPATH установлена перед запуском сервера.

## Docker

При использовании docker-образа эту переменную окружения нужно передать контейнеру.
Добавьте следующую часть в вашу docker-команду.

```bash
--build-arg PA_BASEPATH='/planarally/'
```

## Прокси

### Nginx

При использовании nginx у вас будет очень похожая настройка на описанную в [proxy](/ru/server/advanced/proxy/), но все блоки `location` будут начинаться с `/planarally`, если это ваш нужный подкаталог.

Кроме того, нужно внести одно небольшое изменение в правило location, специфичное для socket.io:

Значение proxy_pass (или host\:port pass) нужно изменить, чтобы оно включало подкаталог. (например, `proxy_pass http://subaiohttp/subpath/socket.io/;`)

### Apache

Обязательно настройте proxypass и reverse на подкаталоге!

```apache
ProxyPass /planarally http://127.0.0.1:8000/planarally
ProxyPassReverse /planarally http://127.0.0.1:8000/planarally
```
