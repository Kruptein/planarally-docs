# Управление пользователями

<Info>
    Этот раздел сильно устарел. Через CLI вы можете запрашивать множество вещей, а также настроить простой просмотр в
    браузере для некоторых административных задач.
</Info>

По состоянию на v0.22.3 на уровне сервера не существует графического интерфейса для управления пользователями, поэтому для управления пользователями приходится использовать python-скрипты.

Всегда убедитесь, что вы сначала находитесь в python-оболочке, прежде чем запускать любой из этих скриптов. Просто откройте терминал и введите `python`, чтобы открыть оболочку; выйти из оболочки можно командой `quit()`

PlanarAlly использует peewee в качестве ORM-инструмента для базы данных.

## Список всех имён пользователей на сервере

```python
from src.db.all import User
[ u.name for u in User.select() ]
```

## Смена пароля для конкретного пользователя

```python
from src.db.all import User
u = User.get(name="*some-username*")
u.set_password("*new-passowrd*")
u.save()
```

## Создание нового пользователя от имени администратора

```python
from src.db.all import User
User.create_new("*some-username*", "*some-password*", "*some-email(optional)")
```
