# Активы

<Image src={DashboardAssets} alt="Активы панели управления" />

Раздел **Активы** позволяет управлять активами или создавать активы, которые можно использовать в кампаниях.
_О том, как ими пользоваться, см. в разделе [Активы DM](/ru/docs/dm/assets/)_.

<Info>Сейчас активы интересны только DM. В будущем здесь также появится возможность загружать активы игрокам.</Info>

В правом верхнем углу находится небольшая панель действий, которая позволяет создать папку, загрузить новые активы или удалить активное выделение.

## Навигация по папкам

Основной экран представляет собой обозреватель папок, в который можно войти двойным кликом.
Текущий путь к папке отображается в виде хлебных крошек сразу под заголовком «MANAGE ASSETS».

Чтобы вернуться в предыдущую папку, можно дважды кликнуть по папке «..»[^1].
Клик по любому сегменту хлебных крошек позволяет вернуться сразу на несколько папок назад.

## Загрузка активов

Активы можно загружать, кликнув по значку добавления файла на панели действий или перетащив их на менеджер активов.

## Перемещение активов

Активы можно перемещать, перетаскивая их в нужную папку.
Чтобы переместить актив на одну папку вверх, перетащите его на папку «..».

Можно перемещать сразу несколько активов — либо перетаскивая папку, содержащую несколько активов, либо выбрав несколько активов.

## Выбор активов

Одиночный клик по активу выделит его и снимет выделение со всех остальных активов.

Чтобы расширить выделение, можно использовать ctrl+клик или shift+клик.
Первый добавляет в выделение только кликнутый файл,
а второй — все файлы между последним и новым выделением.

<Info>
    Текущее поведение осталось от предыдущего менеджера активов и повторяет логику обычных файловых обозревателей.

    Однако способ отображения выделения делает его не совсем интуитивным.
    Возможно, это изменится в будущем.

</Info>

[^1]: Это понятие из мира Unix.
