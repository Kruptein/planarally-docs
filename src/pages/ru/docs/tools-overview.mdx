# Обзор инструментов

PlanarAlly предоставляет набор инструментов для взаимодействия с игрой и другими игроками.
Для DM предусмотрены дополнительные инструменты, соответствующие их потребностям.
Большинство (но не все) из этих инструментов доступны через панель инструментов в правом нижнем углу экрана.

## Панель инструментов и режимы

Чтобы панель инструментов не была перегружена множеством опций, инструменты отображаются в зависимости от режима панели.
Сейчас существует 2 режима: «Игра» и «Сборка»; первый ориентирован на инструменты, реально используемые во время игры,
а второй — на инструменты, используемые в основном при подготовке DM.

Чтобы переключить режим, кликните по нужному режиму или используйте клавишу `Tab`.

Ниже представлен обзор всех инструментов и режимов, в которых они доступны.
Учтите, что поведение некоторых инструментов может отличаться в зависимости от режима.

## Краткая справка по инструментам

| Инструмент                               | Доступ | Режим    | Описание                                                       |
| ---------------------------------------- | ------ | -------- | -------------------------------------------------------------- |
| [Select](/ru/docs/tools/select/)         | Все    | Оба[^1]  | Выбор, перемещение, поворот или изменение размера фигур.       |
| [Pan](/ru/docs/tools/pan/)               | Все    | Оба      | Перемещение области просмотра игры.                            |
| [Draw](/ru/docs/tools/draw/)             | Все    | Сборка   | Создание фигур различных базовых форм.                         |
| [Spell](/ru/docs/tools/spell/)           | Все    | Игра     | Измерение и накладывание заклинаний.                           |
| [Ruler](/ru/docs/tools/ruler/)           | Все    | Оба      | Измерение расстояний.                                          |
| [Ping](/ru/docs/tools/ping/)             | Все    | Игра     | Отображение временного маячка, видимого всем.                  |
| [Map](/ru/docs/tools/map/)               | DM     | Сборка   | Помогает подогнать размер активов (в основном карт) под сетку. |
| [Vision](/ru/docs/tools/vision/)         | Все    | Игра[^2] | Ограничение того, какие персонажи вносят вклад в обзор.        |
| [Zoom](/ru/docs/tools/zoom/)             | Все    | Оба[^3]  | Приближение/отдаление части игры.                              |
| [Initiative](/ru/docs/tools/initiative/) | Все    | Оба[^3]  | Отслеживание порядка инициативы и эффектов по времени.         |
| [Undo/Redo](/ru/docs/tools/undo/)        | Все    | Оба[^3]  | Отмена и повтор определённых действий.                         |

[^1]: Функциональность отличается в зависимости от режима.

[^2]: Отображается на панели инструментов только тогда, когда реально может использоваться.

[^3]: Не входит в панель инструментов.
