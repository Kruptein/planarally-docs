# Инструмент Ping

Инструмент Ping доступен через панель инструментов в правом нижнем углу игрового стола, но только в [режиме игры](/ru/docs/tools-overview/#toolbar-and-modes).
Он служит минималистичным инструментом-«маячком».
Пока кнопка мыши нажата и удерживается, всем игрокам отображаются два круга в текущем положении вашего курсора.

Круги пинга используют тот же цвет, что и цвет вашей линейки из [настроек клиента](/ru/docs/game/settings/).
