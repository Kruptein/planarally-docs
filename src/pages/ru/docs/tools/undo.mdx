# Отменить/Повторить

У этого «инструмента» нет места на панели инструментов или какого-либо другого элемента интерфейса — он управляется двумя сочетаниями клавиш.

С помощью ctrl+z вы можете отменить операцию, а с помощью ctrl+shift+z — повторить её.

Список поддерживаемых в настоящее время действий:

- перемещение фигур
- поворот фигур
- изменение размера фигур
- смена этажа
- смена слоя
- создание/удаление фигур
