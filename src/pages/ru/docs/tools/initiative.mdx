# Инструмент Initiative

Инструмент Initiative — это перемещаемое всплывающее окно, которое позволяет отслеживать порядок инициативы различных объектов (обычно жетонов).

<Image src={InitiativeOverviewPicture} width={462} aspectRatio={462 / 492} alt="Обзор инструмента Initiative" />

## Доступ

Инструмент Initiative недоступен через панель инструментов в правом нижнем углу пользовательского интерфейса.
Вместо этого к нему обращаются через контекстные меню.
Щёлкнув правой кнопкой мыши в любом месте карты, вы всегда можете выбрать `Show Initiative` в контекстном меню, активировав тем самым инструмент.
Кроме того, контекстное меню объектов (фигур, активов или жетонов) показывает опцию `Show Initiative`, если объект уже внесён в список инициативы.
Если объект ещё не внесён в список инициативы, контекстное меню покажет `Add Initiative` (`Add all to Initiative`, если выбрано несколько объектов), что одновременно откроет инструмент Initiative и внесёт объект в список.

Инструмент Initiative открывает перемещаемое всплывающее окно, которое можно закрыть, нажав на <WindowClose /> в правом верхнем углу.

Он содержит список инициативы, в котором может быть несколько отдельных записей, а ниже — панель с несколькими функциями.

## Список инициативы

Список инициативы по сути представляет собой таблицу с шестью столбцами и строкой для каждого объекта, добавленного в список инициативы.
_Активная_ строка/запись выделяется зелёным фоном, что означает, что наступил ход этого объекта.

При наведении курсора на запись отображается имя внесённой фигуры, а связанный с ней объект на карте выделяется красной рамкой.
Это особенно полезно, если на карте есть несколько объектов, иллюстрированных одним и тем же активом (например, похожие монстры и т. п.).

### Обозначение

В самом левом краю каждой строки находится обозначение фигуры, внесённой в инициативу.
Если объект является активом, обозначением будет миниатюрная версия актива.
Если объект является базовым жетоном, обозначением будет текст, отображаемый на жетоне.
Если объект является другой фигурой, обозначением будет имя фигуры, указанное в свойствах при добавлении объекта в инициативу.

### Значение инициативы и сортировка

За обозначением следует значение инициативы, которое может быть любым числом.
Игроки могут изменять значение инициативы только тех объектов, к которым им предоставлен доступ.
DM может изменять значение инициативы всех объектов в списке.

Записи автоматически сортируются по этому значению: наибольшие значения оказываются в верхней части списка, наименьшие — в нижней.
При наведении на запись она выделяется рамкой с выступом в правом нижнем углу.
Любой элемент можно перетащить, щёлкнув и удерживая этот выступ, — ручная сортировка имеет приоритет над автоматической.

### Эффекты с длительностью

В следующем столбце отображается значок <Stopwatch />, за которым следует число (по умолчанию 0).
Этот столбец показывает, сколько эффектов с длительностью (см. ниже) назначено объекту.
Эта функция удобна для отслеживания баффов и/или эффектов (например, заклинаний), наносящих урон с течением времени.

Эффекты с длительностью — это произвольные записи, назначаемые записи в списке инициативы, которые действуют лишь ограниченное время, то есть в течение раундов.
Щелчок левой кнопкой мыши по значку <Stopwatch /> добавит новый эффект с длительностью, связанный с соответствующей записью.
При наведении на запись список эффектов с длительностью раскрывается ниже, соединяясь с выделяющей рамкой.
Список эффектов с длительностью активной записи всегда раскрыт.

Эффекты с длительностью можно добавлять в любой момент.
DM может добавлять эффекты к любой записи, а игроки — только к записям, к которым им предоставлен доступ.

Каждый эффект с длительностью имеет два значения: описание и длительность.
Описание отображается слева (по умолчанию при создании: `New Effect`) и может быть любым текстом.
Длительность отображается справа (по умолчанию: `10`) и должна быть числом; она описывает продолжительность эффекта в предстоящих раундах.
Каждый раз, когда запись становится _активной_, длительность уменьшается на единицу, пока не достигнет `0`.

После того как длительность достигнет `0`, при следующем переходе записи в активное состояние, вместо изменения с `0` на `-1`, эффект с длительностью исчезнет.
Его можно удалить, нажав кнопку-корзину <TrashAlt /> рядом с ним.

### Видимость

В следующем столбце отображается значок <Eye />, который переключает видимость записи.
Если значок <Eye /> выглядит серым, объект невидим, то есть соответствующую строку видит только DM.
Объект, добавленный игроком, по умолчанию видим, а объекты, добавленные в инициативу DM, по умолчанию невидимы.

### Групповая инициатива

Во втором справа столбце отображается значок <Users />.
Щелчок по значку переключает индивидуальную/групповую инициативу.

Когда запись отмечена как _групповая инициатива_, её нельзя удалить (см. ниже) — ни нажатием на символ-корзину <TrashAlt />, ни удалением связанного объекта.
При наведении курсора она по-прежнему будет выделять связанный жетон; в настоящее время нет возможности выделять несколько объектов одновременно.

### Удаление

Самый правый столбец со значком <TrashAlt /> служит для удаления записи из списка.
DM может удалить любую запись из списка инициативы.
Игроки могут удалять только записи, к которым им предоставлен доступ.

Удаление жетона, внесённого в инициативу, или его перемещение в другую локацию также приведёт к удалению соответствующей записи в инструменте Initiative.

Записи, добавленные в групповую инициативу (см. выше), удалить нельзя.

## Панель функций

Панель функций представляет собой одну строку, содержащую индикатор `Round`, показывающий текущий раунд действий/боя, слева, и четыре кнопки справа от этого индикатора.

### Автоблокировка обзора

Значок <Eye /> переключает автоблокировку обзора. Эта функция полезна для игроков, которым принадлежит более одного жетона. Если она активна, то каждый раз,
когда ход переходит к другому объекту (см. [следующий ход](/ru/docs/tools/initiative/#next-turn) ниже), будет показываться обзор только
этого объекта. Каждый игрок может включать и отключать эту функцию индивидуально. Автоблокировка обзора показывает обзор только тех
объектов, к которым у игроков есть соответствующий доступ.

<Info title="Vision Tool">
    Автоблокировка обзора вызывает перенастройку [инструмента Vision](/ru/docs/tools/vision/). Используйте этот
    инструмент, чтобы настроить, какие линии обзора вы хотите видеть вне инициативы.
</Info>

Для DM эта кнопка не имеет функции, поскольку они всегда видят всё.

### Автоблокировка камеры

Значок <Video /> переключает автоблокировку камеры.
Когда автоблокировка камеры активна, каждый раз, когда ход переходит к другому объекту (см. ниже), область просмотра центрируется на новом активном объекте.
Каждый игрок может включать и отключать эту функцию индивидуально.
Автоблокировка камеры центрирует область просмотра только на тех объектах, которыми игроки могут управлять.
Поэтому для DM центр области просмотра будет меняться практически при каждом нажатии кнопки _Next_.
Область просмотра игроков будет меняться только тогда, когда согласно трекеру инициативы активным становится жетон, которым они управляют.

### Сброс

Кнопка <SyncAlt /> сбрасывает раунды и ходы.
Раунды будут сброшены до Round 0, а ход будет передан объекту в верхней части списка.
Обратите внимание, что ни значения инициативы, ни эффекты с длительностью не сбрасываются.
Эта функция доступна только DM.

### Следующий ход

Кнопка <ChevronRight /> (_Next_) назначает следующего игрока в порядке инициативы _активным_ (см. выше).
Эта функция доступна только DM.
