# Инструмент Zoom

Хотя это и не выбираемый инструмент на панели, в правом верхнем углу экрана есть отдельный инструмент Zoom.

Кроме того, для масштабирования можно использовать колесо прокрутки мыши.
Это поведение можно отключить в [настройках клиента](/ru/docs/game/settings/#behaviour).

Ключевое различие между колесом прокрутки и инструментом прокрутки в том, что первое масштабирует относительно указателя мыши, а второй — относительно центра экрана.
