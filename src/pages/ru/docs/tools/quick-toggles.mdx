# Быстрые переключатели

Под панелью инструментов DM есть несколько дополнительных значков. Это быстрые переключатели, полезные для самых разных задач.

<Image src={QuickTogglesImage} width={150} alt="Обзор панели быстрых переключателей" />

## Подмена игрока

Когда эта функция включена, экран DM отображается так, как если бы они находились в режиме подмены игрока (см. [Подмена игрока](/ru/docs/dm/settings/#fake-player)).

## Линия обзора

Этот быстрый переключатель появляется только при включённой [линии обзора](/ru/docs/dm/settings/#only-los).

Он позволяет отключить LoS **только** на вашем экране. Как и переключатель подмены игрока, он помогает проверять настройки освещения и обзора во время подготовки.
Он отображается зелёным, когда LoS включён, и красным, когда он (временно) отключён.

В частности, при работе над новой локацией, где у вас, скорее всего, нет готовых фигур с доступом к обзору, вы можете использовать его для проверки настроенного освещения без необходимости создавать временные фигуры.

## Инициатива

Быстрый переключатель инициативы по сравнению с другими переключателями — это больше, чем просто удобство.
При включении он становится зелёным (пока вы не нажмёте снова) и указывает, что [инициатива](/ru/docs/tools/initiative/) активна.

Он автоматически открывает интерфейс инициативы для всех игроков и активирует некоторые из [настроек инициативы](/ru/docs/game/settings/#initiative).
Эти настройки активны только тогда, когда инициатива явно включена с помощью этого переключателя!
