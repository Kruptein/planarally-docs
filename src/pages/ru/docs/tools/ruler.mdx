# Инструмент Ruler

Инструмент Ruler доступен через панель инструментов в правом нижнем углу игрового стола независимо от [режима](/ru/docs/tools-overview/#toolbar-and-modes).
Это простой инструмент, позволяющий измерять расстояния.

Из точки клика рисуется линия с числом, показывающим расстояние до курсора мыши, — до тех пор, пока вы не отпустите кнопку.
Нажатие `space` по пути устанавливает контрольные точки, чтобы легко измерять расстояния вокруг объектов.
Отображается первая десятичная цифра, что позволяет использовать метрическую систему с играми, задуманными для имперской (например, стандартная сетка 5 фт в D&D соответствует 1,5 м).

Если включить параметр `Share with others`, появляющийся над кнопкой `Ruler` на панели инструментов, линейка будет **публично** видна всем игрокам в сессии.
Если этот параметр выключен, линейку видите только вы.
Эта настройка также используется линейкой, встроенной в [инструмент Select](/ru/docs/tools/select/).

Цвет, которым отрисовывается линейка, каждый игрок может выбрать в [настройках клиента](/ru/docs/game/settings/).
Линейка также имеет [поведение привязки](/ru/docs/game/snapping/), которое пытается привязываться к логичным местам на сетке.
