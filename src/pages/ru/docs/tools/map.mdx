# Инструмент Map

Инструмент Map доступен на панели инструментов в правом нижнем углу игрового стола, но только в [Режиме сборки](/ru/docs/tools-overview/#toolbar-and-modes) и только для GM.
Он предлагает простой способ подогнать произвольную фигуру под сетку.
Его можно использовать для изменения размеров произвольных фигур, но основное его применение связано с картами.

Чтобы использовать инструмент Map, сначала нужно выбрать фигуру.
Если это не так, инструмент Map сообщит вам об этом, и вы сможете выбрать фигуру прямо в нём, не переключаясь на инструмент Select.

Если фигура выбрана, вы сможете выделить в ней область, которую хотите использовать в качестве ориентира, либо масштабировать всё изображение целиком.
Обратите внимание: в любом случае масштабируется всё изображение.
Масштабирование «всего изображения» просто берёт всё изображение за ориентир, не выделяя для этого лишь его часть.

## Выбор области

Область выбирается перетаскиванием рамки вокруг неё.
Например, вы можете выделить область, которая должна соответствовать участку 3 на 3 на сетке.
После первоначального выделения вы можете изменить его размер и дополнительно подправить, чтобы оно покрывало ровно то, что вам нужно.

Когда выделение готово, вы можете указать размеры X и Y, которые должна занимать выделенная область, и нажать Apply.

## Масштабирование всего изображения

Масштабирование «всего изображения» использует всё изображение в качестве ориентира для масштабирования.
Это можно сделать, указав целевое количество ячеек сетки или целевое количество пикселей.
При указании ячеек сетки изображение будет занимать заданное количество ячеек, а при указании пикселей — изменит размер согласно введённым значениям.
В обоих вариантах можно сохранить пропорции изображения, соединив символ-«звено» (links) справа от полей ввода.
