# Инструмент Vision

Инструмент Vision доступен на панели инструментов в правом нижнем углу игрового стола в обоих [режимах](/ru/docs/tools-overview/#toolbar-and-modes).
Он помогает отслеживать обзор нескольких жетонов.
Его поведение различается для игроков и DM.

## Игрок

При щелчке инструмент Vision откроет список всех объектов, для которых у игрока [настроен доступ к обзору](/ru/docs/game/shapes/#access).
По умолчанию они отображаются в списке как активные, что обозначается цветным фоном.
Во всех режимах и инструментах будет показываться только обзор тех жетонов, у которых в инструменте Vision есть _активная_ запись.

При щелчке запись деактивируется, и её фон становится серым.
При этом обзор этого жетона больше не будет отображаться на игровом столе.

## DM

По умолчанию DM всегда видят всё.
Использование одного лишь инструмента Vision этого не изменит.
Однако они могут [подменить игрока](/ru/docs/dm/settings/#fake-player), чтобы добиться эффекта, аналогичного описанному выше.
В этом случае они используют инструмент Vision, чтобы определить, чей обзор игрока они хотят видеть.
