# Краткая справка

## Слои по умолчанию

Подробнее о слоях см. в [документации по слоям](/ru/docs/dm/layers/).

| Имя    | виден игрокам | редактируется игроками | краткое описание                                                          |
| ------ | ------------- | ---------------------- | ------------------------------------------------------------------------- |
| Map    | Да            | Нет                    | Слой под сеткой, обычно используемый для карт-активов                     |
| Grid   | Да            | Нет                    | Недоступен для выбора даже DM, но может быть настроен в настройках сессии |
| Tokens | Да            | Да                     | Основной игровой стол                                                     |
| DM     | Нет           | Нет                    | Место для DM, где можно размещать объекты, скрытые от игроков             |
| Vision | Да            | Нет                    | Все фигуры здесь невидимы на других слоях                                 |

## Сочетания клавиш

На Mac используйте `Command` вместо `Ctrl`.

### Перемещение

Значительная часть сочетаний клавиш посвящена перемещению фигур или экрана.

| Клавиша/Модификатор         | Контекст       | Действие                                                                 |
| --------------------------- | -------------- | ------------------------------------------------------------------------ |
| Arrow-keys, Numpad 1-4, 6-9 | нет выделения  | Сдвинуть стол на 1 клетку сетки в указанном направлении                  |
|                             | есть выделение | Сдвинуть выбранные фигуры на 1 клетку сетки в указанном направлении      |
| Space, Numpad 0             |                | Отцентрировать экран на следующем жетоне (циклически по вашим жетонам)   |
| Shift                       | есть выделение | Перемещать фигуры сквозь препятствующие движению объекты (только для DM) |
| Ctrl + 0, Numpad 5          |                | Сфокусироваться на начале координат (0,0) сетки                          |
| Numpad 5                    | есть выделение | Сфокусироваться на центре выделения                                      |
| middle mouse click (hold)   |                | Перемещать экран                                                         |
| middle mouse scroll         |                | Масштабировать относительно текущего указателя мыши.                     |
| Page up/down                |                | Переместить этаж камеры вверх/вниз                                       |
| Page up/down + alt          | есть выделение | Переместить выделение на этаж вверх/вниз                                 |
| Page up/down + shift + alt  | есть выделение | Переместить выделение и этаж камеры вверх/вниз                           |

### Поведение

| Клавиша/Модификатор | Контекст | Действие                                                     |
| ------------------- | -------- | ------------------------------------------------------------ |
| Tab                 |          | Переключить режимы (Сборка/Игра)                             |
| Alt (hold)          |          | Отключить [привязку](/ru/docs/game/snapping)                 |
| Ctrl + u            |          | Показать/скрыть интерфейс                                    |
| Ctrl + z            |          | Отменить                                                     |
| Ctrl + shift + z    |          | Повторить                                                    |
| n                   |          | Открыть [менеджер заметок](/ru/docs/game/notes)              |
| Space               | линейка  | Установить контрольные точки [линейки](/ru/docs/tools/ruler) |

### Взаимодействие с выделением / фигурами

| Клавиша/Модификатор | Контекст          | Действие                                                         |
| ------------------- | ----------------- | ---------------------------------------------------------------- |
| Enter               | есть выделение    | Открыть диалог редактирования фигуры                             |
| Ctrl                | есть выделение    | Расширить активное выделение фигурами, выбранными с зажатым Ctrl |
|                     | изменение размера | Сохранять пропорции                                              |
| Space               | есть выделение    | Установить контрольные точки [линейки](/ru/docs/tools/ruler)     |
| Del, Backspace      | есть выделение    | Удалить все фигуры из активного выделения                        |
| d                   | есть выделение    | Снять выделение со всех выбранных фигур                          |
| x                   | есть выделение    | Отметить фигуру(ы) как побеждённые                               |
| Ctrl + l            | есть выделение    | Заблокировать/разблокировать выбранные фигуры                    |
| Ctrl + c            | есть выделение    | Скопировать выделение в буфер обмена                             |
| Ctrl + v            |                   | Вставить из буфера обмена на стол                                |
