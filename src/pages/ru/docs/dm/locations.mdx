# Локации

Инструмент Locations предоставляет несколько экземпляров набора [слоёв](/ru/docs/dm/layers/) с собственными настройками; каждый такой экземпляр далее будет называться _локацией_.

## Панель локаций

Активно получать доступ к локациям и управлять ими может только DM.
Для этого нажмите на значок <Compass /> в левом верхнем углу экрана.
Поскольку это функция «только для DM», игроки не видят эту кнопку.
Игроки одновременно взаимодействуют только с одним холстом; для них каждая новая локация выглядит как другая карта (то есть другой набор уложенных друг на друга [слоёв](/ru/docs/dm/layers/)).

Когда панель открыта, в первой её строке слева отображается кнопка создания новой локации, за которой следуют элементы для каждой локации кампании.
Текущая локация выделяется белым текстом и значком <Cog />, тогда как текст и кнопки остальных локаций белые с красноватым оттенком.
Каждый элемент списка состоит из ручки для перетаскивания локации, отображения её названия и кнопки <Cog /> для доступа к настройкам конкретной локации.

Локация, в которой присутствуют игроки, также отображает вкладку с надписью «Players» (Игроки), которую можно развернуть, чтобы увидеть список конкретных игроков, находящихся в этой локации.

Во второй строке панель локаций показывает кнопку доступа к архивированным локациям.
Если ни одна локация не архивирована, кнопка будет слегка полупрозрачной; она станет полностью непрозрачной, если архивирована хотя бы одна локация.

Повторный клик по значку <Compass /> закроет панель локаций.

## Создание и изменение порядка локаций

Нажатие на кнопку «+» слева на панели локаций откроет диалог, в котором нужно ввести название локации.
Это название можно изменить позже.

## Настройки локации

Новая локация наследует настройки по умолчанию кампании, заданные в [настройках](/ru/docs/dm/settings/).
Некоторые из этих настроек можно переопределить индивидуально для каждой сессии.

Настройки локации открываются по значку <Cog /> на соответствующем элементе панели локаций.
Настройки локации открывают диалог с тремя вкладками: Admin, Grid и Vision.

Любая настройка, переопределяющая значения по умолчанию кампании, останется такой до сброса.
Ручная установка настройки, совпадающей со значением по умолчанию кампании, не восстановит связь с умолчаниями, а сохранит это значение, даже если значения по умолчанию кампании впоследствии изменятся.

### Admin

Вкладка _Admin_ в настройках локации позволяет переименовать локацию, отправить её в архив или удалить.

Архивированные локации исчезнут с панели локаций.
Чтобы вернуть архивированную локацию на панель, откройте архив через кнопку `Show archived locations` (Показать архивированные локации) на панели локаций.
Откроется список всех архивированных локаций.
Восстановление выполняется нажатием кнопки `select` (выбрать).

<Image src={RenameLocation} alt="Меню переименования локации" />

Архивировать или удалять можно только те локации, где никого нет — ни игроков, ни DM.

## Смена локаций

При открытой панели локаций DM может сменить локацию, просто кликнув по блоку с названием нужной локации.

Игроки не могут сменить локацию самостоятельно.
По приглашению игроки присоединяются к существующей локации, в которой уже есть другой игрок (независимо от того, вошёл ли этот игрок в систему в данный момент).
Если в кампании нет других игроков, первый игрок, перешедший по приглашению, присоединится к локации, в которой активен DM.
Игроки останутся в своей активной локации, пока DM не перетащит их в другую.

Игроков можно перетаскивать группой или по отдельности, как показано здесь.

Игроки, отправленные в другую локацию, _не_ переносят с собой ни одной из фигур, которыми они управляют.
Эти фигуры должен отправить в ту локацию DM.

## Перемещение фигур в другую локацию

Если у локации есть одна или несколько точек появления, фигуры можно перемещать в эту локацию по отдельности или группой через контекстное меню по правому клику.

Как DM, вы можете создать одну или несколько точек появления, кликнув правой кнопкой по нужной области и выбрав действие «create spawntoken» (создать жетон точки появления).

При отправке в другую локацию фигуры появляются по центру выбранной точки появления — особой фигуры, которая находится на _dm_-[слое](/ru/docs/dm/layers/#dm).
