# Маркеры

Маркеры доступны из бокового меню (нажмите на значок <Cog /> в левом верхнем углу окна браузера, чтобы открыть меню).

Это место, где фигуры, которые вы отметили, появляются для быстрого доступа. Нажав на один из своих маркеров, вы отцентрируете экран на соответствующей фигуре.

Чтобы пометить фигуру, просто щёлкните по ней правой кнопкой мыши и выберите пункт «Установить маркер». После установки маркера вы можете снять его либо через меню маркеров, либо щёлкнув правой кнопкой мыши по фигуре и выбрав «Удалить маркер».
