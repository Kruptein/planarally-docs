# PlanarAlly Documentation

PlanarAlly is an open-source virtual tabletop you can self-host and run without an internet connection.
This documentation covers using PlanarAlly as a player or DM, and hosting your own server.

## Core features

**Lighting & vision** — Fog of war, dynamic lights, and line-of-sight so players only see what their characters can.
[Documentation →](/docs/dm/lighting-vision/)

**Layers, floors & locations** — Stack map elements in layers, split buildings into floors, and organise scenes across locations.
[Overview →](/docs/game/gameboard/)

**Assets & templates** — Upload maps and tokens, organise them in folders, and save shape presets for reuse.
[Documentation →](/docs/dm/assets/)

**Tools** — Ruler, draw, spell areas, initiative tracking, and more — available in Build and Play modes.
[Overview →](/docs/tools-overview/)

**Notes** — Campaign notes with search, tags, and optional attachment to shapes.
[Documentation →](/docs/game/notes/)

**Self-hosting** — Run your own server with full control over your data. Works offline once set up.
[Setup guide →](/server/setup/)
